## メイン説明文

```
ChatGPTを使ったデータ分析のやり方を、スシローの実話で解説します。
アンケートの自由回答1000件——ほとんどの会社が読み切れずに眠らせています。答えは「読まずに、読み切る」。分類と集計はAIに任せ、人は決めることに集中する分担です。

回転寿司最大手のスシローは、すし皿1枚1枚にICタグを付け、年間10億件規模のデータで1分後・15分後の売れゆきを予測。
廃棄量を約1/4（75%減と報道）にしました。ポイントは、データを「集めるため」ではなく「決めるため」に使っていること。

この動画で分かること：
✅ データ分析の価値は量でも高度さでもなく「決断への接続」
✅ 3つの原則（問いから始める／分類は機械に・解釈は人に／数字と声をセットで読む）
✅ 実演：そのまま使える自由回答の分類プロンプト（件数＋代表意見の原文引用）

「アンケートやレビューを集めたのに活かせていない」「グラフを眺めるだけで会議が終わる」個人事業主・小さな会社の担当者の方に特におすすめです。
明日やることは1つだけ——手元の自由回答を、この動画のプロンプトで分類してみること。

※ナレーションはAI音声合成（VOICEVOX:玄野武宏）を使用しています。
```
