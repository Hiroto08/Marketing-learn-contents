## メイン説明文

```
AIでの記事作成のやり方を、伊藤園の「日本初のAIタレントCM」の実話で解説します。
AIで記事や画像を量産すると没個性になる——それはAIの性能ではなく「任せかた」の問題です。

▼【無料】マーケの型 全20話まとめ＆実践チートシート（PDF）を配布中
👉 https://witty-composer-9473.kit.com/ac0f4ce77b

2023年9月、伊藤園は「お〜いお茶 カテキン緑茶」のテレビCMに生成AIのモデルを起用しました（日本初と報道）。
理由は安さではなく、「現在の自分と30年後の自分を同じ1人として描く」という、人には難しい表現の課題を解くため。
人の代わりをさせるのではなく、人にできないことを任せる——これがAI活用の分かれ目です。

この動画で分かること：
✅ 没個性の正体——「人の代替」と「人にできないことを任せる」の分かれ目
✅ 3つの原則（目的から選ぶ／AIは下書き係・人は関所／らしさを先に言語化）
✅ 実演：記事作成ワークフロー3段階（構成10案→AI下書き→人の関所）と「らしさの設計図」の書き方

「AI任せの文章が読まれない」「量産すると自分らしさが消える」個人事業主・小さな会社の担当者の方に特におすすめです。
明日やることは1つだけ——らしさの設計図（トーン3語・禁句3つ・視点1つ）を紙1枚に書くこと。

※ナレーションはAI音声合成（VOICEVOX:玄野武宏）を使用しています。
```
