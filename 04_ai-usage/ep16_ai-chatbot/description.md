## メイン説明文

```
チャットボット導入の成否を分ける「AI接客の設計」を、LOHACO「マナミさん」の実話で解説します。
24時間働いてくれるはずのボットが客を怒らせるのは、性能ではなく設計の問題——出口のない導線と、欲張った守備範囲です。

アスクルの通販サイトLOHACOは2014年にチャットボット「マナミさん」を導入。顔と名前を与えて利用が増え、
守備範囲をよくある質問に絞った結果、問い合わせの約5割を自動応答（オペレーター換算10人分以上）。
しかも問い合わせの約4割は、人が受けられない夜間でした。

この動画で分かること：
✅ ボットが嫌われる本当の理由——「できないことまでやらせる」から
✅ 3つの原則（守備範囲を決める／出口を塞がない／人格を与える）
✅ 導入前の紙1枚の準備（FAQトップ10・3回で人に渡すルール・名前と挨拶）

「問い合わせ対応に人手が足りない」「自動化したいが客に嫌われるのが怖い」個人事業主・小さな会社の担当者の方に特におすすめです。
明日やることは1つだけ——よくある質問トップ10を30分で書き出すこと（導入しなくてもFAQページになります）。

※ナレーションはAI音声合成（VOICEVOX:玄野武宏）を使用しています。
```
