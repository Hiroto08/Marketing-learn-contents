【第16回】24時間働く営業マン。AIチャットボットによる接客デザイン

「24時間対応できるはず」のチャットボットが、なぜ顧客を怒らせて離脱させてしまうのか。
原因は性能ではなく「会話設計」にあります。AI活用編の最終回となる今回は、
会話設計の3原則・カスタマージャーニー上の最適な配置・人間へのエスカレーション設計を、
実例とともに徹底解説します。

この動画では以下のことを解説します：
✅ 会話設計の3原則（1ターン1意図／フィードバックの可視化／トーン設計）とDon Norman・Cathy Pearlの知見
✅ カスタマージャーニー上でボットを置くべき場所（認知〜検討／購入〜サポート）
✅ エスカレーション設計の3条件と、過剰自動化・ロボット的な言葉づかいなど3つの落とし穴
```

## 参考・補足リソース

```
・Don Norman 『The Design of Everyday Things』改訂版（2013）——フィードバックとシニファイア（手がかり）の設計原則
