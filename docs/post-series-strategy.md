> 位置づけ：EP24（11/14 公開）の後＝**シーズン2**の基準文書。v0.1.1（10/29）を、制作現場の役割分担どおりに

> 企画の中身（各回のブリーフ）は `docs/season2-briefs.md`。上位の事業設計は `docs/monetization-strategy.md`、制作ルールは `.claude/skills/episode-production/`。

## 0. 結論（v0.1.1 からの変更点）

1. **相手を変える。** 実際に見ているのは「マーケを学びたい初心者」ではなく **40〜50代男性中心の"企業の裏側"好き**。本編の推薦元の9割は「下矢一良の正直メディア」（企業ニュース・PR・CMの裏側解説）だった。シーズン2はこの層に向けて、**実在企業の「なぜ？」をマーケの型で種明かしする**チャンネルにする。
2. **本編をやめない。むしろ本編が登録の本丸。** 1,000再生あたりの登録は Shorts 0.24人 に対し本編 **16.9人（約70倍）**。課題は「本編が見つからない」ことであり、本編の価値ではない。
3. **Shorts は毎日ではなく週4本。** v0.1.1 の「毎日1本」は撤回。外部調査（Metricool・79.9万本）では Shorts は月5本前後の投稿で本編の再生が最も伸び、月35本以上では本編が Shorts ゼロ並みに落ちる。さらに 2026年7月の収益化ポリシー明確化で「続けて見ると繰り返しに感じるテンプレ型」が明示的に対象になった。**本数より1本ごとの固有性。**
4. **タイトルは企業名から始める。** 検索で実際に来ている語は「伊藤園」「ジョブ理論」「髙田明」などの**固有名詞**。「CPA」「CRM」などの用語検索はほぼゼロ。
5. **完結した24話は「教科書」として L1（タイトル・概要欄だけ）で企業名入りに付け替える。** 再ビルド不要で、固有名詞検索と関連動画の入口を増やす。

## 3. プロデューサー決定（シーズン2の設計）

### 3.1 コンセプト

- **シリーズ名（仮）**：「売れる仕組みの裏側」
- **約束（チャンネルの一文）**：「あの会社は、なぜ売れる（売れない）のか。ニュースと身近な商品の裏側を、マーケの型で5分で解く」
- **相手**：40〜50代の会社員・管理職・経営者・自営業。ビジネスニュースや企業の裏話が好き。マーケの用語を学びたいわけではないが、**自分の仕事に使える「なるほど」**は持ち帰りたい。
- **競合との違い**：企業の裏側系（PR・メディア出身者の解説）は「何が起きたか」を話す。こちらは**「なぜ効いたか（型）」と「あなたの商売ならどうするか」**まで言う。24話の教科書が裏付けになる。

### 3.2 3本の柱

| 柱 | 形 | 頻度 | 中身 | 役割 |
|---|---|---|---|---|
| ① 裏側ショート | 30〜50秒 | **週4本** | 身近な商品・企業の「えっ？」を数字1つで種明かし | 認知・題材テスト |
| ② ケースファイル（本編） | **5〜7分**・10〜12枚 | 週1本（土） | 1本1社。冒頭10秒で答え→なぜ効くか（型）→あなたの商売への当てはめ | **登録の本丸** |
| ③ このチャンネルで実験 | 6〜8分 | 月1本（月末の土） | 本チャンネル自身の実数を全部見せて、マーケ理論を試した記録 | 他に無い一次情報 |

### 3.3 週の型

| 曜日 18:00 | 公開 | 狙い |
|---|---|---|
| 火 | ショート（テスト題材A） | 翌週以降の本編候補を試す |
| 木 | ショート（テスト題材B） | 同上 |
| 金 | ショート（土曜本編の予告：問いだけ出す） | 本編の初速をつくる |
| **土** | **本編（ケースファイル）**／月末は実験回 | 登録 |
| 日 | ショート（本編の続き：「明日やる1つ」） | 関連動画リンク＝本編 |

- 制作量は「Shorts 週4本＋本編 週1本」。今（本編2本＋Shorts 6本/週）より軽い。浮いた工数は**リサーチとパッケージング**に回す。
- **題材テストのループ**：火・木のテスト題材のうち、**公開7日後のエンゲージ再生が多い方**を、2週後の本編にする（リサーチ・台本の準備期間を1週とる）。

### 3.4 パッケージング規則（シーズン2で追加・変更）

1. **本編タイトルは企業名・商品名を先頭10文字以内に**置く（例：「コメダ珈琲は、なぜ長居されても儲かる？」）。フレームワーク名は付けないか、末尾の【】に。
2. **Shorts タイトルは「えっ？」を主語に**（数字・意外な事実・自分ごとの問い）。企業名はできるだけ入れる（検索の受け皿）。
3. サムネは企業のロゴや商品写真を使わない（権利）。**企業名の文字＋数字1つ＋対比**で作る。
4. 冒頭禁止：「この動画では」「今日の目次」「チャンネルの紹介」。**最初の10秒で問いの答えを言い切る**（10/28 の学び）。
5. 題材の重複禁止：24話の主人公（`docs/episode-briefs.md` と各回 script.md）と、**推薦元チャンネル（下矢一良の正直メディア等）が直近で扱った題材は主役にしない**（R4②の「既存の型の模倣」を避ける。補強の言及は可）。
6. 企業を貶めない（「敵は思い込み」の原則を継続）。炎上・失敗事例は事実と公開資料だけで語る。

### 3.5 判定に使う数字（シーズン2の最初の4週・11/15〜12/12）

| 指標 | 今 | 4週後の目標 |
|---|---|---|
| 新作 Shorts の公開7日後のエンゲージ再生（中央値） | **7**（10月公開11本。再生の中央値は50） | **75**（再生300前後に相当） |
| Shorts のエンゲージ率 | 24.8%（全期間）／約15%（10月公開分） | 30% |
| 本編の公開7日後の再生（中央値） | 約5 | **50** |
| 本編の30秒残存 | 36〜61% | 60% |
| 本編の平均視聴時間 | 0:22〜1:09 | 2:00 |
| 1,000再生あたりの登録（全体） | 0.6 | 2 |
| 本編の流入に占める関連動画＋Shorts の割合 | 約60% | 維持（70%） |

**12月末の着地**：登録者 **50人**（達成ライン）／100人（上振れ）。v0.1.1 と同じ。収益化戦略§4.2 の M1（登録者300・月間本編2,000再生）は **2027年3月に後ろ倒し**で確定する。

4週で Shorts と本編の目標の両方に届かなければ、§3.1 の相手は維持し、**題材の型**（身近な商品 ↔ 企業ニュース ↔ AI の驚き）の比率を入れ替える。

### 3.6 v0.1.1 の「初速低下の切り分け実験」の扱い

- 「毎日1本」の群は R2・R4 を踏まえて**取りやめる**。
- 代わりに **題材の効果だけ**を比べる：対照＝EP19〜24 の Shorts（講座寄り・3本同時公開）、比較＝シーズン2の最初の8本（勝ち型・分散公開）。公開の仕方も違うため、**2倍以上の差が出たときだけ**「勝ち型＋分散で行ける」と結論する。

| テンプレ量産と判定される（R4①②） | 週4本に絞る・毎回ちがう実在企業と数字・シーズン2で見た目を変える・他チャンネルの題材をなぞらない |
| 実在企業の扱い（誤り・名誉） | 公開資料だけで語る。断定は数字のある事実だけ。失敗事例は「何を学べるか」に寄せる |
| 時事ネタの鮮度切れ | 時事は全体の半分まで。残りは身近な商品の定番の謎（長く検索される） |
| 年齢層が上の視聴者に合わない語り口 | 若者向けの煽りやスラングを使わない。数字と事実で落ち着いて語る（今の VOICEVOX 男性声のままでよい） |
| 本編が短くなりミッドロール広告の条件（8分）を満たさない | 収益化はまだ遠い（44時間/4,000時間）。今は登録と視聴維持を優先。登録500人を超えたら 8分版を試す |
