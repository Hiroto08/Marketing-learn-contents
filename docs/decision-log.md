## 決定の記録

### 2026-11-05

- **記録は GitHub に残す**（ユーザーの指示）。考え・判断・提案は文書にしてコミットする。入口はこのファイル。動画（mp4）はリポジトリに入れない。
- **3週目（11/29〜）から「最新事例ファースト」**（ユーザー承認）。
  - 主役は直近3〜6か月の実例で、古典の研究は「なぜ」の説明役にする。
  - 予約は3〜5日先までにとどめる。
  - 理由：時事の Shorts はすでに上位にいる。Shorts は7日で再生が出尽くすので、ネタの古さで損をしない。
  - 最初の2週間（u01〜u14）は実験中なので、題材を変えない。
  - → 作戦 §5.1、`s2_ura/README.md`、`s2_ura/topic-pool.md`、`docs/routines/ura-weekly-production.md`
- **月・木 10:47 JST の制作ジョブを登録**。題材補充→制作→非公開アップ→公開予約の順に回す。初回の題材集めは 11/7 11:23。
- **ケースファイルに note 記事・Kit メールは当面付けない**（私の判断）。
  - 理由：note→YouTube の流入は28日で3回、Kit の購読者は1人。どちらも入口になっておらず、工数を YouTube に寄せる。
  - 週次分析で note からの流入が増えたら見直す。
  - → 作戦 §4.3
- **題材の差し替え2件**（私の判断）。
  - 値上げの回：ガリガリ君は EP21 で使ったため、コストコの1.5ドルのホットドッグ（u09）に替えた。
  - 行列の回：根拠の数字が無いため、北京のレストランの人気TOP5の実験（u06）に替えた。
  - 1本目と c01 は、JCペニーのセール全廃（売上−25%）にした。
- **YouTube のアップロード上限のリセットは、冬時間の間は17:00 JST**（夏時間は16:00）。アップの予定はこれに合わせる。
- **ビルド環境**：Playwright を、同梱の chromium-1194 に合う 1.56.0 に固定した（`_tools/setup_env.sh`）。今朝、録画が動かなかったため。
