# Shorts「関連動画」貼り付けチェックリスト

YouTube Studio専用の手動作業。**Data APIでは設定不可**（`videos`リソースに関連動画リンクの項目が無いため）。

旧本編（EP01〜06の旧版ドラフト）を削除したため、Shortの関連動画は下表の**現行本編ID**へ設定／貼り替える。

## 手順（1本あたり）

Studio → コンテンツ → 該当Short → 編集 → 「関連動画」 → 下表の「本編ID」を指定 → 保存。

- EP04〜06は本編もShortも非公開だが、Studioでは非公開動画も関連動画に指定でき、公開時にそのまま有効になる。
- EP07・08はShortが無いため対象外。
