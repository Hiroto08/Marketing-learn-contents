# 固有名詞の台帳（読みと確認ソース）

原稿（ナレーション・テロップ）に出る人名・企業名・商品名・地名は、すべてこの表に載せる（品質ルール 2026-11-10・Issue #2）。

- **載っていない固有名詞があると、ビルドは止まる**（`_tools/checks/check_readings.py`）。
- **読みが確認できない固有名詞は、原稿に使わない**。名前を出さない表現（「ある経済学者」など）に置き換える。
- 確認日は `python3 _tools/checks/proper_nouns.py --verify` が、確認ソースのページを取得して確認文字列を見つけた日を書く。手で書かない。
- 一次ソースの優先順：本人・会社の公式サイト → 出版社の著者紹介（著書の表記）→ 官公庁。海外の人名・社名で日本語の公式表記が無いものは、訳書の出版社か事典の表記を使い、「二次」と書く。
- 読みは、複数認めるときだけ「／」で並べる（例：ニッポン／ニホン）。
- 書式の決まりは `_tools/checks/proper_nouns.py` の冒頭にある。
