# 表現仕様書（デザイン＆サウンドコード）v1

2026-11-13 作成（社長指示・Issue #2 の Step 2）。チャツネのブランドコード v1 に「表現コード」として追補する案。

- **状態：採用（社長決裁 2026-11-13）。素材埋め込み・アニメーションありを標準とする。Shorts と長尺の両方に適用する。**
- **本適用の日程**

  | 期間 | 扱い |
  |---|---|
  | 〜11/28 | 試作のみ。公開済み・予約済みの動画（u01〜u14・c01・c02・EP24）には当てない |
  | 11/29〜12/5 | 試作のレビューと、この仕様書の確定。第3週の制作（u15〜u21）は現行の表現のまま |
  | 12/6 の週の制作バッチから | 本適用。Shorts は同週のバッチ（u22〜）から、長尺は次のケースファイル c03 から |

  日付の判定は `_tools/expression/expr_gate.py` が行う（`series.json` の `expression.apply_from`）。適用日より前は、映像意図があっても現行の表現で作る。
- 当て方の手順は `.claude/skills/yt-expression/SKILL.md`（どのモデルでも同じ結果になるよう、型の選び方と検査を決めてある）。動作確認は `bash _tools/expression/selftest.sh`。
- 台本・事実・数字・固有名詞の決まり（`quality-gates.md` の R・F・A・T）は、そのまま有効。この文書は「見た目と音」だけを決める。
- 項目はすべて、数値で合否を判定する。検査は `python3 _tools/expression/check_expr.py <mp4> --html <html>`。
- 判断の基準：デザインと音は、勝ちパターン「困りごとへの種明かし × 実在事例 × 数字」を引き立てるためにある。**数字が地味で飾りが派手なら不合格。**
- 型（色・配置・音の対応）は固定する。素材（BGM の曲・図の種類・写真）は回ごとに替える。

|---|---|---|
| 和文 | Noto Sans JP 900（本文）・700（補足） | Noto Sans JP 800〜900（本文）・600（補足） |
| 数字・英字 | Inter 900 | Inter 900 |
| 本文 | 76〜88px（テロップ同期のルールどおり。幅 870px に収める） | 58px（大きい行 77px） |
| **数字** | 本文の 1.4 倍（106〜123px） | カードの数字 123px／文中の数字は本文の 1.6 倍／題名の数字 192px |
| 見出し | — | 50px・補足色 |

| 番組名の帯 | 48px | 42px |

- 最小は Shorts 48px・長尺 42px。これより小さい文字（ページ番号・進行の点）は置かない。
- 行の長さ・折り返しは、テロップ同期のルール（画面の文＝ナレーション、`<br>` 以外で折り返さない）のまま。
- 西暦は「数字の見せ場」に数えない（白・本文と同じ大きさ）。

## 3. 配置

**Shorts**
- 上 192px・下 400px・左右 48px は空ける（今と同じ）。文字は中央の幅 880px。
- 番組名の帯：上のセーフエリアの直下・全スライドで同じ位置。「▍売れる仕組みの裏側 #01」。
- 進行バー：下のセーフエリアの直上・高さ 8px・シリーズの色。
- 映像の枠（§8 を使うとき）：帯の下・幅 880px・高さ 470px。文字はその下。

**長尺**
- 余白：上 11%・左右 6%・下 7%。番組名の帯は左上（上 4.2%・左 6%）、進行バーは下端（高さ 0.55%）。
- 1画面の要素は5つまで。最後の1枚（締め）は、番組名のカードを出す（空の画面を作らない）。
- 飾りの輪・点の格子・ページ番号・進行の点は出さない（情報を持たない要素）。

## 4. 数字とグラフ

- 数字は、その画面でいちばん大きく、数字の色。単位まで同じ大きさ・同じ色。
- 数字の出現は「拡大（1.3〜1.35倍）から等倍に着地・0.30秒」。行き過ぎて戻る動きは使わない。
- グラフは棒だけ（前→後の2本）。色は、前＝補足色、後＝数字の色。軸・目盛り・凡例は描かない。値のラベルは1つ。
- 回数・件数は「点の並び」で見せる（590回＝590個の点）。
- **グラフ・図に、台本に無い数字や文字を書かない**（T2 と同じ）。

## 5. BGM

| 項目 | 決まり |
|---|---|
| 曲 | 自作の3曲を回す：`bgm_a_calm`（84bpm）・`bgm_b_curious`（92bpm）・`bgm_c_steady`（88bpm）。回の番号 ÷ 3 の余りで決まる |
| テンポ | 80〜96bpm |
| 長さ | 1曲 60秒以上。同じ4小節を3回以上くり返さない（今の曲は22.5秒・2回くり返しを全話で使用） |
| 音の成分 | 3〜6kHz のエネルギーが全体比 −30dB 以上（今の曲は −68dB＝こもる） |
| 調 | ハ長調／イ短調。効果音（ラ・ド・ミ・ソ）と濁らない |
| 始まり | 0.00秒から鳴らす（フェードイン 0.05秒）。今は 1.5秒かけて立ち上がる |
| 声の下 | 声がある間は自動で約8dB 下げる（サイドチェイン）。声の無い所は基準音量 |
| 間 | 数字・答えの直前 0.45秒は、さらに 9dB 下げる（静けさを作る） |
| 終わり | 長尺：3秒でフェードアウト。Shorts：消さない（0.15秒だけ）＝ループのつなぎ目に谷を作らない |
| 禁止 | 歌入り・ドラムの強い曲・有名曲に似た進行のコピー・外部の音源で台帳に無いもの |

## 6. ラウドネスと声の処理

| 項目 | 基準 |
|---|---|
| 統合ラウドネス | −14.0 LUFS ±0.5（今は −14.8〜−15.1） |
| トゥルーピーク | −1.0 dBTP 以下 |
| 動画間の差 | 0.5 LU 以内 |
| 声と BGM | 声のある所と間の差 10〜20dB |
| 声の処理（この順） | ハイパス 70Hz → 250Hz を −2dB → 3.5kHz を +3dB → 8kHz 以上を +2dB → コンプレッサー（−22dB・3:1・アタック 8ms・リリース 120ms） |
| 間（ま） | 文の間 0.28秒・段落の間 0.45秒（今と同じ）。**数字の見せ場・答えの文の直前は 0.6秒（Shorts）・0.7秒（長尺）**。数字の間は1枚に1回まで |

- 声の読み・速さ・抑揚の設定は変えない（読みのルールはそのまま）。耳で確かめる項目（V1〜V4）は、人が判定する。

## 7. 効果音（意味と音の対応）

| 意味 | 音 | いつ | 音量 | 上限 |
|---|---|---|---|---|
| 問い | 上がって終わる2音（ラ→ミ）＋低い打音 | **動画の 0.00秒** | −9dB | 1本に1回 |
| 数字 | 低い打音＋短いクリック＋高い1音（ミ） | 数字が画面に出る瞬間 | −10dB | 1枚に1回（その画面で最初の数字） |
| 答え | 下がって落ち着く3音（ソ→ミ→ド）＋和音 | 答えの文が出る瞬間 | −9dB | 1本に1回 |
| 場面転換 | 0.3秒のやわらかい息 | スライドの切り替え | −20dB | 長尺だけ。Shorts では使わない |

- 同じ意味には、必ず同じ音。意味の無い所（箇条書き・補足）では鳴らさない。
- 本数：Shorts 5個まで・長尺は10秒に1個まで。間隔は 1.5秒以上。重なったら 問い ＞ 答え ＞ 数字 ＞ 場面転換 の順に残す。
- 「問い」（上がる）と「答え」（下がる）を対にして、冒頭の問いが最後に解決する形を音でも作る。

## 8. 映像意図と素材（Shorts・長尺。標準）

台本の各スライドに、次の型のどれかを付ける。付けた結果は `visual_plan.json` に残す。下書きは `plan_visuals.py` が規則で作り、残りを制作担当（どのモデルでも）が `yt-expression` スキルの表で埋める。

| 型 | 使う場面 | 素材 | 動き |
|---|---|---|---|
| 実写イメージ（photo） | 固有名詞（会社・店・場所）が出るスライド | 台帳にある写真だけ（CC0／Public domain／CC BY） | ゆっくり寄る（6秒で 1.0→1.14倍）。数字・年は写真の上に同期して出す |
| 図解アニメ（chart_drop・compare_bars・dot_grid・tag_strike・timeline） | 数字・仕組みを言うスライド | 自作（台本の数字から描く） | 数字のテロップが出た瞬間に、棒が下がる・点が並ぶ・線が引かれる |
| 記号（question・quote・check） | 問い・発言の引用・答え | 自作（疑問符・かぎかっこ・チェックを線で描く） | 0.9秒で描く |
| 長尺：背景の絵（photo・dot_grid）と、数字のカードの棒（bar_cells） | 題名・締め・固有名詞・同じ単位の数字 | 写真は台帳／棒と点は自作 | 写真は24秒かけて寄る。棒は数字と同時に伸びる。文字の配置は変えない |
| 数字の強調表示 | 数字のあるテロップ | — | §4 のとおり |
| 場面転換 | スライドの切り替え | — | 枠ごと下から 0.30秒 |

## 9. 動き

| 項目 | 決まり |
|---|---|
| 出現の種類 | 2種だけ：①下から 14〜18px＋フェード（文字・枠）②拡大から着地（数字だけ） |
| 速さ | どちらも 0.30秒。イージングは `cubic-bezier(.2,.8,.2,1)`（行き過ぎない） |
| タイミング | 要素は、その文を読み始める 0.15〜0.3秒前に出す（今の長尺は 1.2秒前） |
| 使わない | 左右からのスライド・弾む動き・回る飾り |
| 冒頭 | 0.00秒で問いの音、2.0秒以内に数字の着地 |
| ループ（Shorts） | 末尾の無音は 0.6秒まで。BGM は末尾で消さない。絵は冒頭と同じ絵で終わる（§8 V4） |

## 11. ライセンス台帳

`docs/expression/license-ledger.md`。BGM・効果音・書体・画像の、出どころ・商用の可否・クレジット表記。

- 台帳に無い素材は使わない。
- 写真は `_tools/expression/fetch_assets.py` で取得する。取得と同時に、解像度（元の幅 1600px 以上）とライセンス（CC0／Public domain／CC BY）を検査し、台帳に追記する。
- BGM・効果音は、数式から合成した自作（`_tools/expression/synth_v1.py`）。外部の音源は使っていない。

## 13. まだ決めていないこと・できていないこと

- 24話シリーズの長尺（18枚構成）への CSS の当てはめは未検証（試作はケースファイル c01 と Short u01）。24話は全話が公開済みなので、当てる予定は無い。
- 映像意図の下書きは規則で作るが、型を選べないスライド（TODO）は人か AI が埋める。
- 音色の良し悪しは、数値では決められない。Before／After を聞いた人の判定で、§5〜§7 の数値を直す。
- ストック動画（動く実写）は取得元を決めていない（Pexels・Pixabay は API キーが必要）。試作は写真だけ。
