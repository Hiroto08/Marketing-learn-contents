## 4. 変えたこと・変えていないこと

| | 変えた | 変えていない |
|---|---|---|
| 声 | EQ とコンプレッサー（明瞭さの帯域を上げた）。数字と答えの前の間 | 読み・話速・抑揚の設定・台本 |
| BGM | 自作の新しい曲（3曲のうち1曲。68〜73秒・高い音の成分あり）。0秒から鳴らし、声の間は自動で下げる | — |
| 効果音 | 意味ごとに1種（問い・数字・答え・場面転換）。本数を減らした | — |
| 絵 | 色（数字は黄だけ・シリーズは赤1色）、数字を1.4倍、番組名の帯、進行バー、動きを2種に | テロップの文（画面の文＝ナレーション） |

## 5. フレームで確かめて、直した不具合（Fable の最終確認）

| 見つけたこと | 対処 |
|---|---|
| 録画すると、画面にコードの文字が並んだ（CSS のコメントに閉じタグの文字があり、録画用の HTML が壊れた） | コメントを直し、検査を足した |
| 写真が表示されない（録画用の HTML は別のフォルダに置かれる） | 写真を HTML に埋め込む方式にした |
| 1枚目の棒グラフ・数字が動かない（録画エンジンは、1枚目を最初から完成形で出す） | 1枚目は表示の瞬間から時間で動かす |
| 進行バーが動かない | 同上 |
| 長尺の1枚目で、題名の数字が5秒間出ない（番組名のラベルの「#01」を数字と誤判定） | 「数字＋単位」だけを数字と判定 |
| トゥルーピークが −0.6dBTP（AAC 変換で伸びた） | 測って収束させる処理を足した |

## 6. 残っていること（正直に）

1. **Short の冒頭 約0.3秒、テロップの「25%」が空いて見える**（数字が着地する前）。着地を早めるか、最初から出しておくかは要判断。
2. 既存の `verify_shorts.py` の折り返し検査が、③で誤って不合格を出す（数字を大きくすると、行数の数え方がずれる。実際の行数は `<br>` どおりと計測で確認済み）。本適用の前に、検査の数え方を直す。
3. 長尺の最後の1枚（上記 M2）。
4. 映像意図の下書きを機械で作る道具・ストック動画（動く実写）の取得元は、まだ無い。
5. 24話シリーズ（18枚構成）の長尺には、まだ当てていない。
6. 音色（BGM と効果音が心地よいか・安っぽくないか）は、数値では分からない。聞いた感想を Issue #2 にください。数値を直します。
