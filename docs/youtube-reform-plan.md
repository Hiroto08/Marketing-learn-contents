## 1. ゴールとKPI

**ゴール**：「体系的なマーケ講座」から「**1本ずつ独立してクリックされ、最後まで見られ、次も見たくなる動画**」への転換。

| KPI | 最低ライン | 目標 | 判定に使う画面 |
|------|-----------|------|--------------|
| CTR（クリック率） | 2%（これ未満は埋没） | 検索面8%／全体4〜5% | アナリティクス「リーチ」 |
| 30秒地点の残存率 | 60% | 70%以上 | 維持率グラフ |
| 平均視聴維持率（8〜9分動画） | 35% | 45〜55% | 維持率グラフ |
| 1本あたりShorts切り出し | — | 3本 | — |

- 8〜9分という尺は**変えない**（現アルゴリズムで10〜20分帯は適正。伸びない原因は尺ではない）
- VOICEVOXも**継続**（2025年収益化ポリシーはAI音声自体を許容。リスクは「量産テンプレ感」であり、対策は毎回のエピソード固有の事例・図解）

## 2. 現状診断——伸びない7つの構造要因

1. **タイトルが「シラバス型」**：「第N回：〜の超基本」はフレームワーク名が主語。伸びる型は視聴者の得・損・数字が主語（例：リベ大「月5万円の副収入を…」62万回）。「第N回」表記自体が新規視聴者への離脱シグナル。
2. **冒頭11〜19秒が定型オープニング**：「第N回のテーマは〜。さっそく始めましょう」は、視聴者の55%が最初の60秒で離脱する環境では致命的。フックがスライド2まで遅延している。
3. **教科書型の概念解説**：伸びているフェイスレス系（Modern MBA、フェルミ漫画大学、ずんだもん経済系）は例外なく「実在の物語・事例」が入口。概念→例の順ではなく、事例→原則の順が勝ち筋。
4. **画面変化が遅い**：平均28秒/スライドに対し、実証水準は「5〜7秒に1回の視覚変化」。
5. **流入設計が無い**：登録者ゼロ期はブラウジング露出がほぼ無く、現実的な入口は検索＋Shorts。検索KW設計・Shorts切り出しが未実施。
6. **パッケージング後行**：サムネ・タイトルが制作後の後付け。トップ戦略家の原則は「クリックされるtitle+thumbnailが作れない企画はやらない」（時間の30%を企画とパッケージへ）。
7. **ニッチの天井**：「マーケを体系的に学ぶ」層は小さい（マーケ特化はプロ運営でも単体10万人規模）。隣接する大きい需要は「お金・副業・AIツール実演」。特にEP13〜16のAI編は「AI×実演×成果物」文脈に載せ替えれば最大の勝ち筋。

## 4. 新フォーマット仕様 v2（18枚 big style は維持）

### 4.1 動画構造（8〜9分・18スライドへの割り付け）

| 区間 | スライド | 役割 | 必須要素 |
|------|---------|------|---------|
| 0:00〜0:15 | S1 | **コールドオープン** | ビジュアルアンカー（衝撃的な1つの数字/対比）＋違和感フック。※「第N回のテーマは」「さっそく始めましょう」等の定型挨拶は**禁止** |
| 0:15〜0:45 | S2 | **約束（Hormozi式4P）** | Promise（この動画で分かること）→Plan（進め方3点）→Proof（信じられる根拠：実例の数字）→Picture（見終わったあなたの変化）。ここで**メインのオープンループ**（答えはS14以降まで保留する問い）を張る |
| 0:45〜3:00 | S3〜S6 | **ケーススタディ前半** | 実在企業/実例の物語で問題を劇化（1つの事例を深掘り。細切れに例を変えない） |
| 3:00前後 | S7 | **リフック①** | 意外な数字・常識の反転・失敗の暴露 |
| 3:00〜5:30 | S8〜S11 | **原則の抽出** | 事例から理論・フレームワークを一般化。2分毎にミニ問いかけ（「あなたの商品なら？1秒考えてみてください」型）を挟む |
| 6:00前後 | S12 | **リフック②** | 2つ目の反転／メインループの部分回収 |
| 5:30〜7:30 | S13〜S15 | **適用** | 冒頭と同じ事例に原則を当てはめ直す（サンドイッチの下パン）＋視聴者の状況への翻訳（As-Is→To-Be） |
| 7:30〜8:30 | S16〜S17 | **回収とまとめ** | メインループの完全回収。まとめは「明日やること1つ」で締める |
| 最後20秒 | S18 | **次への開ループ** | 次回予告ではなく「未解決の問い」を1つ残す＋終了画面用の静止レイアウト（口頭でも次動画へ誘導） |

### 4.2 ナレーション執筆ルール（数値基準）

- 接続詞監査：「そして」「また」は1本あたり合計2回まで。スライド間の接続は「しかし／ところが／実は／だから／つまり」を基本にする（But/Therefore連鎖）
- 問いかけ（「〜と思いますか」「考えてみてください」等）を1本あたり3回以上、約2分間隔で配置
- オープンループ：S2で張った問いはS14以降まで回収しない。中盤（S8前後）に第2の問いを追加
- 冒頭禁止句：「第N回のテーマは」「さっそく始めましょう」「今日は〜を解説します」（最初の2文以内での使用禁止。約束パート（S2）での「この動画では〜」は可）
- 用語は初出時に必ず一言の平易な補足（EP07のD2C/OMO対応と同様）
- 事実・数字は必ず実在の出典（ファクトチェック済みリスト方式を継続）

### 4.3 スライド・テンポ規則

- **STEPS密度**：各スライドのアニメーションSTEP数 ≥ そのスライドのナレーション秒数 ÷ 7（端数切り上げ）。検証スクリプトあり（skill参照）
- 15秒を超える「変化ゼロ区間」禁止（要素の順次出現・ハイライト移動・グラフ伸長で埋める）
- 図解は毎回1つ以上「このエピソード固有」のものを作る（使い回しテンプレ図解だけの回を作らない）
- サムネで使える「絵になる1枚」（対比・数字・Before/After）を必ずS1またはS7に置く

### 4.4 パッケージング規則

- **タイトル**：25文字以内／視聴者の得・損・数字が主語／フレームワーク名は後半か【】内／「第N回」を入れない
  - 型：`【ターゲット】数字＋損失回避`（例：「広告費、その計算だと赤字です｜CPA・LTV入門」）
- **サムネ**：メイン文字6〜9文字＋数字1つ＋シリーズ共通の背景色。タイトルと同じ文言を繰り返さない（補完関係）
- **検索KW**：企画時に2〜3語の学習意図KW（例「STP分析 やり方」「ペルソナ 作り方 ChatGPT」）を1つ決め、タイトル前方・概要欄冒頭2行・チャプター名に自然に入れる
- **A/B**：公開後はYouTube「テストして比較」でサムネ最大3種を検証（判定は総再生時間ベース、1〜2週間）

### 4.5 Shorts切り出し規則（各回3本）

- 本編の「リフック①」「ミニ問いかけ」「まとめの1アクション」から各1本（45〜60秒）
- 冒頭3秒に本編と同じビジュアルアンカー。「続きは長編で」の橋渡しで終える
- タイトルはKW型（例「ペルソナの作り方で9割がやる失敗」）

## 6. 計測と改善ループ

1. 公開48時間後・7日後・28日後にCTR/維持率グラフを確認
2. 維持率グラフで「15秒以上の平坦→急落」地点を特定し、その区間の構成パターン（長い前置き・図なし説明・静止スライド）を特定→次回の禁止パターンに追加
3. サムネは「テストして比較」で3案回す（判定は総再生時間。1,000〜5,000インプ必要なので初期は最長2週間）
4. 学びは `.claude/skills/episode-production/retention-packaging.md` の「実測からの学び」節に追記していく（スキル＝生きた改善ログ）

## 9. チャンネル設定改革チェックリスト（YouTube Studio側・Phase 0）

対象チャンネル：`https://www.youtube.com/channel/UCZm9m37ivzDN0ZGvQAhBDpw`
※本作業環境からはyoutube.comへのアクセスが遮断されているため、以下は「あるべき設定」のチェックリスト。

### 10.1 チャンネル基本情報（Studio → カスタマイズ／設定）

- [ ] **ハンドル**：`@`ハンドルを検索KWを含む覚えやすいものに（例：`@ai_marketing_lab`）。チャンネルURLを配布物で使う場合はハンドルURLに統一
- [ ] **チャンネル名**：「AI時代のマーケティング・ラボ」は維持でよいが、検索対策として説明文の先頭に補助KWを置く（下記）
- [ ] **チャンネル説明文（概要）**：先頭2行に「誰の・何が・どうなるか」＋主要KW。例：「マーケティング初心者と小さな会社のための実践チャンネル。3C・STP・価格設定からAI活用まで、9分で1テーマを図解します。」以降に想定視聴者・更新頻度・実績/根拠・お問い合わせ
- [ ] **チャンネルキーワード**（設定→チャンネル→基本情報）：`マーケティング入門, マーケティング初心者, AI マーケティング, STP分析, 3C分析, ペルソナ, 価格設定, webマーケティング` 等10個前後
- [ ] **アイコン／バナー**：シリーズ共通色（#0B1220ベース）で統一。バナーに「毎週◯曜更新｜9分で1テーマ」など視聴習慣を作る一文
- [ ] **リンク**：関連SNS・サイトがあれば設定（無ければ空でよい。リンク切れだけは残さない）
- [ ] **対象視聴者**：「子ども向けではない」に設定（教育コンテンツでも誤って「子ども向け」にするとコメント・通知・おすすめが大幅制限される）

### 10.2 レイアウト（チャンネルトップ）

- [ ] **非登録者向けの動画スポットライト（チャンネル紹介動画）**：最も維持率の高い1本（リニューアル後はEP01）を設定
- [ ] **登録者向けのおすすめ動画**：最新のリニューアル回を設定
- [ ] **セクション構成**：①シリーズ再生リスト（入門編→AI活用編の順）②人気の動画 ③Shorts。空の「アップロード動画」だけのトップにしない

### 10.3 再生リスト（回遊の要）

- [ ] 講座全体の再生リストを作成し、**「公式シリーズとして設定」をON**（視聴中に同リストの他動画が優先サジェストされる公式機能）
- [ ] リスト名は講座名でなくベネフィット型（例：「ゼロから学ぶ売れる仕組み【マーケ入門】」）
- [ ] 並び順は**リスト先頭＝最も維持率の高い回**（入口最適化）。以降は学習順
- [ ] 難易度別（入門/実践/AI活用）のサブリストも作成

### 10.4 アップロード時のデフォルト設定（設定→アップロード動画のデフォルト設定）

- [ ] **カテゴリ**：教育
- [ ] **言語**：日本語（動画の言語を明示すると検索・字幕処理が正確になる）
- [ ] **タグのデフォルト**：`マーケティング,マーケティング入門,AI` 等の共通タグ（タグの効果は小さいが表記ゆれ対策になる）
- [ ] **コメント**：許可（保留モデレーションON）。コメントは満足度シグナルの入力源
- [ ] **AI生成コンテンツの開示**：VOICEVOX音声は「改変または合成されたコンテンツ」の開示チェックを**動画ごとに正しく申告**（2024年以降必須化。未申告発覚はリスク）

### 10.5 動画単位で毎回やること（公開チェックリストに追加）

- [ ] **終了画面**：全動画共通テンプレ＝「次に見る動画（ベネフィットで選ぶ）」＋「シリーズ再生リスト」の2要素。最後20秒は静止構成（v2仕様S18）
- [ ] **カード**：本編中で言及した回へのカードを1〜2枚
- [ ] **字幕**：自動字幕を必ず開いて誤変換を修正（合成音声は認識精度が高いので修正は少量。検索インデックスにも効く）
- [ ] **タイトル・サムネA/B**：公開後「テストして比較」でサムネ3案（判定は総再生時間。初期は最長2週間）
- [ ] **チャプター**：description.mdのタイムスタンプを貼る（キーモーメント露出）
- [ ] **Shorts**：本編から3本切り出し、各Shortsに**「関連動画」リンクで本編を設定**（Shorts→長尺の公式導線）

### 10.6 運用リズム

- [ ] **公開曜日・時刻の固定**（例：土曜18時。ターゲットが視聴できる時間帯で固定し、バナーにも明記）
- [ ] リニューアル動画は**プレミア公開**より通常公開でよい（登録者が少ない段階ではプレミアの効果は薄い）
- [ ] 公開48時間後・7日後にCTR/維持率を記録（§6の改善ループ）
- [ ] 旧フォーマット動画（未リニューアル分）は削除せず**非公開化もしない**。リニューアル版公開時に旧版を差し替え（同URL再利用はできないため、旧版は説明欄にリニューアル版へのリンクを追記して放置。検索評価はリニューアル版に集める）
