## ディレクトリ構成

```
Marketing-learn-contents/
├── README.md                  # このファイル（全体ロードマップ）
├── _template/                 # 各エピソード共通テンプレート
│   ├── script.md              # 台本テンプレート
│   ├── description.md         # YouTube概要欄テンプレート
│   └── thumbnail.md           # サムネイル設計テンプレート
├── 01_beginner/               # 初級編（第1〜4回）
├── 02_intermediate/           # 中級編（第5〜8回）
├── 03_practical/              # 実践編（第9〜12回）
├── 04_ai-usage/               # AI活用編（第13〜16回）
├── 05_advanced/               # 上級編（第17〜20回）
└── 06_case-studies/           # 事例編（第21〜24回）
```

各エピソードフォルダには以下の3ファイルを格納します：

| ファイル | 用途 |
|----------|------|
| `script.md` | 撮影用台本（構成・セリフ・スライド指示） |
| `description.md` | YouTube概要欄テキスト（タイムスタンプ・リンク・ハッシュタグ） |
| `thumbnail.md` | サムネイル設計メモ（テキスト案・ビジュアル・カラー） |
