# Kit 設定・貼り付けシート（そのままコピペ用）

チャンネルURL・文言は差し込み済み。特典は**PDFをKitにアップロード**（option A）前提。
Kitの各画面で、下の「→ ここに貼る」をコピペする。

---

## STEP 2：Landing Page（Grow → Landing Pages & Forms → Create New → Landing Page）

**見出し（Headline）→ ここに貼る**
```
広告費をかけずに売上2.2倍。その「売れる仕組み」を、9分×全20話ぶん、1枚に。
```

**サブ見出し（Subheadline）→ ここに貼る**
```
「AI時代のマーケティング・ラボ」で解説した20テーマの要点を、実務ですぐ引けるチートシートにまとめました。メール登録した方に無料でお渡しします。
```

**本文（3点）→ ここに貼る**
```
・マーケティングの型（3C・STP・ペルソナ・価格・USP・CPA/LTV…）を1枚で見返せる
・AIを実務の相棒にするプロンプトの要点まで収録
・動画を見返す前の「地図」として、実務の「手順書」として使える
```

**ボタン文言（Button）→ ここに貼る**
```
無料でチートシートを受け取る
```

**フォーム下の一言 → ここに貼る**
```
登録は無料です。いつでも1クリックで解除できます。新作動画の要点や実務のヒントを、週に1回ほどお届けします。
```

→ **Publish** して、発行された **Landing Page の URL を控える**（STEP 5で私に渡す）

## STEP 3：Incentive email（Landing Page → Settings → Incentive）

- **Incentive email：ON**
- **特典ファイル**：「Add a file / Download」で **`marketing-lab-cheatsheet.pdf` をアップロード**
  （＝メール内の「こちらからどうぞ」ボタンがこのPDFのDLリンクになる）
- **Double opt-in（確認メール）：ON のまま**（確認＆納品を兼ねる）

**件名（Subject）→ ここに貼る**
```
【無料プレゼント】全20話の要点チートシートをお届けします
```

**本文（Body）→ ここに貼る**
```
ご登録ありがとうございます。
さっそく、お約束の「全話まとめ＆実践チートシート」をお渡しします。

▼ こちらからどうぞ（保存してお使いください）
※このボタン／リンクからPDFをダウンロードできます

—

このチートシートは、「AI時代のマーケティング・ラボ」で解説した
マーケティングの型20テーマ（3C・STP・ペルソナ・価格設計・USP・CPA/LTV、
そしてAI活用まで）の要点を、1枚で見返せるようにまとめたものです。

使い方はシンプルです。
1. 気になるテーマの「要点」を上から眺める
2. 1つだけ、明日の仕事で試す
3. 詰まったら、そのテーマの動画で深掘りする

—

このメールでは今後、週に1回ほど、
・新しい動画の要点（見る前に3分で分かるダイジェスト）
・実務で使えるマーケティングの小さなコツ
をお届けしていきます。

まずは、いちばん人気の第1回から見てみてください。
「良い商品が売れない理由の9割」を、実例でお話しています。
▶ https://www.youtube.com/channel/UCZm9m37ivzDN0ZGvQAhBDpw

それでは、また次のメールで。

AI時代のマーケティング・ラボ
```
