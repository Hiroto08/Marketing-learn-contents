## STEP 3：特典配布（実機確認済み・確定版）

**判明した仕様**：このKit UIには独立した「Incentiveタブ」は無い。特典配布は2つのどちらかで行う。

- **✅ 採用した方式＝Automationで配布**（実機で動作確認済み）：
  - Landing Page の **「Send confirmation email」はOFFのまま**（＝登録は即時・確認メール無し。
    Subscribers一覧にすぐ反映される。ダブルオプトインが無いのでフリーメール送信元の到達率問題も回避しやすい）
  - **Automate → Visual Automations → New Automation**
    - Trigger：「Subscribes to a form」→ このLanding Pageのフォームを選択
    - Action：「Send email」→ 本文エディタの「＋」ブロックから**Add file**で
      `marketing-lab-cheatsheet.pdf` を添付（無ければDrive等の共有リンクで代替）
    - 件名・本文は下記をそのまま貼る
  - この方式は**確認メールのON/OFF設定に依存しない**ため、以後この形で運用する
- （非採用）Landing Page の「Confirmation email」をONにして、その本文にダウンロードリンクを
  仕込む方式もあるが、確認メール自体がフリーメール送信元で迷惑メール判定されやすく、
  今回はこちらで詰まったため不採用

**件名（Subject）→ ここに貼る**
```
【無料プレゼント】全20話の要点チートシートをお届けします
```

**本文（Body）→ ここに貼る**
```
ご登録ありがとうございます。
さっそく、お約束の「全話まとめ＆実践チートシート」をお渡しします。

▼ こちらからどうぞ（保存してお使いください）
※このボタン／リンクからPDFをダウンロードできます

—

このチートシートは、「AI時代のマーケティング・ラボ」で解説した
マーケティングの型20テーマ（3C・STP・ペルソナ・価格設計・USP・CPA/LTV、
そしてAI活用まで）の要点を、1枚で見返せるようにまとめたものです。

使い方はシンプルです。
1. 気になるテーマの「要点」を上から眺める
2. 1つだけ、明日の仕事で試す
3. 詰まったら、そのテーマの動画で深掘りする

—

このメールでは今後、週に1回ほど、
・新しい動画の要点（見る前に3分で分かるダイジェスト）
・実務で使えるマーケティングの小さなコツ
をお届けしていきます。

まずは、いちばん人気の第1回から見てみてください。
「良い商品が売れない理由の9割」を、実例でお話しています。
▶ https://www.youtube.com/channel/UCZm9m37ivzDN0ZGvQAhBDpw

それでは、また次のメールで。

AI時代のマーケティング・ラボ
```
