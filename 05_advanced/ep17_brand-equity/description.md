## メイン説明文

```
ブランディングとは何かを、無印良品の実話1本で解説します。
広告を止めた瞬間に売上が消えるのは、蛇口（広告）しかなくて貯水池（ブランド）がないから。
ブランドの正体は、ロゴでも広告でもなく「お客さんとの約束を守り続けた蓄積」です。

1980年、無印良品は「印の無い、良い品」＝ブランドの否定を掲げて西友の40品目から誕生。
「わけあって、安い」と理由を正直に語り、「これがいい」の熱狂ではなく「これでいい」の理性的な満足を目指しました。
約束と一貫性の45年が、比較されずに指名される世界ブランド（世界30以上の国と地域）を作っています。

この動画で分かること：
✅ ブランド＝貯水池モデル（広告は注ぐ水、ブランドは貯まった水、指名は水位の目盛り）
✅ 3つの原則（貯水池で考える／約束を1つ守り続ける／やらないことを決める）
✅ 指名検索の価値——指名された瞬間、価格競争の土俵から降りられる

「広告と値引きをやめられない」「ブランディングがふわふわして分からない」個人事業主・小さな会社の担当者の方に特におすすめです。
明日やることは1つだけ——お店の約束を1行で書くこと（何の店で、何をしないか）。

※ナレーションはAI音声合成（VOICEVOX:玄野武宏）を使用しています。
```
