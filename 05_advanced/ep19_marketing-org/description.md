## メイン説明文

```
マーケティング組織の作り方を、P&Gの実話1本で解説します。
優秀な担当者を雇ったのに成果が出ない——多くの場合、犯人は人ではなく組織図（責任の線引き・数字・会議体）です。

1931年5月13日、P&Gの若手社員ニール・マッケロイは一通の社内メモを書きました。
提案は「ブランドマン」——1つのブランドに責任と権限を持つ専任の責任者を置くこと。
このメモから生まれたブランドマネジメント制は、90年以上たった今も世界中の組織の標準です（HBS/HBR資料より）。

この動画で分かること：
✅ マーケが機能しない組織の正体——「人の問題」ではなく「責任の線引きの問題」
✅ 機能する組織の3原則（責任と権限をセットで1人に／数字を1つにそろえる／会議を決める場に変える）
✅ 小さな会社への実装法（紙1枚の責任表＋週1回30分の「決める会議」）

「マーケ担当を置いたのに成果が出ない」「会議ばかりで決まらない」経営者・個人事業主・小さな会社の担当者の方に特におすすめです。
明日やることは1つだけ——紙1枚に商品を並べて、それぞれの売上責任者の名前を書くこと。

※ナレーションはAI音声合成（VOICEVOX:玄野武宏）を使用しています。
```
