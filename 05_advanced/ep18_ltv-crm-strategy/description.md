## メイン説明文

```
CRMとは何かを、ネスカフェ アンバサダーの実話1本でわかりやすく解説します。
新規のお客さんの獲得には、既存のお客さんの維持の5倍のコストがかかる——それなのに多くの会社は、利益の源泉である「売れた後」を設計せず、新規集客だけを追い続けています。

2012年、ネスレ日本はコーヒーマシンをオフィスに無料で貸し出す「ネスカフェ アンバサダー」を開始。
機械では儲けず、1杯約20円の継続購入で回収するモデルで、28万人のアンバサダーとの長期的な関係を築きました（各種報道・公式資料より）。
この実話から、LTV（顧客生涯価値）を伸ばす3つの原則を取り出します。

この動画で分かること：
✅ CRM（顧客関係管理）の本質——ツールではなく「売れた後に利益を置く」方針
✅ LTVを伸ばす3原則（生涯の合計で見る／続ける理由を設計する／顧客を覚える）
✅ 顧客台帳の作り方と「続ける理由」の実装例（美容室・飲食店・通販の具体例つき）

「新規集客に追われて利益が残らない」「リピーター施策が思いつかない」個人事業主・小さな会社の担当者の方に特におすすめです。
明日やることは1つだけ——常連のお客さんを10人書き出して、1人に感謝の連絡をすること。

※ナレーションはAI音声合成（VOICEVOX:玄野武宏）を使用しています。
```
