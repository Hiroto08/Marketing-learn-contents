## メイン説明文

```
週1回の役員会議のために、社員は1年で30万時間を使っていた——ベイン・アンド・カンパニーが大企業17社を調べて見つけた数字です。会議そのものは7,000時間だけ。残りは、その会議のための「準備の会議」でした。
会議はなぜ下へ下へと増えるのか。会議を実際に減らした Shopify とアマゾンは何をしたのか。約4分で解き明かします。

✅ 30万時間の内訳（上の1時間＝下の約43時間）
✅ Shopify：3人以上の定例会議を一斉削除（約1万2000件・年32万時間の見込み）
✅ アマゾン：スライドの代わりに6ページの文章、会議の最初は全員で黙読
✅ 自分の職場で、定例会議1つの「本当の時間」を数える方法

「売れる仕組みの裏側」は、買い物・職場・SNSの「なんで？」の犯人を、実在の事例と数字で種明かしするシリーズです。Shortsは毎日18時、ケースファイル（本編）は毎週土曜18時に公開。

※ナレーションはAI音声合成（VOICEVOX:玄野武宏）を使用しています。
```
