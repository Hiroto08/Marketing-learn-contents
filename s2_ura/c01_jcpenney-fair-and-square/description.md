# YouTube概要欄テキスト — CASE FILE #01：セールをやめたら売上25%減。JCペニーの値下げはなぜ失敗した？【価格の心理】

---

## メイン説明文

```
セールをやめて、毎日安くした。それなのに、売上は1年で25%減った——アメリカの百貨店JCペニーで、2012年に本当に起きたことです。
値段は下がったのに、なぜ客は離れたのか。答えは「客が買っていたのは、服ではなく『得した気分』だった」から。アンカリング（値段は比べる相手で決まる）と取引効用（人はお得感にもお金を払う）の2つで、約4分で解き明かします。

✅ 590回のセールを全部やめた「フェア・アンド・スクエア」で何が起きたか（売上−25%・赤字9.85億ドル）
✅ 同じ値段でも「3割引き」の方がうれしい理由（ルーレット実験・浜辺のビール）
✅ 自分の値下げで、元の値段を正しく見せるコツ（景品表示法の二重価格の目安つき）

「売れる仕組みの裏側」は、買い物・職場・SNSの「なんで？」の犯人を、実在の事例と数字で種明かしするシリーズです。Shortsは毎日18時、ケースファイル（本編）は毎週土曜18時に公開。

※ナレーションはAI音声合成（VOICEVOX:玄野武宏）を使用しています。
```
