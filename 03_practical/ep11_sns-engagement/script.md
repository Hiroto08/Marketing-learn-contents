### スライド 3：エンゲージメント率の定義と計算式（1:20〜2:10）

**スライド内容：**
```
【見出し】エンゲージメント率とは何か

【定義】
  投稿に対して「何らかの行動を起こした人の割合」

【計算式】
  エンゲージメント率（%）=
  （いいね ＋ コメント ＋ シェア ＋ 保存）÷ リーチ数 × 100

  ※リーチ数＝その投稿を見た人の数

【例】
  リーチ数：1,000人
  いいね：45　コメント：8　シェア：3　保存：12
  → (45+8+3+12) ÷ 1,000 × 100 ＝ 6.8%

【業種別ベンチマーク（Sprout Social「Social Media Benchmarks」）】

  業種               Instagram   Twitter/X   Facebook
  ────────────────────────────────────────────────────
  飲食・カフェ        3.0〜5.0%    0.5〜1.0%   0.5〜1.5%
  小売・EC            1.0〜2.0%    0.3〜0.8%   0.3〜0.8%
  BtoBサービス        0.5〜1.5%    0.2〜0.5%   0.2〜0.5%
  教育・コーチング    2.0〜4.0%    0.5〜1.0%   0.5〜1.5%
  ────────────────────────────────────────────────────
  全業種の目安：1%以上が「良好」／3%以上が「優秀」
```

**アニメーション：** 計算式のパーツが順に組み上がる → 例の数字が電卓のように計算されて結果表示 → 業種別表が1行ずつ出現

**ナレーション：**
「エンゲージメント率の計算式は、いいね・コメント・シェア・保存の合計をリーチ数で割って100をかけたものです。リーチ数とは投稿を見た人の数で、フォロワー数とは異なります。たとえばリーチ1,000人・合計アクション68件なら6.8%。Sprout Socialのベンチマークによると、全業種で1%以上が良好、3%以上が優秀な水準です。まず自分のアカウントの直近10投稿を計算して、この基準のどこに位置するか確認するところから始めましょう。」

### スライド 6：GaryVeeの「Jab / Jab / Jab / Right Hook」理論（3:50〜4:40）

**スライド内容：**
```
【見出し】なぜ「売り込みばかり」のアカウントは反応ゼロになるのか

【Gary Vaynerchuk 『Jab, Jab, Jab, Right Hook』（2013）】

  Jab（ジャブ）= 価値提供
    → 役立つ情報・共感できるストーリー・楽しめるコンテンツ
    → フォロワーの時間・注意・信頼を「貯める」

  Right Hook（ライトフック）= 売り込み
    → 商品紹介・セール告知・申し込み誘導
    → 貯めた信頼を「使う」

【公式】
  Jab : Right Hook ＝ 3 : 1（最低でも）

【売り込みばかりのアカウントで起きること】
  ① フォロワーが「また広告か」と感じてスクロールを飛ばす
  ② エンゲージメントが下がり、アルゴリズム評価が落ちる
  ③ リーチが下がり、売り込みすら届かなくなる
  ④ 結果：フォロワーがいても反応ゼロ

【現実の成功比率（目安）】
  教育・共感・エンタメ投稿：70〜80%
  商品・サービス告知：20〜30%
```

**アニメーション：** ボクシングのジャブとフックのアイコンが登場 → 公式3:1が大きく表示 → 失敗の悪循環が①〜④の矢印フローで展開

**ナレーション：**
「SNSの投稿が「商品紹介」「セール告知」「お知らせ」ばかりになっていませんか。マーケター・起業家のゲーリー・ヴェイナーチャクは2013年の著書で「Jab, Jab, Jab, Right Hook」理論を提唱しました。ジャブとは価値提供——役立つ情報や共感できるストーリーです。ライトフックとは売り込みです。少なくとも3回のジャブを打ってから1回の売り込みをしろ、というのが本質です。売り込みばかりのアカウントはフォロワーがスクロールを飛ばし、エンゲージメントが下がり、リーチが落ちます。売り込みすら届かない状態に自ら落ち込む悪循環です。70〜80%を価値提供に使うことで、残りの20〜30%の告知が初めて効きます。」

### スライド 8：コメントを生む「問いかけ」の技術（5:30〜6:20）

**スライド内容：**
```

【CTAなし vs CTAあり】
  × CTAなし：「今日のランチはパスタでした」
  ○ CTAあり：「今日のランチはパスタでした。
              あなたが最近食べた一番美味しいものは何ですか？
              コメントで教えてください！」

【コメント率を高めるCTAの型 7選】

  ① 二択質問：「あなたはA派？B派？」
  ② 経験を聞く：「〇〇を経験したことがある方はコメントで▲をください」
  ③ 意見を求める：「これについてどう思いますか？」
  ④ 共感確認：「同じ経験をした方はいますか？」
  ⑤ 数字で答えさせる：「あなたは何年やっていますか？数字で教えて！」

【効果の目安】

「エンゲージメントの中でも「コメント」はアルゴリズム評価が特に高い行動です。コメントを増やす最強の手法が、投稿末尾のCTA（行動喚起）設計です。「今日のランチはパスタでした」で終わる投稿と、「あなたが最近食べた一番美味しいものは？コメントで教えてください」で終わる投稿では、コメント率が2〜5倍変わります。特に効果的な型は二択質問・経験を聞く・数字で答えさせる、の3つです。回答のハードルが低いほど参加者が増えます。重要なのは、CTAを「毎回つける」ことを習慣にすることです。ゼロから1へのハードルが最も高い。毎投稿に一言添えるだけで数字は大きく変わります。」

     目安：10〜30%（プラットフォームと投稿タイプで変動）
     意味：アルゴリズムが積極的に配信しているかどうか
     → リーチ率が下がっている投稿タイプを見直す

  ③ プロフィールアクセス率（プロフアクセス数 ÷ リーチ数 × 100）
     目安：2%以上が良好
     意味：「この人が誰か知りたい」という温度感
     → 高いほど「フォロワー候補」を引きつけている投稿

【分析の手順】

  STEP 1：直近10〜30投稿のデータをスプレッドシートに転記する
  STEP 2：保存率・リーチ率・プロフィールアクセス率の上位3投稿を特定
  STEP 3：上位投稿に共通する「テーマ・型・CTA・投稿時間」を抽出
  STEP 4：次月の投稿計画にその要素を意図的に組み込む

【重要な視点】
  → 感覚で「良い投稿」を判断するのではなく
    データで「何が刺さっているか」を発見する習慣をつける
```

**アニメーション：** 3指標が優先順位のランキング形式でビルドアップ → 分析STEPが矢印フローで展開 → 「データで発見する」が強調

**ナレーション：**
「投稿を改善し続けるためには、データを読む習慣が欠かせません。最も重視すべき指標は3つ。第1位は保存率。「あとで見返したい」コンテンツの証明で、アルゴリズム評価が最も高い。第2位はリーチ率。フォロワー数に対してどれだけ届いているかを見ます。低下しているなら投稿タイプの見直しサインです。第3位はプロフィールアクセス率。これが高い投稿は「この人をもっと知りたい」という感情を生んでいる、つまり新規フォロワー獲得に近い投稿です。直近30投稿のデータをスプレッドシートに書き出し、上位3投稿の共通点を探す——これを月1回やるだけで、投稿の精度は着実に上がっていきます。」

## 制作メモ

- **想定ナレーション文字数：** 約3,200字（10分目安 300字/分×10分・±10%許容）
- **スライド3の計算式：** 「リーチ数」と「インプレッション数」の違いを初出時に字幕補助で説明する（リーチ＝ユニークユーザー数、インプレッション＝表示回数）
- **スライド4のアルゴリズム図：** 配信が段階的に広がるイメージを「波紋」アニメーションで表現すると視覚的にわかりやすい
- **スライド6のJab/RightHook：** ボクシングのアイコンをユーモラスに使うと記憶に残りやすい。著作物への言及はタイトル・著者名・出版年を明示する
- **スライド7の投稿頻度：** プラットフォームのアルゴリズムは頻繁に更新されるため「目安」として表記し、公式情報を確認するよう添え書きを入れる
- **スライド9の比較表：** ストーリーズ・リール・ライブを縦3列で並べ、各行を色分けすると視認性が上がる（ストーリーズ＝オレンジ・リール＝紫・ライブ＝赤など）
- **スライド11の事例：** 地方カフェの事例は架空のモデルケースとして明示すること。ただし数値・施策・手順はリアリティのある現実的な設定に基づく
- **テロップ：** エンゲージメント・リーチ・インプレッション・CTA・カルーセル・リール・インサイト・UGC・アルゴリズムなどの専門用語は初出時に必ず字幕補助
- **スライド10の分析ステップ：** Googleスプレッドシートのテンプレート（直近30投稿の指標を記録するシート）を動画概要欄にダウンロードリンクとして用意すると視聴者の実践率が上がる
- **BGM：** シリーズ統一（Lo-Fiインスト）
- **前後回との接続：** スライド1のナレーションで第10回コピーライティングとの接続を示す。スライド13で「ABテスト」への橋渡しとして「今日設計したCTAを次回の手法でテストする」という流れを意識させる
- **サムネイル候補：** 「フォロワー1万人＜フォロワー500人」の比較図を使ったビジュアルは高CTR（クリック率）が期待できる。視聴者の「え？なぜ？」という反応を誘う設計
