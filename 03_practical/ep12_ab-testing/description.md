# YouTube概要欄テキスト — 第12回：その改善、気のせいかもしれません【ABテスト】

---

## メイン説明文

```
ABテストのやり方を、メルカリの検証文化の実話で解説します。
施策のあとに売上が上がっても、それが施策のおかげとは限りません。連休・天気・競合——前後比較では、どれが効いたのか誰にも分からないからです。

日本最大級のフリマアプリ・メルカリは、勘で決めない仕組みを文化にしました。
アプリ改善のほとんどでABテストを使い、常時50本前後の実験が並行。実験設計書を書いてから始め、判定基準は会社の公式ルール。
「効いた気がする」で議論しない会社の作法は、小さなお店でも0円で真似できます。

この動画で分かること：
✅ 前後比較がアテにならない理由と、同時比較（ABテスト）の考え方
✅ 3つの原則——同時に比べる／1回に変えるのは1つ／偶然と区別する（AとAで比べる小技も）
✅ お金をかけない小さなABテストの3手順（メール件名・チラシ2種から）

「施策の効果を体感で判断している」「売上が動いた理由を説明できない」個人事業主・小さな会社の担当者の方に特におすすめです。
明日やることは1つだけ——次の施策の前に「何の数字が、どれだけ動いたら成功か」を1行書くこと。

※ナレーションはAI音声合成（VOICEVOX:玄野武宏）を使用しています。
```
