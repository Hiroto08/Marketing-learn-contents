## 制作メモ

- **想定ナレーション文字数：** 約3,365字（9分目安 約375字/分×9分）
- **18枚化の方針：** 旧13枚構成から内容を保持したまま再分割。スライド2（フック）→2・3、スライド3（定義+Fisher）→4・5、スライド5（サンプルサイズ+p値）→7・8、スライド6（早期終了）→9・10、スライド11（実践例）→15・16 の5か所を2枚に分割し、1スライド1コンセプトの原則に揃えた
- **スライド5の Fisher 解説：** 「農業科学から来ている」という話はウェブマーケ感度の高い視聴者に響く。教養として面白く語れるポイント
- **スライド7〜8のサンプルサイズ計算：** Evan Miller の Sample Size Calculator（https://www.evanmiller.org/ab-testing/sample-size.html）を動画概要欄にリンクとして掲載推奨
- **スライド9の早期終了グラフ：** A・Bの逆転が起きる折れ線グラフ（SVG）は実際のアニメーションを使うと視覚的インパクトが強い。ダミーデータで作成済み
- **スライド13のツール情報：** Google Optimize が2023年に終了している事実は必ず言及する。古い情報のまま参照している視聴者が多いため、アップデートとして価値がある
- **スライド15〜16の事例：** 架空のハンドメイドECとして明示すること。数字は統計的に整合性のあるダミーデータとして構成している
- **スライド17の実験文化：** 「失敗」→「仮説の棄却」という言い換えは、中小企業オーナーへの感情的な刺さりポイント。ここでのトーンは励ましを意識する
- **スライド18の修了演出：** 実践編の締めくくりとして感情的な盛り上がりを作る。BGMを一時的に明るくするなどの演出を推奨
- **テロップ：** ABテスト・CVR・p値・統計的有意差・フォールスポジティブ・リフト率・信頼区間・サンプルサイズ・コントロール群・バリアントなどの専門用語は初出時に必ず字幕補助。p値は特に「難しそう」と感じさせないよう「偶然の確率」と平易に換言する
- **BGM：** シリーズ統一（Lo-Fiインスト）。スライド18はやや明るめのトラックへ切り替えを検討
- **次回との接続：** 実践編が「仮説→検証→改善」のサイクルで締まることを強調し、上級編の「AI + データ」テーマへの橋渡しとして機能させる
- **概要欄掲載推奨リンク：**
  - Evan Miller Sample Size Calculator
  - GA4 公式ドキュメント（コンバージョン設定）
  - Optimizely 公式 A/B Testing Guide
  - Fisher 『The Design of Experiments』紹介ページ（Amazon等）
