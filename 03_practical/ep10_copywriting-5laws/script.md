### スライド 5：法則②——意識レベルに合わせる（Schwartz）——問題を認識していない人から知っている人でコピーは変わる（3:00〜3:50）

**スライド内容：**
```
【法則②】意識レベルに合わせる
（Eugene Schwartz 『Breakthrough Advertising』1966）

【Schwartzの5段階意識レベル】

  レベル5【Most Aware（最も意識が高い）】
    あなたの商品を知っていて、購入も検討している
    → コピー：「今すぐ申し込む」「期間限定〇〇円」

  レベル4【Product Aware（商品認知）】
    あなたの商品を知っているが、まだ買っていない
    → コピー：商品の優位性・他社との違いを強調

  レベル3【Solution Aware（解決策認知）】
    解決策があることは知っているが、あなたを知らない
    → コピー：あなたがどの解決策を提供するかを示す

  レベル2【Problem Aware（問題認知）】
    問題は感じているが、解決策を知らない
    → コピー：問題に共感し、解決策があることを示す

  レベル1【Unaware（未認知）】
    問題すら気づいていない
    → コピー：潜在的な問題・欲求を先に言語化して気づかせる

【NG例】
  レベル1の人に「今すぐ購入」と言っても反応ゼロ
  → 意識レベルのミスマッチがコピーの失敗原因の多くを占める
```

**アニメーション：** ピラミッド型の5段階図が下から順にビルドアップ → 各レベルのコピー指針が右に出現 → NG例がフェードイン

**ナレーション：**
「法則2つ目は、意識レベルに合わせること。これはコピーの天才、ユージン・シュワルツが1966年の著書で提唱した考え方です。同じ商品でも、読み手の「今いる段階」によって、使うべきコピーはまったく変わります。問題にすら気づいていないレベル1の人に「今すぐ購入」と送っても、反応はゼロです。一方でレベル5の「もう買う気満々」の人に長々と問題提起をしても読み飛ばされます。SNS広告はレベル1〜2に届きやすく、リスティング広告はレベル3〜4の人が集まる場です。この「意識レベルのミスマッチ」が、コピーの反応が悪い最大の原因の一つです。まず読み手が今どのレベルにいるかを設定してからコピーを書く習慣をつけましょう。」

### スライド 6：法則③——スリッパリースロープ（Sugarman）——1行目の目的は2行目を読ませること（3:50〜4:40）

**スライド内容：**
```
【法則③】スリッパリースロープ（滑り台理論）
（Joseph Sugarman 『The Adweek Copywriting Handbook』2007）

【Sugarmanの核心理論】
  「1行目の唯一の目的は、2行目を読ませること」
  「2行目の唯一の目的は、3行目を読ませること」
  → コピーは「読み続けさせる滑り台」

【滑り台を作る3つの技術】

  ① 短い文・リズム
     長文を避け、一文を短く。テンポよく読める流れを作る
     例：「これを読んで、後悔した人はいません。理由はシンプルです。」

  ② 小さなYESを積み重ねる
     読み手が「そうそう、その通り」と頷ける文を先に置く
     例：「毎朝、何を着るか迷いますよね。クローゼットは服でいっぱいなのに。」

  ③ 好奇心を刺激して次へ引く（オープンループ）
     答えを少し先に引き延ばす
     例：「その秘密は、実は3つ目の法則にあります。」

【NG構造（滑り台が止まるコピー）】
  × 1段落目に長い自社紹介
  × 専門用語・業界語の多用
  × 「弊社は〜です」から始まるLP
```

**アニメーション：** スリッパリースロープの滑り台イメージ図が出現 → 3技術が1つずつビルドアップ → NG構造が×マーク付きで表示

**ナレーション：**
「法則3つ目は、スリッパリースロープ。コピーライターのジョセフ・シュガーマンが提唱した「滑り台理論」です。1行目の目的は商品を売ることでも、会社を説明することでもありません。2行目を読ませることだけ、です。コピーは読まれ続けることで初めて機能します。そのために有効なのが3つの技術です。1つ目は短い文とリズム。長文は読み手の脳の負担になります。2つ目は小さなYESの積み重ね。読み手が「そうそう」と頷ける共感の文を冒頭に置くことで、心理的に前のめりにさせます。3つ目は好奇心を刺激して次へ引くこと。答えを少しだけ後にずらすと、人は続きを読みたくなります。LPやメルマガの冒頭を「弊社は〜です」から始めている場合、これは今日変えるべき箇所の筆頭です。」

### スライド 7：法則④——社会的証明・権威・希少性（Cialdini）——人間の心理バイアスを活用する（4:40〜5:30）

**スライド内容：**
```
【法則④】社会的証明・権威・希少性
（Robert Cialdini 『Influence: The Psychology of Persuasion』1984）

【Cialdiniの影響力の6原則のうち、コピーに最も効く3つ】

  ① 社会的証明（Social Proof）
     「他の人も選んでいる」という安心感
     コピー例：
     「累計12,000人が選んだ」
     「★4.8（1,240件のレビュー）」
     「利用者の92%が3週間で実感」
     → 数字・件数・割合が信頼を生む

  ② 権威（Authority）
     「信頼できる専門家・機関が認めている」という安心感
     コピー例：
     「医師・栄養士監修」
     「〇〇大学研究チームが採用」
     「業界10年のプロが選ぶ」

  ③ 希少性（Scarcity）
     「手に入りにくいもの」への欲求増大
     コピー例：
     「残り3席」「先着50名限定」
     「この価格でご提供できるのは今月末まで」

【注意：希少性は本物に限る】
  嘘の「残り3席」は信頼を崩す。実際の制約を使うこと

【組み合わせると最強】
  「医師監修・1,200件★4.8・今月末で受付終了」
  → 権威 × 社会的証明 × 希少性の三重構造
```

**アニメーション：** Cialdiniの本の表紙イメージが出現 → 3原則がカード型で1枚ずつスライドイン → コピー例が各カードに追加 → 組み合わせ例が最後に強調表示

**ナレーション：**
「法則4つ目は、社会的証明・権威・希少性。これは社会心理学者ロバート・チャルディーニが1984年に体系化した「影響力の原則」から、コピーに最も効く3つです。社会的証明は「他の人も選んでいる」という安心感で、累計人数・レビュー数・満足率の数字がその代表です。権威は「専門家が認めている」という信頼感で、医師監修・研究機関の採用実績などが使えます。希少性は「手に入りにくい」という状況が欲求を高める心理です。「残り3席」「今月末まで」という言葉は、購買の先延ばしを防ぎます。ただし希少性だけは注意が必要で、嘘の「残り3席」を使い続けると信頼が崩れます。実際の制約のみに使ってください。この3つを1つのコピーに組み合わせると、反応率は飛躍的に変わります。」

### スライド 8：法則⑤——具体的な数字を使う——「効果的」より「3週間で-5kg」「CVR2.3倍」（5:30〜6:20）

**スライド内容：**
```
【法則⑤】具体的な数字を使う

【なぜ数字が効くのか】
  Ogilvy：「数字は読まれる。なぜなら、具体的だから」
  → 曖昧な言葉は流れるが、数字は目に止まる
  → 数字があると「証明された感」が生まれる

【Before（数字なし）→ After（数字あり）比較】

  × 「素早く効果が出る」
  ✓ 「最短3日で効果を実感（利用者の78%）」

  × 「多くの方に選ばれています」
  ✓ 「6,200社・12万ユーザーが導入」

  × 「大幅に改善できます」
  ✓ 「広告費を変えずにCVRが2.3倍になった事例」

  × 「痩せやすい体質に」
  ✓ 「3週間で平均-4.8kg（個人差あり）」

  × 「短時間で作業が完了」
  ✓ 「1日30分の作業が7分になった」

【数字を使う際の3原則】
  ① できるだけ具体的な数字を使う（「約〇〇」より「〇〇」）
  ② 根拠を添える（「利用者調査」「〇〇人のデータ」）
  ③ キリのよい数字より奇数・端数が信頼される
     （「3倍」より「2.8倍」の方が実測感がある）
```

**アニメーション：** Ogilvyの引用がフェードイン → Before/Afterの比較が×→✓の形で1行ずつ出現（×が赤、✓が緑） → 3原則がビルドアップ

**ナレーション：**
「法則5つ目は、具体的な数字を使うことです。オグルヴィは「数字は読まれる。なぜなら具体的だからだ」と言いました。「短時間で完了」という言葉は脳内を素通りします。しかし「30分の作業が7分になった」は目に止まります。数字には「証明された感」があり、読み手に「本当のことが書いてある」という信頼感を与えます。重要な追加ポイントが1つあります。「3倍」より「2.8倍」の方が信頼される、という事実です。キリがよすぎる数字は盛った印象を与えますが、端数や奇数は実測値のように見えます。数字を使う際は必ず根拠を添え、「利用者調査」「〇〇人のデータより」と記載してください。Before/Afterを数字で示すだけで、コピーの説得力は大きく変わります。」

## 制作メモ

- **想定ナレーション文字数：** 約3,200字（10分目安 300字/分×10分・±10%許容）

- **BGM：** シリーズ統一のLo-Fiインスト。スライド9（NG vs OK比較）では一瞬BGMをフェードダウンさせ、対比の強調効果を演出するとよい

- **法則名の常時表示：**
  スライド4〜8では画面左上または下部に「法則①〜⑤」の番号と名称を常にテロップ表示する（例：「法則① ベネフィットファースト」）。視聴者が途中から見ても、今どの法則の説明かが即わかる設計にする

- **スライド5の意識レベル図解：**
  5段階ピラミッドはレベルが上がるほど人数が絞られる逆三角形で表現すると「未認知の人が大多数」「認知済みは少数」という市場感が直感的に伝わる。各レベルに対応する広告媒体（SNS広告＝レベル1〜2、リスティング＝レベル3〜5）を小文字で付記するとより実践的

- **スライド6のスリッパリースロープ：**
  「滑り台」のビジュアルアニメーションで文章が流れ落ちていくイメージを使うと理論が直感的に伝わる。実際のコピー例をアニメーション内でスクロールさせると、読む体験を疑似的に演出できる

- **スライド9のNG vs OK比較：**
  左右2カラム構成。NGは薄いグレー背景・小さいフォント、OKは白背景・強調カラーで視覚的に差をつける。最後にNG→OKの変換ポイントを矢印で5法則と対応させると復習効果が高い

- **スライド10のA/Bテスト解説：**
  「変える要素は1つだけ」のルールをアニメーションで視覚化する（例：2つの変数を変えると交差点が生まれて原因特定不能になる図）。実際のA/Bテストツール（Googleオプティマイズ・Optimizely・Facebook広告マネージャーのA/Bテスト機能など）を補足テロップで紹介するとよい

- **テロップ：** CTR・CVR・CPA・LTV・CTA・A/Bテスト・LP（ランディングページ）・UGC・IMC・D2C・スリッパリースロープ・ベネフィット などの専門用語は初出時に必ず字幕補助。法則名（ベネフィットファースト/スリッパリースロープ）は英語表記も併記する

- **引用文献のテロップ処理：**
  各著者・書籍名は該当スライドのナレーション開始時に2〜3秒テロップ表示する（例：「Ogilvy on Advertising（1983）」）。著作権上、書影の直接使用は避け、書名テキストのみ表示を推奨

- **実践ワークシートの提案：**
  動画説明欄にPDFワークシートを配布すると視聴完了率・コメント率の向上に繋がる。ワークシートに含めるべき項目：
  1. 5法則チェックリスト（自社コピーに各法則が使われているか確認表）
  2. 特徴→ベネフィット変換シート（「だから、あなたは〇〇できる」の穴埋め）
  3. 意識レベル別コピー設計シート（レベル1〜5のターゲット設定と対応コピー例）
  4. NG→OK書き直し練習シート（自社コピーのBefore/After記入欄）
  5. A/Bテスト記録シート（変更箇所・テスト期間・CTR/CVR比較欄）

- **前後エピソードとの接続：**
  冒頭でEp.9（CPA・LTV）との橋渡しを1〜2文入れる（「CPAを下げるのに最も効果的な方法の1つがコピーの改善」）。エンディングではEp.11（SNSエンゲージメント）で今日のコピー法則を活用することを予告し、視聴継続率を維持する

- **コメント促進フレーズの提案：**
  エンディング付近で「あなたの会社のコピーでBeforeとAfterを試してみた結果をコメントで教えてください」と呼びかけると、エンゲージメント率向上とUGC（視聴者体験の蓄積）につながる
