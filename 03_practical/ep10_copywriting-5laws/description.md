## メイン説明文

```
コピーライティングのコツを、ジャパネットたかた創業者・高田明さんの実話1本で解説します。
同じ商品を同じ値段で売っても、売れる人と売れない人がいる。違いは文章のセンスではなく「語る対象」——売れない人は商品を語り、売れる人はその商品がある暮らしを語ります。

1990年、商品が見えないラジオ通販に挑んだ高田さんは、スペックの説明を捨てて聞き手の生活の場面を語り、
佐世保の小さなカメラ店を年商1500億円超の通販企業に育てました（高田氏の著書より）。
その話法は、5つの法則のチェックリストに分解できます。

この動画で分かること：
✅ 売れるコピーの正体——「商品を語る」から「暮らしを語る」への転換
✅ コピーライティング5つの法則（相手を1人に決める／スペックを暮らしに翻訳／数字は体感に換算／次の一行を読ませる／行動の一言で終える）
✅ 自社の商品紹介文の「1行目」を書き換える具体的な手順（Before→After例つき）

「広告文やチラシを書いても反応が薄い」「商品説明が自慢の羅列になってしまう」個人事業主・小さな会社の担当者の方に特におすすめです。
明日やることは1つだけ——商品紹介文の1行目を、お客さん1人の暮らしの場面に書き換えること。

※ナレーションはAI音声合成（VOICEVOX:玄野武宏）を使用しています。
```
