### スライド 3：CPA（Cost Per Acquisition）の定義と計算式（1:20〜2:10）

**スライド内容：**
```
【見出し】CPA（Cost Per Acquisition）とは

定義：
「1件の成果（顧客獲得・購入・申込）を得るために
　かかった広告費」

【計算式】
　CPA ＝ 広告費 ÷ 獲得件数

　例：広告費50,000円 ÷ 獲得5件 ＝ CPA 10,000円

【業種別のCPA目安（参考：Neil Patel / 業界ベンチマーク）】
　EC（物販）    ：1,000〜5,000円
　SaaS・IT     ：5,000〜30,000円
　不動産・保険  ：20,000〜100,000円以上
　士業・コンサル：10,000〜50,000円

【「CPAが低いほど良い」という誤解】
　× CPAが低い ＝ 良い顧客を獲得している　…ではない
　◎ CPAはLTVとセットで評価する
　　「1万円のCPAでも、LTVが5万円なら優秀な投資」
```

**アニメーション：** 定義・計算式がフェードイン → 業種別CPAが表形式でスライドイン → 「誤解」が×→◎の対比で出現

**ナレーション：**
「まずCPAを正確に定義しましょう。CPA（Cost Per Acquisition）は「1件の成果を得るためにかかった広告費」です。計算式はシンプルで、広告費を獲得件数で割るだけです。
業種によって適切なCPAは大きく異なります。ECなら数千円、SaaSなら数万円、不動産・保険では10万円を超えることもあります。だから「CPAが高い＝悪い」とは言い切れません。
最大の誤解は「CPAが低いほど良い」という思い込みです。CPAはあくまでも入口の数字。その後の顧客の購買行動、つまりLTVとセットで初めて正しく評価できます。」

### スライド 4：LTV（Life Time Value）の定義と計算式（2:10〜3:00）

**スライド内容：**
```
【見出し】LTV（Life Time Value）とは

定義：
「1人の顧客が取引を続ける期間に、
　企業にもたらす利益の合計」
　── Philip Kotler 『マーケティング・マネジメント』

【基本計算式】
　LTV ＝ 平均購入単価 × 購入頻度（年） × 継続期間（年）

【具体例で計算】
　平均購入単価：5,000円
　購入頻度：月2回（年24回）
　継続期間：2年

　LTV ＝ 5,000円 × 24回 × 2年 ＝ 240,000円

【LTVが高い顧客 vs 低い顧客】
　高い顧客：定期購入・高単価・長期継続・紹介を生む
　低い顧客：1回購入・低単価・短期離脱・クレームが多い

【利益ベースのLTV（発展）】
　LTV（利益）＝ 平均購入単価 × 粗利率 × 購入頻度 × 継続期間
```

**アニメーション：** 定義がフェードイン → 計算式の3要素が順にビルドアップ → 具体例の計算が数字のカウントアニメーション → 高/低顧客の対比が左右に出現

**ナレーション：**
「次にLTV（Life Time Value：顧客生涯価値）を理解しましょう。コトラーは著書の中で「顧客は取引の積み重ねによって企業に累積的な価値をもたらす」と述べています。
基本の計算式は「平均購入単価×購入頻度×継続期間」の3つの掛け算です。例えば1回5,000円の商品を月2回、2年間買い続けてくれる顧客のLTVは24万円になります。CPA1万円でこの顧客を獲得できたなら、非常に優秀な投資です。
LTVが高い顧客は定期購入・高単価・長期継続・口コミ紹介という特徴を持ちます。逆に低い顧客は1回きりの購入で離脱します。どちらのタイプを獲得しているかが、広告の本当の評価を左右します。」

### スライド 5：LTV÷CPAの黄金比率（3:00〜3:50）

**スライド内容：**
```
【見出し】LTV÷CPA——広告投資の判断基準

【黄金比率】
　LTV ÷ CPA ＞ 3 が「健全」の目安

【比率別の状態】

　LTV/CPA ＞ 3
　　✅ 健全：広告投資を増やす余地あり

　LTV/CPA ＝ 1〜3
　　⚠️ 要注意：利益が薄い・改善が必要

　LTV/CPA ＜ 1
　　❌ 危険：広告費が顧客価値を上回っている
　　　　　　→ 続けると事業が成立しない

【図解：天秤】
　左皿：CPA（広告コスト）
　右皿：LTV（顧客がもたらす価値）
　→ 右が3倍以上重いとき、健全な投資

【なぜ「3倍」か】
　CPA以外にも
　・商品原価・製造コスト
　・人件費・運営費
　・カスタマーサポートコスト
　などがかかるため、LTVがCPAの3倍以上ないと
　広告費を除いた全コストをカバーできない
```

**アニメーション：** 黄金比率「3」が大きく中央に表示 → 3段階の状態が✅⚠️❌カラーで順に出現 → 天秤のアニメーション（バランス崩れ→3倍で安定）→ 「なぜ3倍か」の説明が右に展開

**ナレーション：**
「CPAとLTVの関係を、シンプルな指標で判断できます。それが「LTV÷CPA」の比率です。業界のベンチマークでは、この比率が3以上であれば健全な広告投資とされています。
比率が3を超えていれば、広告費を増やす余地があります。1〜3の間は利益が薄く改善が必要です。1を下回ると広告費が顧客価値を上回り、かければかけるほど赤字になります。
なぜ3倍が目安かというと、広告費の他にも商品原価・人件費・運営費・サポートコストがかかるからです。LTVがCPAの3倍以上なければ、他のコストを全て賄えません。この比率を経営のダッシュボードに加えてください。」

### スライド 6：LTVを上げる3つのレバー（3:50〜4:40）

**スライド内容：**
```
【見出し】LTVを上げる3つのレバー

LTV ＝ 平均購入単価 × 購入頻度 × 継続期間
         ↑レバー①     ↑レバー②   ↑レバー③

【レバー① 平均単価を上げる】
　手法：アップセル・クロスセル
　アップセル  ：上位プラン・高単価商品への誘導
　　　例：月額3,000円プランから5,000円プランへ
　クロスセル  ：関連商品の同時購入を促す
　　　例：シャンプー購入者にトリートメントを推奨
　目標：単価10〜30%向上でLTVは比例して向上

【レバー② 購入頻度を上げる】
　手法：リテンション施策
　・定期購入（サブスク）への移行促進
　・リピート特典・ポイントプログラム
　・パーソナライズされたリマインドメール
　目標：購入頻度が1.5倍になれば LTVも1.5倍

【レバー③ 継続期間を延ばす】
　手法：解約防止・サポート強化
　・オンボーディングの充実（初期体験の質を上げる）
　・解約検討者への能動的なフォロー
　・コミュニティ・会員組織による帰属意識の醸成
　目標：継続期間が2年→3年になれば LTVは1.5倍
```

**アニメーション：** LTV計算式が表示 → 各レバーが矢印でハイライト → レバー①②③がカードとして順にスライドイン（各カードに手法リスト付き）

**ナレーション：**
「LTVを上げる方法は、計算式の3つの変数に直接働きかけることです。レバーは3つあります。
第一は平均単価を上げること。上位プランへ誘導するアップセルと、関連商品を追加購入してもらうクロスセルが主な手法です。単価が10%上がればLTVも10%上がります。
第二は購入頻度を上げること。定期購入への移行やリピート特典が有効です。頻度が1.5倍になればLTVも1.5倍です。
第三は継続期間を延ばすこと。初期体験の質を上げて定着を促し、解約検討者を早期に発見してフォローすることが鍵です。この3つを同時に少しずつ改善するだけで、LTVは複利的に伸びていきます。」

### スライド 7：CPAを下げる3つのアプローチ（4:40〜5:30）

**スライド内容：**
```
【見出し】CPAを下げる3つのアプローチ

CPA ＝ 広告費 ÷ 獲得件数
　↓CPAを下げる ＝ 同じ広告費でより多く獲得する

【アプローチ① クリエイティブ改善（CTR向上）】
　CTR（クリック率）が上がる → 同じ予算で多くの流入
　改善施策：
　・コピー・見出しを複数パターンでA/Bテスト
　・ビジュアル（動画 vs 静止画）の検証
　・ターゲットに刺さる「痛み」や「理想の未来」を訴求
　目安：CTRが1% → 2%に改善 → CPAは約50%改善

【アプローチ② ランディングページ最適化（CVR向上）】
　CVR（転換率）が上がる → 同じ流入でより多く獲得
　改善施策：
　・ファーストビューに「誰向け・何が解決するか」を明示
　・社会的証明（口コミ・実績・メディア掲載）を追加
　・入力フォームのステップ数・フィールド数を削減
　目安：CVR1% → 2%に改善 → CPAは半分に

【アプローチ③ ターゲティング精度向上（無駄な配信を減らす）】
　LTVが低い顧客層への配信を絞り込む
　改善施策：
　・過去の購入データをもとにLTV高顧客の共通属性を抽出
　・類似オーディエンス（Lookalike）の活用
　・時間帯・デバイス・地域別のビッド最適化
```

**アニメーション：** CPA計算式が表示 → 3アプローチがタブ形式で順に展開（各タブに改善施策と目安）→ 「CTR2倍→CPA半分」の数字が強調アニメーション

**ナレーション：**
「LTVを上げる一方で、CPAを下げる努力も並行して必要です。アプローチは3つあります。
第一にクリエイティブ改善です。広告のクリック率（CTR）を上げると、同じ予算でより多くの訪問者を獲得できます。コピーや画像をA/Bテストしてみましょう。CTRが1%から2%に改善するだけで、CPAは約半分になります。
第二にランディングページの最適化です。訪問者が実際に申し込むCVR（転換率）を上げることがCPA直接改善につながります。フォームの入力項目を1つ減らすだけでも転換率が変わります。
第三にターゲティング精度の向上です。LTVが低い顧客層への無駄な配信を絞り込み、LTV高顧客に似た属性（類似オーディエンス）に集中します。」

### スライド 8：リテンション率の威力——Bain & Companyの研究（5:30〜6:20）

**スライド内容：**
```
【見出し】リテンション率の威力
（Frederick Reichheld & Bain & Company 研究）

【衝撃のデータ】
　顧客維持率（リテンション率）を
　わずか5%改善するだけで
　利益は25〜95%増加する

　── Bain & Company研究 /
　　 Reichheld 『The Loyalty Effect』（1996）

【なぜこれほど利益が増えるのか：メカニズム】

  ① 新規獲得コストがゼロ
     既存顧客の維持コストは新規獲得コストの
     約1/5〜1/7（5〜7倍の差）

  ② 購入単価が上がる
     継続顧客は信頼から高価格帯商品も購入しやすい

  ③ 紹介・口コミが生まれる
     リピーターは友人・知人に紹介する確率が高い
     → 紹介獲得のCPAは実質ゼロ

  ④ オペレーションコストが下がる
     既存顧客への対応は習熟により効率化する

【図解：バケツの穴のモデル】
　新規獲得（水を注ぐ）→ 解約（穴から漏れる）
　→ 穴を塞ぐ（リテンション改善）ほうが
　　 水を注ぎ続ける（新規獲得）より効率的
```

**アニメーション：** 「5%改善→利益25〜95%増」が大きく中央にアニメーション → 4つのメカニズムが順にビルドアップ → バケツの穴モデルが最後に図解として出現

**ナレーション：**
「ここで衝撃的な研究データを紹介します。フレデリック・ライクヘルドとベイン・アンド・カンパニーの研究によれば、顧客維持率をわずか5%改善するだけで、利益は25〜95%増加するとされています。
なぜこれほど大きな差が生まれるのか。理由は4つあります。まず新規獲得コストがかからない。既存顧客の維持コストは新規獲得の5〜7分の1です。次に継続顧客は単価が上がりやすい。そして口コミ紹介を生むためCPAがゼロの顧客獲得が起きます。さらにオペレーションが習熟して効率化します。
バケツに水を注ぎ続けるより、まず穴を塞ぐ。新規広告を増やす前に、既存顧客の離脱を止めることが最も費用対効果の高い施策です。」

## 制作メモ

- **想定ナレーション文字数：** 約3,200字（10分目安 300字/分×10分・±10%許容）

- **前エピソードとの接続：** スライド1のナレーションで「第8回まで戦略論（STP・4P・USP）を扱ってきた。今回から実践編として『数字で判断するマーケティング』に入る」と明示することで、シリーズの流れとティアの切り替えを視聴者に伝える

- **スライド5の黄金比率「3」：** SaaS業界では「LTV:CAC = 3:1」は定番指標。EC・実店舗では業種による幅があるため、「目安」と注釈を加えること。スライドの図解は天秤アニメーションが直感的で分かりやすい

- **スライド9のコホート表：** 実際の数字は架空データとして明示する。動画説明欄にコホート分析テンプレート（Googleスプレッドシート）のリンクを貼ると実践促進効果が高い

- **スライド10の事例：** A社は架空のECサイトとして明示すること。ただし計算式は実際のビジネスモデルを反映したリアルな数値設定にしてある

- **テロップ（略語初出時に字幕補助）：**
  - CPA（Cost Per Acquisition：顧客獲得単価）— S2で初出
  - LTV（Life Time Value：顧客生涯価値）— S2で初出
  - CTR（Click Through Rate：クリック率）— S7で初出
  - CVR（Conversion Rate：転換率）— S7で初出
  - コホート（Cohort：同期グループ）— S9で初出
  - リテンション率（継続率・顧客維持率）— S8で初出

- **BGM：** シリーズ統一（Lo-Fiインスト）。実践編スタートなので、やや tempo が速いトラックに変えて「気持ちの切り替え」を演出する選択肢も検討

- **数式の表示：** スライド3・4・5の計算式は数字を動的にカウントアップさせると視覚的に印象が残る（Aftereffects / Motion等で実装可能）

- **次回エピソードとの接続：** スライド7でCPAを下げるためのクリエイティブ改善（CTR向上）に触れた流れで、「では具体的にどんなコピーが人を動かすのか」という問いを立てると第10回への自然な導線になる

- **実践ワークシートの提案（動画説明欄）：**
  1. **LTV計算シート** — 平均単価・頻度・継続期間を入力すればLTVと LTV/CPA比率が自動計算されるGoogleスプレッドシートテンプレート
  2. **チャネル別CPA管理表** — 広告チャネル（リスティング・SNS・SEO・紹介）ごとにCPA・LTV・比率を記録するダッシュボード
  3. **月次コホート残存率表** — 獲得月×経過月のマトリクスで残存率を色分けするヒートマップ形式のテンプレート

- **コメント促進用の問いかけ（動画末尾でナレーターが読み上げ）：**「あなたの会社のLTV/CPA比率はいくつですか？まだ計算したことがない方は、ぜひコメント欄で教えてください。一緒に考えましょう！」
