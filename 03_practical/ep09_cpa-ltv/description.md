## メイン説明文

```
CPAとLTVの計算と使いかたを、やずやの実話1本で解説します。
「広告はうまくいっているのに、お金が残らない」本当の原因は、広告費を入り口の数字（CPA）だけで判断していることです。

1990年に1億円をかけて顧客データベースを導入し、お客さんの「寿命」を測りはじめたやずやは、
新規客を初回で儲ける相手ではなく「これから育つ客」として扱い、12年で売上100倍（西野博道氏の著書より）。
広告費の物差しは、入り口ではなく生涯——LTV≧CPA×3です。

この動画で分かること：
✅ CPA（顧客獲得単価）とLTV（顧客生涯価値）の計算式と使いかた
✅ 「初回赤字でいい」が成立する理由と、LTV≧CPA×3の物差し
✅ 自社の広告費上限を自分で計算する3つの数字（利益・回数・年数）

「広告をいくらまでかけていいか毎回カン頼み」の個人事業主・小さな会社の担当者の方に特におすすめです。
明日やることは1つだけ——今月の売上を「新規」と「2回目以上」の2列に分けること。

※ナレーションはAI音声合成（VOICEVOX:玄野武宏）を使用しています。
```
