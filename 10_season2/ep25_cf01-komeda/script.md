【一言】お客さんのコーヒー代ではなく、お店の仕入れ代

**ナレーション：**

### スライド 5：証拠③——使用料は「席数×定額」（1:51〜2:17）

**スライド内容：**
```
【キッカー】EVIDENCE 03｜使用料の決め方
【見出し】使用料は「席数×定額」

【問い】本部と加盟店、それぞれ何を一番望む？
```

**ナレーション：**
「証拠の3つ目は、加盟店が本部に払う使用料の決め方です。フランチャイズの使用料は、売上の何パーセント、という決め方がよく知られています。ところがコメダは、席の数に比例した定額制です。売上が増えても、本部に払う金額は変わりません。では、ここで考えてみてください。この決め方だと、本部と加盟店は、それぞれ何を一番望むでしょうか。」

### スライド 6：種明かし——稼ぐのは「回転」ではなく「回数」（2:17〜2:44）

**スライド内容：**
```
【キッカー】THE TRICK
【見出し】稼ぐのは「回転」ではなく「回数」
【お金の流れ図】お客さん →（コーヒー代）→ 加盟店 →（豆・パンの仕入れ＋定額の使用料）→ 本部
【バナー】長居はコストではなく、また来る理由への投資
```

**ナレーション：**
「答えは、どちらも同じです。お客さんに、何度も来てもらうこと。加盟店にとっては、売上が増えるほど、自分の収入が増えます。本部にとっては、お客さんが来るたびに、コーヒー豆とパンが減り、それが次の卸売になります。つまりコメダは、1杯あたりの回転ではなく、お客さんが来る回数で稼ぐ仕組みなのです。長居は、コストではありません。もう一度来たくなる理由への、投資です。」

### スライド 8：型——稼ぎ方は2つ。決めると我慢が決まる（3:27〜4:06）

**スライド内容：**
```
【キッカー】THE PATTERN
【見出し】稼ぎ方を決めると、我慢が決まる
【比較2列】回転型（1回の来店でどれだけ回すか／長居＝損）／来店頻度型（同じ客が何回来るか／長居＝また来る理由）
【補足】頻度型＝LTV（1人の客の長い付き合いの売上）を伸ばす商売
【一言】コメダは頻度型を選んだから、長居を歓迎できる
```

**ナレーション：**
「ここまでを、1つの型にまとめます。商売には、大きく2つの稼ぎ方があります。1つは、1回の来店で、どれだけ回すかで稼ぐ、回転型。もう1つは、同じお客さんが、何回来るかで稼ぐ、来店頻度型です。来店頻度型は、1人のお客さんが、長い付き合いの中で落としてくれるお金、つまりLTVを伸ばす商売です。どちらが正しい、という話ではありません。大事なのは、自分がどちらで稼ぐかを決めると、何を我慢してよいかが決まることです。コメダは来店頻度型を選んだから、長居を我慢するのではなく、歓迎できるのです。」

## 制作メモ

- 主ループ：S1「なぜ長居されても困らない？」→ S3〜S5 の3つの証拠 → S6 で回収（回数で稼ぐ）。S5 の問い（本部と加盟店は何を望む？）は S6 冒頭で即回収
- 数字はすべて有価証券報告書（2026年2月期）で確認済み。「約75%」＝国内事業の卸売38,490百万円÷国内事業売上51,374百万円（74.9%）。「約514億円」「約385億円」は百万円単位の四捨五入
- 1席あたりの使用料の金額は二次情報しか無いため使わない（「席数比例の定額制」という公式の表現だけを使う）
- 回転率で稼ぐ他チェーンを悪く言わない（型の違いとして比べる。特定の他社名を出さない）
- S9 の美容室・学習塾は一般的な例示（実在企業の数字ではない）
