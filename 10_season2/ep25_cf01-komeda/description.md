## メイン説明文

```
コメダ珈琲が儲かる理由を、有価証券報告書の数字だけで解き明かします。
長居されても困らない喫茶店——その答えは「お客さんではなく、加盟店から稼ぐ」仕組みにありました。

コメダの国内事業の売上は約514億円。そのうち約385億円、約75%は、加盟店へのコーヒー豆やパンなどの「卸売」です。
国内のコメダ珈琲店1,030店のうち、本部の直営はわずか22店。加盟店が本部に払う使用料は、売上ではなく「席の数に比例した定額制」。
だから本部も加盟店も、1杯あたりの回転ではなく、お客さんが「何回来るか」で稼ぐ形になっています（数字はすべてコメダホールディングス 有価証券報告書 2026年2月期より）。

この動画で分かること：
✅ コメダの売上の入り口（卸売・直営店・使用料）
✅ 長居を「コスト」ではなく「また来る理由への投資」にできる仕組み
✅ 稼ぎ方の2つの型（回転型／来店頻度型）と、あなたの商売への当てはめ方

明日やることは1つだけ——自分の売上の入り口を3つ書き出し、それぞれが「人数・回数・金額」のどれに比例して増えるかを書くこと。

「売れる仕組みの裏側」は、身近な会社・商品の「なぜ？」を、決算資料などの一次情報とマーケティングの型で解くシリーズです。
型を基礎から学びたい方は、教科書シリーズ「マーケティング入門講座 全24話」もどうぞ。

※ナレーションはAI音声合成（VOICEVOX:玄野武宏）を使用しています。
```
