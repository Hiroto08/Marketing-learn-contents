# Shorts台本（3本）— 第23回：失敗事例に学ぶ、良い商品が売れない3つの理由

shorts-production.md 準拠（v2）。各15〜25秒・5スライド・縦型1080x1920。
冒頭0〜3秒に本編と同じビジュアルアンカー（91日／確定被害807人／3つの死因）、1本1論点、
オチで冒頭を再文脈化（ナラティブ+ビジュアルループ）、送客は口頭＋テロップで関連動画リンク（下の長編リンク）誘導。
公開時は各Shortsの「関連動画」に本編を設定する。ナレーションはVOICEVOX読みルール準拠。

## 切り出し候補（5案から3本に絞る）

1. **採用①** 「91日で消えた」＋ペイペイとの生存対比（本編S1・S2・S7素材）——Before/Afterならぬ「生死」の非対称性が最も強いcuriosity gap
2. **採用②** 3つの死因チェックリスト（本編S13素材）——自社にそのまま持ち帰れる自己診断。yt-analystの実測知見（§7）で「保存したくなるチェック形式」が上位傾向のため優先
3. **採用③** 明日やること1つ（本編S17素材）——まとめの1アクションで完結する行動喚起
4. 不採用：会見で二段階認証に答えられなかった社長のエピソード（本編S5素材）——単体で切り出すと個人への揶揄が強調され「企業を貶めるトーンにしない」注意点に抵触するリスクがあるため見送り（本編内では構造の指摘として文脈込みで扱う）
5. 不採用：大塚家具の教訓（本編S15素材）——本編でも1回のみの補強事例であり、単独Short化すると主役（7pay）から離れすぎるため見送り
