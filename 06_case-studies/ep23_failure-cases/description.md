## メイン説明文

```
マーケティングの失敗事例から、良い商品なのに売れない理由を1本の実話で解説します。
資金も技術も看板もあった決済サービスが、なぜたった91日で消えたのか——原因は商品ではありません。

2019年、セブン&アイ・ホールディングスが送り出したスマホ決済「7pay（セブンペイ）」は、
全国2万店超のセブンイレブンで使える鳴り物入りのサービスでした。ところが開始2日目に不正利用が発覚し、
確定被害807人・約3860万円を出して、開始からわずか91日で廃止に追い込まれます。

この動画で分かること：
✅ 「良い商品なのに売れない」に共通する3つの死因（土台・矢面・期限）
✅ 同時期に同じ不正利用トラブルに見舞われながら生き残ったペイペイとの決定的な違い
✅ 自社のプロジェクトをその場で診断できる「3つの死因チェックリスト」

「良い商品・良いサービスを作った自信はあるのに、なぜか評価されない」と感じている
個人事業主・新規事業担当者・企画担当者の方に特におすすめです。
明日やることは1つだけ——「この期限は、誰の都合で決まっているか」を紙に書き出すこと。

※ナレーションはAI音声合成（VOICEVOX:玄野武宏）を使用しています。
```
