# YouTube概要欄テキスト — 第6回：原価率60%でも儲かる価格設定の心理学

---

## メイン説明文

```
価格設定の心理学を、原価率60%超で行列を作った実在の店「俺のイタリアン／俺のフレンチ」の実話で解説します。
値下げしても売れない本当の理由は、価格の数字ではなく「基準・選択肢・理由」が設計されていないことです。

ブックオフ創業者・坂本孝氏が70歳を過ぎて仕掛けた「俺の」シリーズは、ミシュラン級の料理人の皿を
高級店のおよそ3分の1の価格で提供。原価率60%超という"常識の2倍"の数字でも、立ち飲み×1日3回転以上という
構造で黒字化し、予約の取れない行列店になりました。儲けの場所を「ひと皿の利ざや」から「回転数」へ
動かした、価格設計の教科書のような実例です。

この動画で分かること：
✅ 原価率60%の店が儲かるカラクリ（価格・原価・儲けどころを1つの設計図にする）
✅ 価格心理の4原則——アンカリング／価値の天秤（知覚価値）／松竹梅とおとり効果（アリエリーのエコノミスト実験）／価格＝品質シグナル（ワイン実験）
✅ 自社の価格表を3か所書き換える手順（基準を自分で用意する・選択肢を3段にする・理由を語る）

値付けに悩む個人事業主・小さな会社の担当者・EC運営者の方に特におすすめです。
明日やることは1つだけ——価格表に「比べる基準」を1つ書き足すこと。

※ナレーションはAI音声合成（VOICEVOX:玄野武宏）を使用しています。
```
