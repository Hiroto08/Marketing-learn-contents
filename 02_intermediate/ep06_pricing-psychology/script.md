### スライド 6：チャーム価格・端数価格——「980円」が「1,000円」より売れる心理（3:50〜4:30）

**スライド内容：**
```
【見出し】③ チャーム価格・端数価格

【定義】
　1,000円ではなく980円、
　10,000円ではなく9,800円——
　「端数価格（チャーム価格）」のこと

【なぜ効くのか】
　→ 人間は数字を「左から読む」
　→ 980円 → まず「9」を認識 → 「900円台」と感じる
　→ 1,000円と実際の差は20円なのに「かなり安い」印象

【研究知見】
　・端数価格は「計算された価格」という印象を与える
　　（値引きがギリギリまで抑えられた誠実な価格感）
　・整数価格は「品質・プレミアム感」を想起させる
　　（高級品・ギフトには整数価格が有効なことも）

【使い分け】
　端数価格（980円・4,980円）
　　→ 日用品・ECサイト・価格競争が激しい市場
　整数価格（1,000円・5,000円）
　　→ 高級品・ブランド品・贈答品・サービス業
```

**アニメーション：** 980円 vs 1,000円の比較 → 「左から読む」の視線誘導アニメーション → 使い分け表が出現

**ナレーション：**
「3つ目はチャーム価格、端数価格の心理です。なぜ1,000円でなく980円に設定するのか改めて考えてみましょう。
人間の脳は数字を左から読みます。980円を見た瞬間にまず「9」を認識し、「900円台」として処理します。1,000円との差はわずか20円なのに、心理的には「明らかに安い」と感じるのです。
ただし万能ではありません。端数価格は「誠実に値引きした価格」という印象を与えますが、高級ブランドや贈答品では安っぽく見えることがあります。1万円の腕時計と9,800円の腕時計を並べると、後者のプレミアム感が損なわれます。
スーパーやECの日用品には端数価格、高級品やブランド品には整数価格——商品のポジショニングに合わせた使い分けが重要です。」

### スライド 7：損失回避バイアス——「得をする」より「損をしない」が行動を動かす（4:30〜5:20）

**スライド内容：**
```
【見出し】④ 損失回避バイアス
（Kahneman & Tversky "Prospect Theory" Econometrica, 1979）

【定義】
　「人間は同じ金額の『利益』より『損失』を
　　約2倍大きく感じる」
　（ノーベル経済学賞受賞の研究）

【実験：どちらを選ぶ？】
　選択肢A：確実に1,000円もらえる
　選択肢B：50%の確率で2,000円もらえる（期待値は同じ）
　→ 多くの人がAを選ぶ（損失を避けようとする）

【価格表現への応用】
　❌「今なら2,000円お得！」（利得フレーム）
　✅「今日申し込まないと2,000円損します」（損失フレーム）

【具体例】
　・「残り3席！」「今だけ送料無料」
　　→ 機会損失を意識させる
　・期間限定・数量限定の価格表示
　　→「終わったら損をする」という動機づけ
　・サブスクの「解約しないと〇〇がなくなる」通知
```

**アニメーション：** 実験の2択がアニメーション → 2倍の感じ方グラフ → 利得/損失フレームの比較 → 具体例がビルドアップ

**ナレーション：**
「4つ目は損失回避バイアスです。ノーベル経済学賞を受賞したカーネマン教授とトベルスキー教授が発表したプロスペクト理論の核心で、人間は「得」と「損」を同じ重みで感じません。損失の痛みは利益の喜びの約2倍大きく感じるとされています。
これを価格表現に活かすと、「今なら2,000円お得！」という利得フレームより、「今日申し込まないと2,000円損します」という損失フレームの方が行動を促す力が強くなります。
「残り3席」「本日23時59分まで」「今だけ送料無料」——これらはすべて機会損失を意識させる表現です。ただし乱用は信頼を損ないます。本当に限定性がある場合にのみ使うことが長期的な信頼構築に不可欠です。」

### スライド 8：価格バンドリング——まとめ買いで「割安感」を演出する（5:20〜6:10）

**スライド内容：**
```
【見出し】⑤ 価格バンドリング
（Raghubir & Srivastava, Journal of Consumer Research, 2002）

【定義】
　複数の商品・サービスをセットにして
　「まとめ買いがお得」と感じさせる価格設定

【バンドリングの種類】
　純粋バンドリング：セット販売のみ（単品不可）
　混合バンドリング：単品でも買えるが、セットがお得

【具体例】
　単品購入：
　　マーケティング講座 基礎編：5,000円
　　マーケティング講座 中級編：5,000円
　　　　計：10,000円
　
　セット購入：
　　基礎編＋中級編 セット：7,800円（22%OFF）
　
　→ 個別購入より安い → まとめて買った方がトクという知覚

【バンドリングが有効な理由】
　・個別価格のアンカリング効果でセット価格がお得に見える
　・価格の「比較コスト」が下がり判断が簡単になる
　・1回の購入単価（客単価）を上げられる
```

**アニメーション：** 単品vs.セットの価格比較がアニメーション → 差額がハイライト → 有効な理由が1行ずつ出現

**ナレーション：**
「5つ目は価格バンドリングです。ラグービルとスリバスタバの2002年の研究でも示されているように、セット価格は顧客の割安感の知覚を大きく変えます。
原理はシンプルで、まず単品価格を見せてアンカーを作り、セット価格と比較させることで「まとめた方が得」という判断を引き出します。
例えば「基礎編5,000円・中級編5,000円」と見せてから「セットで7,800円（22%OFF）」と提示すると、「2,200円お得！」というアンカリング効果が働きます。
バンドリングには単品販売しない「純粋バンドリング」と、単品でも買えるがセットがお得な「混合バンドリング」があります。多くの場合、混合バンドリングの方が購入の入口が広く、客単価を上げやすくお勧めです。」

### スライド 9：フレーミング効果——同じ価格でも「表現」次第でお得感が変わる（6:10〜7:00）

**スライド内容：**
```
【見出し】⑥ フレーミング効果
（Thaler & Sunstein『Nudge』2008）

【定義】
　同じ内容でも、表現（フレーム）の違いで
　受け取る印象が大きく変わる効果

【価格表現のフレーム例】

　年間コスト：36,000円 → 大きく見える
　　　　　　　月額3,000円 → 小さく見える
　　　　　　　1日あたり100円 → 「コーヒー1杯より安い」

　効果的な言い換え例：
　　❌「年間36,000円の投資が必要です」
　　✅「1日わずか100円で、プロ品質のツールが使えます」

【その他のフレーミング技法】
　・「初期費用無料」（月額に折り込む）
　・「〇〇円相当の特典付き」（価値の見える化）
　・「上位XX%だけが受けられるプレミアム体験」
　　（希少性フレーム）
　・「今すぐ始めると〇〇日分無料」
　　（損失回避×フレーミングの組み合わせ）
```

**アニメーション：** 36,000円→月額→1日あたりのスケール変換アニメーション → ❌→✅の書き換え → その他のフレーミングがビルドアップ

**ナレーション：**
「6つ目はフレーミング効果です。セイラーとサンスティーンも指摘しているように、同じ金額でも「どう表現するか」で全く違う印象を与えます。
年間36,000円という価格を月額3,000円と言い換えると小さく感じる。さらに「1日あたりわずか100円」と表現すると「コーヒー1杯より安い」という身近な比較になります。同じ36,000円なのに、表現ひとつで「高い」から「安い」への逆転が起きるのです。
SaaSやサブスクリプションで月額・日額表示が一般的なのはこのためです。また「初期費用0円」の文字を大きくして月額を小さく表示する、特典の価値を「〇〇円相当」と金額換算して見せるなど、視覚的なフレームも購買判断に影響します。」

### スライド 10：プレミアム価格戦略——あえて高くすることで「品質」を演出する（7:00〜7:50）

**スライド内容：**
```
【見出し】ボーナス：プレミアム価格戦略
（Cialdini『Influence』1984 ——権威・希少性と価格知覚）

【逆説：高い価格が売上を増やすことがある】

　「安いから売れる」は普通の発想
　「高いから売れる」という逆の現象がある

【ヴェブレン財（Veblen goods）とは】
　価格が上がるほど需要も増える特殊な財
　（高級ブランド品・ラグジュアリー体験など）

【事例：ワインの価格実験】
　・同一ワインを「5ドル」と「45ドル」で提示
　→ 45ドルと知ったグループの方が
　　「おいしい」と評価
　→ 価格が品質情報として機能している

【プレミアム価格が有効な条件】
　✅ ブランドの一貫したストーリーがある
　✅ 比較されない独自のポジションを持っている
```
