その外側が実体製品（品質・デザイン・機能）、さらに外側が拡張製品（保証・サポート・コミュニティ）です。現代では拡張製品が差別化の主な戦場になっています。
Appleで言えば、iPhoneのコアは「繋がる・表現できる・ステータス」。AppleCareやApp Storeは拡張製品です。コアから設計を始めるのが正しい順序です。」

### スライド 5：Price（価格）：コスト積み上げ vs 価値ベース vs 競合ベースの3アプローチ（3:00〜3:50）

**スライド内容：**
```
【見出し】Price（価格）——3つのアプローチ

【比較表】

アプローチ       | 考え方                    | 特徴・注意点
─────────────────────────────────────────────────────
① コスト積み上げ  | 原価 + 利益率 = 価格      | 簡単・市場無視リスクあり
② 価値ベース     | 顧客が感じる価値 = 価格    | 高マージン可・価値の説明が必要
③ 競合ベース     | 競合の価格を基準に設定     | 安全・差別化できない

【推奨アプローチ：価値ベース】
　・「いくらで作れるか」ではなく「いくらの価値があるか」が出発点
　・ユニクロ：品質と手頃さの価値提供 → SPAで原価を下げて価値ベース価格を実現

【価格と他のPとの整合】
　高品質製品 × 低価格 → ブランド毀損リスク
　高価格    × 大量流通 → 価値訴求のミスマッチ
```

**アニメーション：** 3行の比較表が1行ずつ出現 → 価値ベースがハイライト → 整合の注意がフェードイン

**ナレーション：**
「2つ目のPはPrice、価格です。アプローチは3つ——コスト積み上げ・競合ベース・価値ベースです。
コスト積み上げは計算が簡単ですが需要を無視するリスクがあります。競合ベースは差別化できません。最もおすすめは価値ベース——「顧客にとっていくらの価値があるか」から出発します。ユニクロはSPAで原価を抑え「この品質でこの価格」という価値ベースの訴求を実現しています。
注意点として、価格は他の3Pと整合しなければなりません。高品質の製品を極端に低価格で売ると顧客は品質を疑います。価格はそれ自体が品質のシグナルです。」

### スライド 8：4Cへのシフト：Lauterborn（1990）が提唱した顧客目線の再解釈（5:30〜6:30）

**スライド内容：**
```
【見出し】4Cへのシフト——顧客目線で4Pを読み替える

【背景】
  ラウターボーン（1990年、*Advertising Age* 誌）が提唱
  "New Marketing Litany: 4Ps Passe; C-Words Take Over"

  「企業が売りたいものを売るのではなく、
   顧客が買いたいものを売れ」

【4Pの限界】
  ・企業（売り手）の視点で設計されている
  ・顧客の実感・ニーズが後回しになりやすい
  ・「Product を作ったから売る」という発想を生む

【4Cの4つのC】

  Product  →  Customer Solution（顧客ソリューション）
              「製品の仕様ではなく、顧客の問題を解くか」

  Price    →  Cost to the Customer（顧客コスト）
              「金銭的コストだけでなく、時間・手間・心理的コストも含む」

  Place    →  Convenience（利便性）
              「入手しやすいか・使いやすいか」

  Promotion →  Communication（コミュニケーション）
              「一方的な広告ではなく双方向の対話」
```

**アニメーション：** ラウターボーンの引用がフェードイン → 4Pが左列に出現 → 右列に4Cが矢印で対応しながら順にスライドイン

**ナレーション：**
「4Pを理解したうえで、4Cへのシフトを学びましょう。
1990年、ラウターボーンがアドバタイジング・エイジ誌で「4Pはもう古い。C-ワードに置き換えよ」と提唱しました。4Pは「企業視点」で設計されており、顧客の実感が後回しになりやすいという限界があります。
4Cでは4Pを顧客視点で読み替えます。ProductはCustomer Solution、PriceはCost to the Customer、PlaceはConvenience、PromotionはCommunicationです。
4Pで骨格を作り、4Cで顧客視点をチェックする——これが現代マーケティング設計の基本です。」

### スライド 10：4Pの整合性：製品・価格・流通・プロモーションが一貫しているか（7:10〜8:00）

**スライド内容：**
```
【見出し】4Pの整合性チェック——一貫性が成果を生む

【整合性の原則】
  4つのPはそれぞれが「同じターゲット・同じ価値提案」を向いていなければならない

【整合チェックリスト】

  Product × Price
  　→ 製品の品質・希少性と価格帯は一致しているか
  　例：ハイエンド素材を使った製品を「980円」で売っていないか

  Product × Place
  　→ 製品のブランドポジションとチャネルは合っているか
  　例：ラグジュアリーブランドが量販店に並んでいないか

  Product × Promotion
  　→ 製品の本当の強みと訴求内容は一致しているか
  　例：「環境にやさしい」訴求をしながら過剰包装していないか

  Price × Promotion
  　→ 価格訴求（安さ）とブランド訴求（高品質）が矛盾していないか

【ユニクロの整合例】
  Product：シンプルで機能的な高品質ベーシックウェア
  Price  ：SPA製造で実現した価値ベース価格（高品質×手頃）
  Place  ：大型路面店・モール・EC（利便性と視認性）
  Promotion：「LifeWear」コンセプトで一貫したブランド発信
  → 4つが一貫して「良いものを、誰もが、手軽に」を体現
```

**アニメーション：** チェックリストが1項目ずつ出現 → ユニクロ例が4P対応で下に展開 → 「一貫して体現」が強調

**ナレーション：**
「4Pの4要素は同じ価値提案を指し示す必要があります。これが整合性です。
確認すべき組み合わせは4つ。製品と価格——品質と価格帯は釣り合っているか。製品と流通——ブランドポジションとチャネルは合っているか。製品とプロモーション——本当の強みを訴求しているか。価格とプロモーション——安さと品質訴求が矛盾していないか。
ユニクロは4Pが見事に整合しています。製品は高品質ベーシック、価格はSPAで実現した手頃さ、流通は大型店とECで利便性確保、プロモーションは「LifeWear」で一貫したブランド発信。4つすべてが「良いものを誰もが手軽に」を体現しています。」

### スライド 11：実践例：あるD2Cブランドの4P設計と4Cの視点での改善（8:00〜8:50）

**スライド内容：**
```
【見出し】実践例：あるD2Cスキンケアブランドの4P設計

【当初の4P設計】

  Price    ：原価率40%で算出した4,800円（コスト積み上げ）
  Place    ：自社ECサイトのみ
  Promotion：Instagram広告・インフルエンサー起用

【課題】購入率が低く、リピートが続かない

  Customer Solution（顧客ソリューション）の問い
  　→「天然成分」訴求より「敏感肌の不安を解消する」が顧客の本音

  Convenience（利便性）の問い
  　→ 自社ECのみでは「試してみたい」顧客の入口が狭い
  　→ Place：定期便（サブスク）導入 + Amazon出品でタッチポイント拡大

  Communication（コミュニケーション）の問い
  　→ 一方向の広告のみ → 顧客の肌悩みをDMで聞く施策を追加
  　→ Promotion：UGC（ユーザー投稿）を積極的に引用・拡散

【改善結果】
  初回購入率：+38%　／　3ヶ月リピート率：+52%
```

**アニメーション：** 当初設計 → 課題 → 4Cの4段階が順にビルドアップ → 改善結果が強調表示
