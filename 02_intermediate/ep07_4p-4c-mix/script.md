マーケティングミックスとは、製品・価格・流通・プロモーションの4つが一枚岩の戦略のもとで噛み合っている状態のことです。今日はこの噛み合わせをどう作るかを、具体例とともにお伝えします。」

### スライド 3：マーケティングミックスとは：4Pが生まれた背景（Borden 1964, McCarthy 1960）（1:20〜2:00）

```
1960年

1964年
  Neil H. Borden
  "The Concept of the Marketing Mix"
  → 「マーケティングミックス」という概念・名称を確立

【4Pとは】
  企業が「コントロールできる」マーケティング変数の組み合わせ
  → 戦略を「実行可能な施策」に落とし込む設計図

【補足】
  Kotler & Keller（2016）：「4Pは今もマーケティング施策設計の基本骨格」
```

**アニメーション：** 年表が左から順にスライドイン → 4Pの定義がフェードイン → Kotlerの言葉が引用ボックスで出現

**ナレーション：**
「4Pはどこから来たのでしょうか。1960年、マッカーシーが著書『Basic Marketing』の中でProduct・Price・Place・Promotionという4つの変数でマーケティング施策を整理しました。これが4Pの原点です。そして1964年、ニール・ボーデンが「マーケティングミックス」という概念と言葉を定着させました。
4Pの本質は、企業がコントロールできる変数の組み合わせ、という点にあります。景気・競合・消費者トレンドは自社ではコントロールできません。しかし製品・価格・流通・プロモーションは、自社が意思決定できる変数です。だからこそ「設計図」として使えるのです。
コトラーとケラーは2016年版のマーケティング・マネジメントでも「4Pは今もマーケティング施策設計の基本骨格である」と述べています。1960年代に生まれたフレームワークが60年以上経った今も現役である理由は、シンプルでありながら本質を捉えているからです。では各要素を一つひとつ見ていきましょう。」

### スライド 4：Product（製品）：3層モデル（コア→実体→拡張）で製品を設計する（2:00〜3:00）

**スライド内容：**
```
【見出し】Product（製品）——3層モデルで設計する

【同心円図：内側から】

  ① コア（Core Product）
     顧客が本当に求めている「便益・価値」
     例：ドリルを買う人が欲しいのは「穴」ではなく「棚を作りたい体験」

  ② 実体（Actual Product）
     物理的な製品・サービスの具体的仕様
     → 品質・デザイン・ブランド名・パッケージ・機能

  ③ 拡張（Augmented Product）
     製品に付随する付加的サービス
     → 保証・アフターサービス・配送・設置・コミュニティ

【例：Apple iPhone】
  コア   ：繋がる・表現できる・ステータスを持つ
  実体   ：スペック・デザイン・iOS
  拡張   ：AppleCare・App Store・Genius Bar
```

**アニメーション：** 同心円が内側から順に拡大して出現 → Apple例が右側にスライドイン

**ナレーション：**
「最初のPはProduct、製品です。ここで重要なのはコトラーが提唱した3層モデルです。
一番内側にあるのはコア製品——顧客が本当に求めている価値・便益です。有名な例えがあります。ドリルを買う人が欲しいのは「ドリル」ではなく「壁に穴を開ける能力」、さらにいえば「棚を設置して部屋を快適にしたい体験」です。多くの企業が製品の機能や仕様を磨くことに集中しますが、顧客が購入するのはコアの便益だということを忘れてはいけません。
その外側に実体製品——品質・デザイン・ブランド名・パッケージ・機能など、物理的な製品仕様があります。顧客が実際に触れる部分です。
さらに外側に拡張製品——保証・アフターサポート・配送・設置・コミュニティなど、製品に付随する付加的なサービスです。現代では、この拡張製品が競合との差別化を生む重要な戦場になっています。
Appleで考えると、iPhoneのコアは「繋がる・表現できる・ステータスを持つ」体験です。実体はスペック・デザイン・iOS。AppleCareやApp Store・Genius Barは拡張製品に当たります。製品設計はコアから始め、実体・拡張と順番に設計するのが正しい順序です。」

### スライド 5：Price（価格）：コスト積み上げ vs 価値ベース vs 競合ベースの3アプローチ（3:00〜3:50）

**スライド内容：**
```
【見出し】Price（価格）——3つのアプローチ

【比較表】

アプローチ       | 考え方                    | 特徴・注意点
─────────────────────────────────────────────────────
① コスト積み上げ  | 原価 + 利益率 = 価格      | 簡単・市場無視リスクあり
② 価値ベース     | 顧客が感じる価値 = 価格    | 高マージン可・価値の説明が必要
③ 競合ベース     | 競合の価格を基準に設定     | 安全・差別化できない

【推奨アプローチ：価値ベース】
　・「いくらで作れるか」ではなく「いくらの価値があるか」が出発点
　・ユニクロ：品質と手頃さの価値提供 → SPAで原価を下げて価値ベース価格を実現

【価格と他のPとの整合】
　高品質製品 × 低価格 → ブランド毀損リスク
　高価格    × 大量流通 → 価値訴求のミスマッチ
```

**アニメーション：** 3行の比較表が1行ずつ出現 → 価値ベースがハイライト → 整合の注意がフェードイン

**ナレーション：**
「2つ目のPはPrice、価格です。価格設定には大きく3つのアプローチがあります。
コスト積み上げは原価に利益率を乗せる方法です。計算は簡単ですが市場の需要を無視するリスクがあります。スタートアップや中小企業でよく見られるパターンです。競合ベースは競合他社の価格を基準に設定する方法です。市場から大きく外れにくいというメリットがある一方、自社の価値を根拠にしていないため差別化できません。
一番おすすめなのは価値ベース価格設定です。「いくらで作れるか」ではなく「顧客にとっていくらの価値があるか」から出発します。顧客が認識する価値——時間の節約、感情的な満足、社会的ステータスなど——を正しく評価できると、マージンを維持しながら顧客にも納得感を与えられます。
ユニクロはSPA（製造小売業）モデルで製造コストを極限まで下げ、「この品質でこの価格」という価値ベースの訴求を成立させています。原価を下げることで価値ベースの価格が実現できた好例です。
そして大切な注意点として、価格は他の3Pと整合しなければなりません。高品質の製品を極端に低価格で売ると、顧客は「品質が怪しいのでは」と疑います。価格はそれ自体が品質のシグナルです。この点は次のスライド10で詳しく説明します。」

### スライド 7：Promotion（プロモーション）：IMC（統合マーケティングコミュニケーション）の発想（4:40〜5:30）

**スライド内容：**
```
【見出し】Promotion（プロモーション）——IMCの発想で統合する

【Promotionの要素（プロモーションミックス）】
  ・広告（Advertising）
  ・販売促進（Sales Promotion）
  ・PR・パブリシティ
  ・ダイレクトマーケティング
  ・人的販売
  ・デジタル・SNSマーケティング

【IMC（統合マーケティングコミュニケーション）とは】

  店舗：「古い陳列・スタッフが製品を知らない」

```

IMCのポイントは「すべての顧客接点からのメッセージを統一する」ことです。テレビ広告では革新的なブランドを打ち出しているのに、SNSではセール情報ばかり、店舗では製品を知らないスタッフが対応する——これではブランドメッセージがバラバラになります。
すべてのタッチポイントで同じ価値観・同じトーンを届けることで、はじめてブランドとして記憶に残ります。このIMCの発想がPromotionの核心です。」

### スライド 8：4Cへのシフト：Lauterborn（1990）が提唱した顧客目線の再解釈（5:30〜6:30）

**スライド内容：**
```
【見出し】4Cへのシフト——顧客目線で4Pを読み替える

【背景】
  ラウターボーン（1990年、*Advertising Age* 誌）が提唱
  "New Marketing Litany: 4Ps Passe; C-Words Take Over"

  「企業が売りたいものを売るのではなく、
   顧客が買いたいものを売れ」

【4Pの限界】
  ・企業（売り手）の視点で設計されている
  ・顧客の実感・ニーズが後回しになりやすい
  ・「Product を作ったから売る」という発想を生む

【4Cの4つのC】

  Product  →  Customer Solution（顧客ソリューション）
              「製品の仕様ではなく、顧客の問題を解くか」

  Price    →  Cost to the Customer（顧客コスト）
              「金銭的コストだけでなく、時間・手間・心理的コストも含む」

  Place    →  Convenience（利便性）
              「入手しやすいか・使いやすいか」

  Promotion →  Communication（コミュニケーション）
              「一方的な広告ではなく双方向の対話」
```

**アニメーション：** ラウターボーンの引用がフェードイン → 4Pが左列に出現 → 右列に4Cが矢印で対応しながら順にスライドイン

**ナレーション：**
「4Pを理解したうえで、次のステップとして4Cへのシフトを学びましょう。
1990年、アドバタイジング・エイジ誌に掲載されたラウターボーンの論文が原点です。彼は「4Pはもう古い。顧客を表すC-ワードに置き換えよ」と主張しました。
4Pの本質的な限界は「企業（売り手）の視点で設計されている」点にあります。製品を作ったから売る、という発想になりやすいのです。
4Cでは4つのPをすべて顧客視点で読み替えます。ProductはCustomer Solution——製品の仕様ではなく顧客の問題を解決できるか。PriceはCost to the Customer——金銭コストだけでなく時間・手間・心理的コストも含む顧客の総コスト。PlaceはConvenience——入手・利用のしやすさ。PromotionはCommunication——一方的な広告ではなく、顧客との双方向の対話です。」

### スライド 9：4Pと4Cの対応表：企業視点→顧客視点への読み替え（6:30〜7:10）

**スライド内容：**
```
【見出し】4Pと4Cの対応表——企業視点 vs 顧客視点

【対応表】

企業視点（4P）              顧客視点（4C）
─────────────────────────────────────────────────────────
Product（製品）         → Customer Solution（顧客ソリューション）
  「何を作るか・売るか」     「顧客のどんな問題・不満を解決するか」

Price（価格）           → Cost to the Customer（顧客コスト）
  「いくらで売るか」         「顧客が払う総コスト（金銭＋時間＋心理）」

Place（流通）           → Convenience（利便性）
  「どこで売るか」           「顧客にとってどれだけ手に入れやすいか」

Promotion（プロモ）     → Communication（コミュニケーション）
  「どう告知するか」         「顧客と双方向でどう対話するか」
─────────────────────────────────────────────────────────

【メッセージ】
  4Pを設計する際は、常に4Cの問いでチェックする
  → 「これは顧客の視点で設計されているか？」
```

**アニメーション：** 4Pの列が先に出現 → 矢印が引かれながら4Cの列が右にスライドイン（1行ずつ） → 最後にメッセージが強調表示

**ナレーション：**
「対応関係を整理した表で確認しましょう。
ProductとCustomer Solution。製品を「何を作るか」で考えるのではなく、「顧客のどんな問題・不満を解決するか」を起点に設計します。
PriceとCost to the Customer。価格は企業が「いくらで売りたいか」ではなく、顧客が払う総コストで考えます。金銭だけでなく、購入に費やす時間・手続きの手間・不安などの心理的コストも含めた負担全体です。
PlaceとConvenience。「どこで売るか」ではなく「顧客にとってどれだけ手に入れやすいか」に視点を移します。
PromotionとCommunication。一方的に告知するのではなく、顧客と双方向で対話する関係を作ることです。
