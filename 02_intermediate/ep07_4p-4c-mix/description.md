## メイン説明文

```
4Pと4Cの違いと使いかたを、1996年スターバックス日本上陸の実話1本で解説します。
製品も価格も広告も全部やっているのに売れない本当の原因は、努力不足ではなく「4つの施策が噛み合っていない」ことです。

値引き0回・テレビCM0本のまま、日本で2,000店。
男性喫煙率58%の時代に「全面禁煙・値引きなし・広告なし」で参入したスターバックスは、
なぜ勝てたのか——答えは、コーヒーではなく「居場所」という1つの顧客価値から、
製品・価格・売り場・伝え方（4P）をすべて逆算した「整合」にあります。

この動画で分かること：
✅ 施策がバラバラな会社が空回りする本当の原因（足りないのではなく、噛み合っていない）
✅ 4P（マッカーシー1960）と4C（ラウターボーン1990）の違い——同じ現実の表と裏
✅ 顧客価値1行から4つを逆算して揃え直す手順（As-Is→To-Be・紙1枚のワーク付き）

「何かを足す前に、まず揃える」。同じ予算のまま歯車を回しはじめたい
個人事業主・小さな会社の担当者の方に特におすすめです。

※ナレーションはAI音声合成（VOICEVOX:玄野武宏）を使用しています。
```
