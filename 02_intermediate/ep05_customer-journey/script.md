初めて聞いたブランドの商品を、その場で即購入しますか。普通はしません。まず調べて、比較して、口コミを確認して、それから買う。この一連の流れが『カスタマージャーニー』です。

### スライド 5：コトラーの5Aフレームワーク（3:10〜4:00）

```
【見出し】コトラーの5Aフレームワーク

Aware     Appeal     Ask       Act       Advocate
（認知）  （訴求）  （調査）  （行動）  （推薦）

Aware  → 商品の存在を知る
Appeal → 興味・好感を持つ
Ask    → 能動的に情報収集・比較する
Act    → 購入する・使い始める
Advocate → 他者に勧める・口コミを発信する

【ポイント】
　→ 直線ではなく「ループ」構造
　→ Advocateが次の人の Aware を生む
```

**アニメーション：** 5つのA が左から順に出現 → 矢印でループが描かれる → 各説明が下に出現

**ナレーション：**
「コトラーが2016年の著書『マーケティング4.0』で提唱した5Aフレームワークを詳しく見ていきましょう。
Aware（認知）は商品の存在を知る段階。Appeal（訴求）は「良さそう」と感じる段階。Ask（調査）は自ら検索・比較・口コミを読む段階。Act（行動）は購入・使い始める段階。Advocate（推薦）は体験を他者に勧める段階です。
最大の特徴は直線ではなくループ構造であること。Advocateになった顧客がSNSで発信することで、新しい人のAwareが生まれます。
このループをどう回すかが現代マーケティングの核心です。ファンが自然に拡散してくれる仕組みができると、広告費を増やさずに新規顧客が増え続けます。」

### スライド 6：ステージ別施策①——Aware／Appealフェーズ（4:00〜5:00）

**スライド内容：**
```
【見出し】ステージ別施策 ① Aware → Appeal

【Aware（認知）フェーズ】
目的：まず存在を知ってもらう
主な施策：
　・SNS広告・ディスプレイ広告（認知拡大）
　・インフルエンサー起用・PR記事
　・SEO（検索流入）・YouTube動画
　・口コミ・シェアが起きやすいコンテンツ設計

【Appeal（訴求）フェーズ】
目的：「もっと知りたい」という感情を引き出す
主な施策：
　・ブランドストーリー・世界観の発信
　・感情的ベネフィットを前面に出したコンテンツ
　・SNSのビジュアル統一・印象的なビジュアル表現
　・ファーストビューのコピーで「自分ごと化」させる

【注意】この段階で「今すぐ買ってください」は逆効果
```

**アニメーション：** Aware → Appeal の2ブロックが順に出現 → 施策リストがビルドアップ → 注意が赤字で表示

**ナレーション：**
「5Aの各ステージで、具体的にどんな施策が有効かを見ていきましょう。
Aware（認知）フェーズの目的は、まず存在を知ってもらうことに絞ります。SNS広告・ディスプレイ広告・インフルエンサー起用・SEOなどが主な施策です。
Appeal（訴求）フェーズでは「知った」を「気になる」に変える必要があります。スペックより「これを使うとどんな気持ちになるか」を伝える方が、顧客の心は動きます。
注意点として、この2フェーズでは「今すぐ購入」を迫らないこと。初対面の相手に即購買を求めるのは逆効果です。まず関係性を育てることが先決です。」

### スライド 7：ステージ別施策②——Ask／Actフェーズ（5:00〜6:00）

**スライド内容：**
```
【見出し】ステージ別施策 ② Ask → Act

【Ask（調査）フェーズ】
目的：比較・検討している顧客の疑問を解消する
主な施策：
　・FAQ・ブログ記事・比較コンテンツ
　・レビュー・事例・導入実績の掲載
　・無料サンプル・トライアル・デモ動画
　・Google広告（指名検索・比較検索）

【Act（行動）フェーズ】
目的：購入の決断を後押しする
主な施策：
　・LP（ランディングページ）の改善
　・カート離脱防止（リマーケティング・メール）
　・期間限定オファー・社会的証明（口コミ・評価数）
　・購入後の体験設計（スムーズな開梱・オンボーディング）

【ポイント】
　Ask → Act の転換率 ＝ 「CVR（コンバージョン率）」
　ここがボトルネックになっているケースが最も多い
```

**アニメーション：** Ask → Act の2ブロックが順に出現 → ポイントがハイライト

**ナレーション：**
「Ask（調査）フェーズは、顧客が能動的に情報収集を始めている段階です。「他社と何が違う？」「実際に使った人の声は？」——こういった疑問を解消するコンテンツが求められます。
よくある失敗は、Askフェーズの顧客にAware向けのブランド世界観コンテンツを出し続けること。すでに検討している人には、比較情報・事例・レビューが必要です。
Act（行動）フェーズでは「後押し」が鍵です。LPの分かりやすさ、口コミの件数・評価点、期間限定オファーが購入の背中を押します。
ECサイトではカートに入れたまま離脱する「カート落ち」が頻発します。このActフェーズのボトルネックを解消するだけで売上が大きく改善するケースは多いです。」

### スライド 8：ステージ別施策③——Advocateフェーズ（6:00〜6:50）

**スライド内容：**
```
【見出し】ステージ別施策 ③ Advocate（推薦）フェーズ

目的：顧客をブランドの「語り部」にする

主な施策：
　・購入後のフォローアップメール・サンクスレター
　・SNSシェアを促す仕掛け（ハッシュタグ・UGC設計）
　・ロイヤルティプログラム（ポイント・会員特典）
　・紹介プログラム（友人紹介で特典）
　・コミュニティ形成（ファン同士の繋がりを作る）

【なぜAdvocateが重要か】
　・新規顧客獲得コスト（CPA）が大幅に下がる
　・口コミ経由の顧客はLTV（顧客生涯価値）が高い傾向
　・「信頼できる第三者」からの情報は広告より信頼される

【結論】既存顧客への投資がマーケティング最大の費用対効果
```

**アニメーション：** 施策リストがビルドアップ → 重要性の3点が順に出現 → 結論が強調表示

**ナレーション：**
「多くの企業がAdvocate（推薦）フェーズを軽視しています。「売れたら終わり」という発想です。でも実はここが最も費用対効果の高い投資先かもしれません。
口コミ・紹介で来た顧客はLTV——顧客生涯価値——が高く、新規獲得コストも大幅に下がります。
施策は購入直後のフォローアップ、SNSシェアを促すハッシュタグ設計、ロイヤルティプログラムなど。
そして特に重要なのがUGC（ユーザー投稿コンテンツ）です。顧客が自らSNSに投稿した体験談は、企業の広告より信頼度が高く、Aware・Appealフェーズを強力に後押しします。Advocateが育つと、顧客自身がマーケターになってくれます。」

### スライド 10：実践例——あるSaaS企業のジャーニーマップ事例（8:00〜8:50）

**スライド内容：**
```
【見出し】実践例：あるSaaS（業務管理ツール）のジャーニーマップ

【課題】
　・SNS広告のCTRは高いが、無料トライアル登録に繋がらない
　・登録後の有料転換率が低い

【ジャーニーマップで発見した「穴」】

　Aware：SNS広告 → 訴求力は十分 ✅
　Appeal：広告LPのファーストビューが機能訴求中心 ⚠️
　　　　　→ 感情的ベネフィットが弱い
　Ask：導入事例ページが少ない・FAQ不足 ❌
　　　 → 競合比較されたときに情報不足で離脱
　Act：無料トライアル登録後のオンボーディングが弱い ❌
　　　 → 初回ログイン後に何をすれば良いか分からず放置

【改善後】
　・LPの冒頭を「作業時間が週5時間削減できた」体験談に変更
　・導入事例を3社→12社に拡充
　・登録後72時間以内にチュートリアルメール配信
　→ 有料転換率が2.1倍に改善
```

**アニメーション：** 課題 → 穴の発見が各ステージで ✅⚠️❌ アイコン付きで出現 → 改善後が出現 → 2.1倍が強調

**ナレーション：**
「ジャーニーマップを使って課題を解決した例を見てみましょう。あるSaaS業務管理ツールの事例です。
「広告クリック率は高いのにトライアル登録されない」「登録後に有料転換しない」という二重の悩みがありました。
マップで分解した結果、3つの穴が見えました。①AppealのLPが機能説明に偏り感情的ベネフィットが弱い、②Ask段階の導入事例が少なく比較時に離脱される、③登録後のオンボーディングが未整備でそのまま放置される。
この3点を改善したところ、有料転換率が2.1倍になりました。広告費は1円も変えていません。ジャーニー全体を俯瞰したことで、本当のボトルネックが見えたのです。」

### スライド 11：陥りがちな罠——ファネル思考に閉じてループが見えない（8:50〜9:20）

**スライド内容：**
```
【見出し】陥りがちな罠：ファネル思考だけでは不十分

【ファネル（漏斗）思考の限界】

　認知
　 ↓
　興味
　 ↓
　検討
　 ↓
　購入 ← ここで「終わり」と考えてしまう

【問題点】
　❌ 購入後の顧客体験が設計されない
　❌ LTVとAdvocateの視点が抜け落ちる
　❌ 「新規獲得コスト」ばかり増え続ける構造になる

【対策：ループ（フライホイール）思考へ】
　購入後の顧客満足 → 口コミ・紹介 → 新規認知
　　　　→ 獲得コストが自然に下がっていく
```

**アニメーション：** ファネル図 → ×マークが付く → ループ図に変換されるアニメーション

**ナレーション：**
「多くのマーケターが陥る罠をお伝えします。「ファネル思考だけで完結させてしまう」ことです。
ファネルは認知から購入で終わる直線モデル。シンプルですが、購入後の世界がありません。
結果、既存顧客へのケアが疎かになり、リピートされず離脱が続く「バケツに穴が開いた状態」になります。新規獲得コストだけが膨らみ続けます。
対策はファネルをループ（フライホイール）として捉え直すこと。満足した顧客が口コミを発信し、その口コミが新しい認知を生む——このループが回ると、獲得コストが自然と下がってブランドが自走し始めます。」
