## メイン説明文

```
USPの作り方を、ハズキルーペの実話1本で解説します。
品質は負けていないのに価格で比べられて負ける本当の理由は、「比べられる土俵」にいることです。

100円ショップにも同類品がある拡大鏡市場で、本体約1万円のまま累計500万本超。
支えたのは、年間100億円超の広告費を「大きく見える」というたった一言に集中させた
一点訴求＝USP（ユニーク・セリング・プロポジション）でした。

この動画で分かること：
✅ 指名買いされる商品と、価格で比べられる商品の違い（比べる相手を消す仕組み）
✅ USPの3条件（リーブス1961）——具体的な提案／競合の沈黙／人を動かす力
✅ 自社の一点を見つける「3つの窓」と、紹介文を一点突破に直す3ステップ

「値下げ以外の戦いかたが見つからない」「強みを聞かれると全部それなりとしか言えない」
個人事業主・小さな会社の担当者の方に特におすすめです。
明日やることは1つだけ——紹介文から、競合でも言える言葉を全部消すこと。

※ナレーションはAI音声合成（VOICEVOX:玄野武宏）を使用しています。
```
