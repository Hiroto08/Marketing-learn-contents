### スライド 3：USPとは何か（定義）——Rosser Reeves（1961）の提唱。3条件（独自・競合未提供・購買を動かす）（1:20〜2:10）

**スライド内容：**
```
【見出し】USPとは何か

定義：
「Unique Selling Proposition（独自のセールス提案）」
── Rosser Reeves 『Reality in Advertising』（1961）

【USPの3条件】

条件① 独自性（Unique）
　→ 競合が言っていない、あなただけの主張

条件② 競合未提供（Selling）
　→ 競合は提供できていない、または提供していない強み

条件③ 購買を動かす（Proposition）
　→ 顧客が「だから買おう」と思える具体的なベネフィット

【例：Reevesの代表作】
　M&M's（エム&エムズ）：
　「チョコレートは手の中で溶けず、口の中で溶ける」
　→ 独自・競合未提供・ベネフィット明確 = 完璧なUSP
```

**アニメーション：** 定義がフェードイン → 3条件が1行ずつビルドアップ → M&M'sの例が出現し3条件に色付けで対応

**ナレーション：**
「USPとは、Unique Selling Propositionの略で、日本語では「独自のセールス提案」と訳されます。1961年に広告の巨人、ロッサー・リーブスが著書『Reality in Advertising』で提唱したコンセプトです。
USPには3つの条件があります。第一に「独自性」——競合が言っていない、あなただけの主張であること。第二に「競合未提供」——他社が提供できていない、または提供していない強みであること。第三に「購買を動かす」——顧客が「だから買おう」と思える具体的なベネフィットに結びついていること。
リーブス自身の名作がM&M'sです。「チョコレートは手の中で溶けず、口の中で溶ける」。これはまさに3条件を満たしています。独自で、競合は言っておらず、「手が汚れない」という明確なベネフィットがある。このシンプルな一文が、M&M'sを世界的ブランドにしました。」

```
　　　　　　　┌────────┬────────┐
　業界全体　　│コスト　　　│差別化　　　│

差別化戦略：

【ポーターの警告】

　→ どれで戦うかを明確に決めることが第一歩
```

**アニメーション：** 2×2マトリクスが順に出現 → 各セルに具体例がフェードイン → 警告メッセージが赤字で強調

**ナレーション：**
「USPを考える前に、どの土俵で戦うかを決める必要があります。ハーバード大学のマイケル・ポーターは1980年の著書で、企業が取り得る競争戦略を3つに整理しました。
一つ目はコストリーダーシップ。業界で最も安くつくれる力を武器に価格競争で勝つ戦略です。ユニクロやウォルマートがこれに当たります。
二つ目は差別化戦略。コストよりも独自の価値を高めることで、価格プレミアムを獲得する戦略です。Appleやルイヴィトンはまさにこれです。
三つ目は集中戦略。特定の市場セグメントや顧客層に絞り込み、そこでの競争に勝つ戦略です。高級旅館や専門クリニックなどが例として挙げられます。
そしてポーターが特に警告したのは「中間に留まること」です。安くもなく差別化もできない、どちらも中途半端な状態は最も危険です。どの戦略で戦うかを選ぶことが、USP設計の出発点です。」

```
　自社ブランドの『場所（ポジション）』を確保することである」

【脳内マップのイメージ】

「高級コーヒー」のポジション → スターバックス

→ USPが届いてポジションが確立する

【リース＆トラウトの法則】
```

**ナレーション：**
「USPをうまく伝え続けた先に何が起きるか。それが「ポジショニング」です。リース＆トラウトは1981年の著書で、マーケティングは商品の戦いではなく「顧客の頭の中の戦い」だと言い切りました。
「高級コーヒーといえばスターバックス」「スポーツ飲料といえばゲータレード」「検索といえばGoogle」——これらはすべて、顧客の記憶の中に確固たるポジションを持っているブランドです。
USPは「私たちはこういう強みがある」という発信側の主張であり、ポジショニングはその結果として顧客の頭の中に生まれる「場所」です。USPが正しく届き続けると、記憶の中のポジションが確立されます。
リース＆トラウトが強調したのは「カテゴリの第一位を狙え」ということです。人の記憶は1位しか覚えない。コーラの2位、3位のブランドを即座に答えられますか。USPとポジショニングはセットで考えることが重要です。」

### スライド 7：USPの見つけ方②——競合分析で「誰もやっていないこと」を見つける（4:50〜5:40）

**スライド内容：**
```
【見出し】USPの見つけ方 ② 競合分析

【競合分析のフレームワーク：比較表】

　評価軸        自社   競合A  競合B  競合C
　─────────────────────────────────
　価格           ◎     ○      △      ×
　配送スピード   △     ◎      ○      ○
　カスタマイズ   ◎     ×      △      ○
　アフター対応   ◎     △      ○      △
　ブランド認知   △     ◎      ◎      ×
　専門サポート   ◎     ×      ×      ×

【分析のポイント】
　→ 自社が「◎」で競合が「×または△」の評価軸 = USP候補
　→ 競合全員が◎の評価軸 = 戦場（差別化できない）
　→ 誰も「◎」をつけていない評価軸 = ブルーオーシャン候補

【注意】
　競合の「やっていないこと」は2種類ある
　① やろうとしたができないこと（参入障壁）→ 強いUSP
　② やれるがやっていないこと（見落とし）   → 弱いUSP（追随される）
```

**アニメーション：** 比較表がスプレッドシートのように1行ずつ出現 → 自社◎・競合×の行がハイライト → 注意の2種類が強調表示

**ナレーション：**
「USPを見つける2つ目のアプローチは競合分析です。主要な競合3〜5社を横並びにした比較表を作り、複数の評価軸で採点します。
重要なのは「自社が強く、競合が弱い」評価軸を見つけることです。自社が◎で、競合が×や△の評価軸こそがUSP候補です。
一方、競合全員が◎の評価軸は「戦場」です。そこで戦っても差別化にはなりません。
さらに大切な視点は、競合が「やっていないこと」の理由です。できないからやっていないのか、やれるけどやっていないのか。この違いは決定的です。コスト・技術・特許などで参入障壁がある場合は強いUSPになります。しかしやろうと思えばできるだけのことは、翌月には追随されます。競合が構造的にできないことを見つけることが、持続可能なUSPへの道です。」

### スライド 8：USPの見つけ方③——バリュープロポジションキャンバス（Osterwalder 2014）の活用（5:40〜6:30）

**スライド内容：**
```
【見出し】USPの見つけ方 ③ バリュープロポジションキャンバス
（Alexander Osterwalder et al. 『Value Proposition Design』2014）

【キャンバスの構造：2つの円・四角形】

　【顧客プロフィール（右側：円）】      【価値マップ（左側：四角形）】
　　顧客のJob（やりたいこと）       →   製品・サービス（Products & Services）
　　Pains（困りごと・不満）         →   ペインリリーバー（痛みを取り除くもの）
　　Gains（嬉しいこと・期待）       →   ゲインクリエイター（喜びをつくるもの）

【フィット（一致）が起きている状態】
　→ 顧客のPainsをリリーバーが解消している
　→ 顧客のGainsをクリエイターが実現している
　→ この「フィット」こそがUSPの核心

【実践例：コカ・コーラ】
　Job：飲み物で気分転換・リフレッシュしたい
　Pain：単調な味の飲み物は飽きる・気分が上がらない
　Gain：すっきりした爽快感・特別な瞬間の演出
　→ 「ハッピネス（赤・笑顔）」がペインをリリーブし、ゲインを創出
```

**アニメーション：** 左右の図が同時に出現 → 矢印でフィット関係が示される → コカ・コーラの例がフェードイン

**ナレーション：**
「USPを見つける3つ目のアプローチは、オスターワルダーらが2014年に提唱したバリュープロポジションキャンバスです。
このツールは2つの要素で構成されます。右側の「顧客プロフィール」は、顧客がやりたいこと（Job）、困りごと（Pains）、嬉しいこと（Gains）の3つを整理します。左側の「価値マップ」は、自社の製品・サービスがどのPainsを取り除き（ペインリリーバー）、どのGainsを生み出すか（ゲインクリエイター）を整理します。
両者がぴたりと一致した状態を「フィット」と呼びます。このフィットがUSPの核心です。
コカ・コーラの「赤と笑顔」は、単純な清涼飲料を「特別な瞬間のハッピネス」として演出することで、顧客のPain（単調さ・退屈）をリリーブし、Gain（爽快感・特別感）を創出しています。このキャンバスで自社を整理すると、USPの輪郭が見えてきます。」

### スライド 9：ブルーオーシャン戦略——競争のない市場を作る（Kim & Mauborgne 2005）——戦略キャンバスの描き方（6:30〜7:20）

**スライド内容：**
```
【見出し】ブルーオーシャン戦略
（W. Chan Kim & Renée Mauborgne
 『Blue Ocean Strategy』2005）

【レッドオーシャン vs ブルーオーシャン】

　レッドオーシャン（既存の市場）
　　→ 競争が激しく血みどろ（赤）の状態
　　→ 差別化のない消耗戦

　ブルーオーシャン（未開拓の市場）
　　→ 競争相手がいない新しい価値空間を創る
　　→ 競争を無意味にする

【戦略キャンバスの描き方：4つのアクション】

　① 取り除く（Eliminate）
　　業界の常識だが顧客に不要なものを取り除く

　② 減らす（Reduce）
　　業界標準以下に水準を下げるもの

　③ 増やす（Raise）
　　業界標準以上に引き上げるもの

　④ 付け加える（Create）
　　業界が提供していなかった新要素を加える

【例：シルク・ドゥ・ソレイユ】
　サーカスから動物・スター出演を「取り除き」、
　芸術性・ストーリーを「付け加え」、
　新カテゴリを創出した
```

**アニメーション：** 赤vs青の対比図 → 4つのアクション（ERRC）がタイル型で出現 → シルク・ドゥ・ソレイユの例が矢印付きで図示

**ナレーション：**
「差別化の究極形が、キム＆モボルニュのブルーオーシャン戦略です。2005年に発表されたこの考え方は「競争のない市場空間を自ら創り出す」という発想です。
従来の市場はレッドオーシャン。競合が多く、差別化のない消耗戦が続きます。一方ブルーオーシャンは、競争そのものを無意味にする新しい価値空間です。
その実現ツールが「4つのアクション」です。業界の常識を「取り除く」、水準を「減らす」、標準を「増やす」、まったく新しい要素を「付け加える」。
典型例がシルク・ドゥ・ソレイユです。従来のサーカスから動物ショーやスターを「取り除き」、芸術性とストーリーを「付け加え」た。これによって競合サーカスとの比較を無意味にし、演劇・バレエの観客層を新たに取り込みました。USPとは、競合との差を比較することだけでなく、新しい軸を創造することでもあります。」

### スライド 10：USPを言語化する——「顧客・ベネフィット・根拠」の3要素で一文にまとめる（7:20〜8:10）

**スライド内容：**
```
【見出し】USPを一文で言語化する

【3要素の公式】

　USP = 「顧客（誰に）」 × 「ベネフィット（何が得られるか）」
　　　　 × 「根拠（なぜ信頼できるか）」

【言語化テンプレート】
　「[ターゲット顧客] は、[具体的な課題・悩み] を抱えていますが、
　 私たちの [製品・サービス] は [根拠・仕組み] によって
　 [ベネフィット] をもたらします。これは競合では [できない理由] です。」

【実践例】

　◎ 良いUSP例
　「多忙な中小企業経営者が、請求書作業に週3時間かけていたのを
　 弊社ツールは自動処理により30分以内に完了させます。
　 競合は手動確認が必要ですが、弊社はAI自動照合で誤処理ゼロを実現しています。」

　× 悪いUSP例
　「高品質で丁寧なサービスを提供しています。」
　→ 独自性なし・ベネフィット曖昧・根拠ゼロ

【USP言語化チェックリスト】
　□ 競合のサービスに同じ文が使えないか？
　□ 数字・事実・実績で裏付けられているか？
　□ 顧客がイメージできる具体的な言葉か？
```

**アニメーション：** 3要素の公式が順に表示 → テンプレートがフェードイン → 良い例・悪い例が対比 → チェックリストが出現

**ナレーション：**
「分析で見つけたUSPの素材を、伝わる一文に言語化するステップです。USPの言語化には「顧客・ベネフィット・根拠」の3要素が必要です。
顧客は誰か——ターゲットを絞るほどUSPは鋭くなります。ベネフィットは何か——「気持ちよい」ではなく「週3時間が30分になる」のように具体的な数字で語れるかが重要です。根拠は何か——なぜその価値が生まれるのかの仕組みや証拠です。

言語化後に3つのチェックをしてください。「競合のサービスに同じ文が使えないか？」——使えるなら差別化できていません。「数字や事実で裏付けられているか？」「顧客が具体的にイメージできる言葉か？」この3つを全てクリアしたとき、本物のUSPが完成します。」

```

　→ 顧客インタビューから「地元に溶け込む体験」を発見し言語化

　・USPは「顧客視点」で語られるとき初めて機能する
　・スペックのUSPより「意味・物語・アイデンティティ」のUSPが強い
　・失敗の本質は「差別化の言語化」を後回しにしたこと
```

**アニメーション：** 成功例2つがカード形式で順に出現 → 失敗例が暗いトーンで出現 → 教訓が3行順に出現

**ナレーション：**
「実際の事例で差別化の成否を見てみましょう。AppleのUSPは「スペックの高さ」ではなく「Think Different——常識を疑い、創造性を解放する」というアイデンティティです。iPhoneはカメラの画素数を訴求しません。「あなたが撮った写真は芸術作品だ」と訴求します。だから他社より高くても選ばれ続けます。
