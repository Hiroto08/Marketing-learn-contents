# 第1回：そもそもマーケティングとは？「売れる仕組み」の正体

## 動画基本情報

| 項目 | 内容 |
|------|------|
| 想定尺 | 10分（±1分） |
| 難易度 | 初級 |
| 対象視聴者 | マーケティング未経験〜入門者。個人事業主・会社員問わず「なぜ売れるのか知りたい人」 |
| 学習ゴール | 「マーケティング＝広告」という誤解を解き、「売れる仕組みを設計する行為」と再定義できる |

### 主な引用・参考文献

- Peter F. Drucker『マネジメント』（1973）

```
× チラシを配ること
× 広告を出すこと

→ これらは「マーケティングの一部」に過ぎない
```

でも実は、これらはどれも『マーケティングの手段』であって、マーケティングそのものではありません。つまり、マーケティングの一部に過ぎないんです。
広告を打てばマーケティングをやっていると思いがちですが、それは最後の一手でしかない。手段だけを先に学んでも、なぜか成果につながらない——その根本的な理由が、今日でわかります。
まずは『そもそもマーケティングとは何か』という問いから、一緒に整理していきましょう。」

### スライド 3：マーケティングの公式定義（1:30〜2:30）

**スライド内容：**
```
【見出し】マーケティングとは？（公式定義）

アメリカ・マーケティング協会（AMA）2017年改訂版：

"Marketing is the activity, set of institutions, and processes
for creating, communicating, delivering, and exchanging
offerings that have value for customers, clients, partners,
and society at large."

【日本語訳ポイント】
顧客・社会にとって価値ある「提供物」を
　　創り・伝え・届け・交換するための活動
```

**アニメーション：** 英文が先に表示 → 日本語訳がハイライトしながらフェードイン

**ナレーション：**
「マーケティングの世界標準の定義を見てみましょう。
アメリカ・マーケティング協会——AMAが定めた定義で、2017年に改訂された最新版です。
英語の原文が難しく感じるかもしれませんが、要点はシンプルです。『顧客にとって価値があるものを作り、伝え、届け、交換する——その一連の活動すべて』これがマーケティングです。
注目してほしいのは、『創る・伝える・届ける・交換する』という4つのプロセスです。これらすべてをまとめてマーケティングと呼ぶんです。
つまり、広告は最後の『伝える』というステップのひとつに過ぎません。マーケティングは、広告よりもはるかに広い概念なんです。」


『マーケティングの目的は、販売を不要にすることである』——一見、逆説的に聞こえますよね。売ることが目的なのに、販売を不要にするとはどういうことか。
これが本質を突いた言葉で、本当に優れたマーケティングができれば、セールスや説得をしなくても、商品が『自然に選ばれる状態』を作り出せるんです。お客さんが『これだ！』と自分から選びにきてくれる。
これが『売る』という行為と、『売れる仕組みを作る』という発想の根本的な違いです。」

### スライド 5：「売る」vs「売れる仕組みを作る」（3:30〜4:30）

**スライド内容：**
```
【左右比較レイアウト】

【左：❌ 旧来の発想】          【右：✅ マーケティング思考】
「どうやって売るか」           「なぜ選ばれるか」
商品ありき                     顧客ありき
一方的に押し込む               自然に引き寄せる（Pull）
短期的な売上                   長期的な関係構築
```

**アニメーション：** 左側が先に表示 → 右側がスライドインで比較

**ナレーション：**
「わかりやすく左右に並べて比べてみましょう。
旧来の発想は『どうやって売るか』が出発点です。商品ありきで、いかに顧客を説得するかを考える。一方的に押し込む、いわゆる『プッシュ型』の発想ですね。目的も短期的な売上が中心になりがちです。
一方、マーケティング思考は『なぜ選ばれるか』が出発点。顧客が何を求めているかをまず理解して、その答えとして商品・サービスを設計します。引き寄せる『プル』の発想で、目的は長期的な関係構築です。
この根本的な方向の違いが、すべてのマーケティング戦略の出発点になります。」

### スライド 6：マーケティングが担う4つの機能（4:30〜5:30）

**スライド内容：**
```
【見出し】マーケティングが担う4つの機能
（Kotler & Keller, 2016を基に）

① 市場を理解する    ── 誰が・何を・なぜ求めているか調査
② 戦略を設計する   ── ターゲット・ポジションを決める
③ 価値を創造する   ── 製品・価格・流通を設計する
④ 価値を伝える     ── 広告・PR・コンテンツで届ける
```

**アニメーション：** ①〜④が番号順に1つずつフェードイン

**ナレーション：**
「コトラーの教科書的な整理をすると、マーケティングには大きく4つの機能があります。
まず①『市場を理解する』——誰が何に困っていて、何を求めているかをリサーチする段階です。次に②『戦略を設計する』——どの顧客層を狙い、どんな立ち位置で価値を届けるかを決める。
そして③『価値を創造する』——商品・価格・流通の仕方を設計する段階。最後が④『価値を伝える』——これが広告やSNSにあたる部分ですね。
重要なのは、広告は最後のステップだということです。①〜③の土台をしっかり作ってからこそ、④の広告が初めて効果を発揮できる。逆に、土台がなければいくら広告を打っても成果が出ないのはこのためです。」

### スライド 7：具体例 — スターバックスはなぜ高くても売れる？（5:30〜6:45）

**スライド内容：**
```
【見出し】例：スターバックスのマーケティング

☕ コーヒー1杯：600〜700円
   ← コンビニコーヒーの約5〜7倍

なぜ選ばれる？

① 市場理解：「カフェで過ごす時間」に価値を感じる層がいる
② 戦略設計：「サードプレイス（第3の居場所）」として差別化
③ 価値創造：店舗空間・接客・カスタマイズ体験すべてがセット
④ 価値伝達：ブランドストーリー・SNS・カップデザイン

→ 高くても「選ばれる理由」が設計されている
```

**アニメーション：** 価格比較 → ①〜④が順にビルドアップ → 結論矢印

**ナレーション：**
「具体例で理解しましょう。スターバックスのコーヒーは1杯600〜700円ほど。コンビニコーヒーの5〜7倍の価格です。それでも世界中で売れ続けている。なぜでしょうか？
実はスターバックスは、コーヒーを売っているわけではないんです。『第3の居場所（サードプレイス）』——家でも職場でもない、自分だけの落ち着ける時間と空間を売っています。
①市場理解として、カフェで過ごす時間に価値を感じる層がいることを発見した。②それを戦略として、他のカフェとは違う『居場所』として差別化した。③店舗空間・接客・カスタマイズという体験全体を価値として創造し、④ブランドストーリーやSNSを通じて伝えてきた。
価格ではなく、体験そのものに価値がある——これが『売れる仕組み』の設計です。スタバの広告は、この土台があって初めて機能しているんです。」

### スライド 8：マーケティング ≠ 広告・宣伝（6:45〜7:30）

**スライド内容：**
```
【図解：氷山モデル】

        ┌─────────────┐
        │  広告・宣伝    │ ← 見えている部分（水面上）
        └─────────────┘
━━━━━━━━━━━━━━━━━━━━━━ 水面
   ┌──────────────────────────┐
   │  顧客理解 / 戦略設計        │
   │  商品・価格・流通の設計     │ ← 見えない部分（水面下）
   │  ブランド・文化・体験設計   │
   └──────────────────────────┘

氷山の水面下こそが、マーケティングの本体
```

**アニメーション：** 水面上だけ表示 → 水面が引いて水面下が現れる

**ナレーション：**
「これを氷山に例えると、広告・宣伝は水面の上に出ている、誰もが見える部分です。でも水面下には、顧客理解・戦略設計・商品開発・価格設計・流通設計——これだけ大きな土台があって、初めて広告が機能するんです。
氷山の大半が水面下にあるのと同じように、マーケティングの本体も、表から見えない部分にあります。多くの人が『マーケティング＝広告・宣伝』と思ってしまうのは、水面上の部分しか見えていないから。
この講座では、水面下の本質から順番に積み上げていきます。」

手段は変わり続けますが、本質は1960年代から一切変わっていません。『顧客を深く理解して、価値を届ける』——この一点だけです。」

## 制作メモ

- **想定ナレーション文字数：** 約2,700字（10分目安 / 4〜4.5字/秒）
- **BGM：** 穏やか・集中できる系インスト（Lo-Fiなど）。ナレーション中は音量を下げる
- **テロップ：** 各スライドの重要キーワード（「売れる仕組み」「ドラッカー」等）は字幕でも強調
- **画面構成：** スライド全画面 or スライド+ワイプ（顔出しなしでも成立する設計）
- **アニメーション方針：** 過剰にしない。箇条書きのビルドアップ・フェードインのみで十分
- **引用表記：** スライド下部に小さく出典を表示（例：Kotler & Keller, 2016）
