### スライド 3：KGI・KPI・KSI（先行指標）の構造——ゴールから逆算する（1:20〜2:10）

**スライド内容：**
```
【見出し】KGI・KPI・KSI の構造

【ピラミッド図（上から下へ）】

        KGI（Key Goal Indicator）
        ＝最終ゴール指標
        例）年間売上 1,000万円

           ↓ 逆算する

        KPI（Key Performance Indicator）
        ＝中間プロセス指標
        例）月間新規顧客100人 / CVR 3%

           ↓ さらに先行させる

        KSI（Key Success Indicator）
        ＝先行指標（未来の結果を予測する数字）
        例）週次コンテンツ配信本数 / メルマガ開封率

【ポイント】KGIは「結果」、KPIは「プロセス」、KSIは「未来のシグナル」
```

**アニメーション：** ピラミッドが上から1段ずつ出現 → ポイントがハイライト

**ナレーション：**
「まず、指標の3つの階層を整理しましょう。
一番上がKGI、Key Goal Indicator。最終的なゴールを示す指標です。年間売上1,000万円、とか、新規会員1万人といったものです。
真ん中がKPI、Key Performance Indicator。KGIを達成するための中間プロセスを測る指標です。月間新規顧客数やコンバージョン率がここに入ります。
一番下がKSI、Key Success Indicator。先行指標とも呼ばれます。KPIの結果が出る前に、うまくいっているかを予測するための数字です。
大切なのは、必ずKGIから逆算して考えることです。『まず何の指標を上げればKGIに近づくか』という問いを繰り返すことで、本当に意味のある指標が見えてきます。」

　（1人が3回見たら「リーチ1・インプレッション3」）

ブランド認知率は、ターゲット層の中で自社を知っている人の割合。これはアンケートやサーベイで測ります。テレビCMや大型キャンペーンの効果測定によく使われます。
認知の指標は『届いているか』を測るものです。ただし、届いただけでは売上になりません。認知の数字が上がっても次の獲得につながっていなければ、戦略を見直す必要があります。」

### スライド 6：獲得指標の詳細——CVR・CPA・CPL・ROAS（3:50〜4:40）

**スライド内容：**
```
【見出し】獲得指標の詳細

┌──────┬────────────────────────────────────────┐
│ CVR   │ コンバージョン率 = CV数 ÷ セッション数（%）     │
│       │ 「サイトに来た人の何%が購入・申込したか」        │
├──────┼────────────────────────────────────────┤
│ CPA   │ 顧客獲得単価 = 広告費 ÷ CV数（円）             │
│       │ 「1人の顧客を獲得するためにいくらかかったか」    │
├──────┼────────────────────────────────────────┤
│ CPL   │ リード獲得単価 = 広告費 ÷ リード数（円）        │
│       │ 「1件の見込み客情報を取るのにいくらかかったか」  │
├──────┼────────────────────────────────────────┤
│ ROAS  │ 広告費用対効果 = 売上 ÷ 広告費 × 100（%）      │
│       │ 「広告1円に対して何円の売上が返ってきたか」      │
└──────┴────────────────────────────────────────┘

【例】広告費10万円 → CV 50件 → CPA 2,000円
```

**アニメーション：** 表が1行ずつ出現 → 計算例がハイライト

**ナレーション：**
「次は獲得層の指標です。こちらは直接的に「お金の効率」を測る指標になります。
CVR（コンバージョン率）は、サイトに来た人のうち何%が購入や申込などのアクションを取ったかです。CVRが低ければ、LP（ランディングページ）の改善が必要というシグナルです。
CPA（顧客獲得単価）は、1人の顧客を獲得するためにかかった広告費です。CPAが高すぎると、LTV（後述）との比較で赤字になるリスクがあります。
CPLはリード獲得単価。BtoB企業でよく使われ、問い合わせや資料請求1件にかかったコストです。
ROAS（ロアス）は広告の費用対効果です。ROAS 300%なら広告費1円に対して3円の売上が生まれたことを意味します。
これらの指標は単体で見るより、LTVと組み合わせて『許容できるCPAはいくらか』を計算することが重要です。」

### スライド 7：継続指標の詳細——LTV・チャーン率・NPS（フレッドライヒヘルド）（4:40〜5:30）

**スライド内容：**
```
【見出し】継続指標の詳細

【LTV（Life Time Value：顧客生涯価値）】
　定義：1人の顧客が生涯にわたって自社にもたらす総売上
　例）月額3,000円のサービスを平均2年継続
　　　→ LTV = 3,000円 × 24ヶ月 = 72,000円
　目安：LTV > CPA × 3 で収益性が安定

【チャーン率（解約率）】
　定義：一定期間内にサービスを解約した顧客の割合
　例）月初100人 → 月末に5人解約 → チャーン率 5%
　ポイント：チャーン率1%の改善が利益に大きく影響する

【NPS（Net Promoter Score）】
　定義：「この会社を友人・知人に薦める可能性は？」
　　　　0〜10点で回答 → 推奨者% − 批判者% = NPS
　出典：Fred Reichheld, HBR（2003）
　ポイント：顧客ロイヤルティと将来の収益成長を予測する指標
```

**アニメーション：** LTV → チャーン率 → NPS の順に出現。LTVの計算例がステップ表示

**ナレーション：**
「継続層の3指標を解説します。初学者の方には少し難しく聞こえるかもしれませんが、一つずつ丁寧に見ていきます。
まずLTV、顧客生涯価値。一言で言うと『1人の顧客が一生涯で自社にいくら使ってくれるか』です。月額3,000円のサービスを平均2年使ってくれるなら、LTVは72,000円。このLTVがわかると、CPA、つまり顧客獲得にいくらまでかけていいかの上限が計算できます。
次にチャーン率（解約率）。一定期間内に離脱した顧客の割合です。月100人のユーザーのうち5人が解約すれば、チャーン率は5%。一見小さな数字ですが、チャーン率が高いとどれだけ新規顧客を獲得しても、バケツの穴から水が漏れるように成長が止まります。
最後にNPS、ネット・プロモーター・スコード。フレッド・ライヒヘルドが2003年にハーバード・ビジネス・レビューで提唱した指標です。『この会社を友人に薦めますか？』を0〜10点で聞き、推奨者の割合から批判者の割合を引いた数値がNPSです。顧客ロイヤルティと将来の収益成長を予測する指標として世界中の企業が活用しています。」

### スライド 9：短期指標と長期指標のバランス——CVだけ追うと失敗する理由（6:20〜7:10）

**スライド内容：**
```
【見出し】短期 vs 長期：指標のバランスを取る

【出典】Les Binet & Peter Field
　『The Long and the Short of It』（2013）
　IPA（英国広告業協会）の大規模研究：約1,400件の広告キャンペーン分析

【主な知見】
┌────────────────┬────────────────────┐
│ 短期施策（0〜6ヶ月） │ 長期施策（1〜3年）        │
│ 刺激→即時反応       │ ブランド構築→将来の収益    │
│ CVR / ROAS / CPA    │ ブランド認知率 / NPS      │
│ セールスや割引       │ コンテンツ・PR・ブランド広告 │
│ 計測しやすい         │ 計測しにくい              │
└────────────────┴────────────────────┘

【結論】最適な予算配分（業種による）
　短期：長期 ＝ 約 40：60 が平均的に効果的

【陥りやすい罠】
コンバージョンだけ追うと…
　→ ブランドが弱体化 → 将来の顧客獲得コストが上昇
```

**アニメーション：** 比較表が左右同時に出現 → 最適配分の数字がハイライト → 罠の説明がフェードイン

**ナレーション：**
「指標を設計するうえで、もう一つ意識してほしいことがあります。短期指標と長期指標のバランスです。
イギリスの広告研究者、レス・ビネットとピーター・フィールドは、1,400件以上の広告キャンペーンを分析した著書『The Long and the Short of It』でこう指摘しています。短期的なコンバージョンを追うだけでは、長期的なブランド資産が育たないと。
短期施策はCVRやROASなど計測しやすい指標で成果が見えます。一方、ブランド構築は認知率やNPSの向上として現れ、効果は1〜3年という長いタイムスパンで出てきます。
研究によれば、短期と長期の予算配分は約40対60が平均的に効果的とされています。
コンバージョンだけを追い続けると、ブランドが弱まり、将来の顧客獲得コストが上昇するという悪循環に陥ります。KPIの設計では、短期と長期の指標を必ずセットで持つことが大切です。」

### スライド 10：A/Bテストの基本——仮説→実験→計測→改善のサイクル（7:10〜8:00）

**スライド内容：**
```
【見出し】A/Bテストで指標を改善する

【PDCAサイクル図】

  ① 仮説を立てる
　「ボタンの色を変えれば CTR が上がるはず」
         ↓
  ② A案 vs B案 を用意する
　A案：現行デザイン  B案：変更版デザイン
         ↓
  ③ 同条件で測定する
　ランダムに半数ずつ振り分け → 統計的有意差を確認
         ↓
  ④ 勝者を実装 → 次の仮説へ

【A/Bテストの鉄則】
・一度に変える変数は1つだけ
・サンプル数が十分になるまで待つ（焦らない）
・統計的有意差（p値 < 0.05）を確認してから判断する
```

**アニメーション：** サイクル図が①→②→③→④と順番にビルドアップ → 鉄則が1行ずつ出現

**ナレーション：**
「KPIを設定したら、次はその数字を継続的に改善していく仕組みが必要です。そこで活用するのがA/Bテストです。
流れはシンプルです。まず仮説を立てる。『CTAボタンの色を赤から緑に変えるとクリック率が上がるのでは？』というように、具体的な仮説を一つ用意します。
次にA案（現行）とB案（変更版）を用意し、ユーザーをランダムに2グループに分けて同じ条件で計測します。
結果に統計的な有意差があれば、勝者のデザインを本番に実装。そしてまた次の仮説へ。このサイクルを繰り返すことで、指標が継続的に改善されます。
注意点が3つあります。変える変数は一度に一つだけ。複数同時に変えると、どの変更が効果をもたらしたかわからなくなります。十分なサンプル数が集まるまで判断しない。そして統計的有意差を必ず確認する。焦って途中で止めると、誤った結論を導きます。」

### スライド 11：指標の設計ステップ——KGI→KPI→アクションへの落とし込み（8:00〜8:40）

**スライド内容：**
```
【見出し】指標を設計する5ステップ

Step 1：KGI を決める
　「最終的に何を達成したいか」を数値で定義する
　例）半年後に月間売上300万円

Step 2：KGIを分解してKPIを設定する
　例）月間CV数150件 × 客単価2万円 = 300万円

Step 3：KPIに紐づく先行指標（KSI）を選ぶ
　例）週次LP訪問数・フォーム到達率

Step 4：バニティメトリクスを除外する
　「その指標でアクションを変えられるか？」で精査する

Step 5：計測・レビューのリズムを決める
　例）週次でKPIダッシュボードを確認、月次でKGIをレビュー

【参考】Bendle et al.『Marketing Metrics』3rd ed.（2016）
```

**アニメーション：** Step 1〜5が順番にビルドアップ

**ナレーション：**
「ここまで学んだことを踏まえて、指標を実際に設計する5ステップを整理します。
ステップ1は、KGIを数値で定義すること。『売上を上げたい』では測れません。『半年後に月間売上300万円』のように具体化します。
ステップ2は、KGIを分解してKPIを設定すること。300万円の売上なら、『150件のCV × 客単価2万円』というように、掛け算で分解します。
ステップ3は、KPIに先行する指標（KSI）を選ぶこと。CV数の前に何の数字が増えれば良いかを考えます。
ステップ4は、バニティメトリクスを除外すること。『この指標を見てアクションを変えられるか？』と問い直します。
ステップ5は、計測とレビューのリズムを決めること。週次でKPIを確認し、月次でKGIをレビューするなど、定期的な見直しの仕組みを設けることが指標を形骸化させないカギです。」
