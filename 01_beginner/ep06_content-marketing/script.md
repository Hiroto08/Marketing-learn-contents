```

　　　　　　なぜそれが可能なのか？

【比較図：2つの集客方法】

　広告（Push型）              コンテンツ（Pull型）
　────────                   ────────
　出稿すれば人が来る           記事・動画を蓄積
　止めれば止まる               止めても読まれ続ける
```

なぜそれが可能なのか。答えは、コンテンツが『資産』として積み上がるからです。
広告はお金を出している間だけ人が来ます。止めれば、ぴたりと集客も止まります。
一方でブログ記事や動画は、公開した瞬間からインターネット上に残り続け、1年後も3年後も検索されて読まれます。
つまり、コンテンツに費やした時間とお金は、じわじわと資産になっていく。これがコンテンツマーケティングの根本的な発想です。」

### スライド 4：従来型広告 vs コンテンツマーケティング——「割り込み型 vs 許可型」（2:10〜3:00）

**スライド内容：**
```
【見出し】広告 vs コンテンツ——セス・ゴーディンの問題提起

　割り込み型マーケティング（Interruption Marketing）
　→ テレビCM・バナー広告・飛び込み営業
　→ 見たくない人に無理やり届ける
　→ 消費者は免疫をつけて無視するようになった

　許可型マーケティング（Permission Marketing）
　→ 相手が「受け取りたい」と思う情報を届ける
　→ 信頼の積み上げがベースにある
　→ コンテンツマーケティングはこちらの流れ

【現実のデータ】
広告ブロッカー利用率：世界で約42%（2023年）
```

**アニメーション：** 割り込み型の問題点を✕で表示 → 許可型が○で表示 → データが出現

**ナレーション：**
「1999年、マーケティング思想家のセス・ゴーディンは著書『パーミッション・マーケティング』の中で、従来の広告に対する鋭い問題提起をしました。
テレビCM、バナー広告、飛び込み営業——これらはすべて、相手が望んでいないのに割り込む『インタラプション型』のマーケティングだ、と。
当初から20年以上が経ち、この指摘はさらに現実的になっています。現在、世界のインターネットユーザーの約4割が広告ブロッカーを使っています。
つまり、お金をかけた広告が最初から見られていないのです。
その反省から生まれたのが、相手が自ら求める情報を先に届ける『許可型』の発想。コンテンツマーケティングは、まさにこの流れに乗っています。」

### スライド 5：ZMOT——購入前にGoogleで調べる行動（3:00〜3:50）

**スライド内容：**
```
【見出し】ZMOT（ゼロ・モーメント・オブ・トゥルース）
Google × Jim Lecinski（2011）

【従来の購買モデル】
　刺激（広告を見る）→ 店頭（First Moment）→ 購買

【ZMOTを加えたモデル】
　刺激（広告を見る）
　　　↓
　ZMOT：Googleで調べる・口コミを読む・比較する
　　　↓
　店頭 or ネット購買

【データ】購入前にオンライン調査をする消費者の割合
　2011年: 70% → 現在: ほぼ全員

【結論】「調べられたとき、そこにいること」が最重要
```

**アニメーション：** 従来モデル → ZMOTが加わるモデルへと変化するアニメーション

**ナレーション：**
「コンテンツマーケティングが重要な理由をもうひとつ。Googleが2011年に発表した調査レポートに『ゼロ・モーメント・オブ・トゥルース』、略してZMOT（ズィーモット）という概念があります。
人は何かを買う前に必ずオンラインで調べるようになった、という行動の変化を示したものです。
たとえば、友人に飲食店を勧められた瞬間、あなたはどうしますか？たいていスマホを取り出してGoogleで検索しますよね。
レビューを読み、他の店と比較し、公式サイトを見て、ようやく行くかどうかを決める。
この『調べる瞬間』が購買決定に大きな影響を与えます。
だからこそ、その調べる瞬間に自分のコンテンツが表示されていることが重要なのです。コンテンツマーケティングの目的のひとつは、まさにこのZMOTに存在することです。」

### スライド 6：TOFU・MOFU・BOFUフレームワーク（3:50〜4:50）

**スライド内容：**
```
【見出し】コンテンツを「購買ファネル」で設計する

【ファネル図（上から下へ幅が狭まる漏斗）】

　┌────────────────────┐
　│     TOFU（認知層）        │  ← 広い
　│  まだ商品を知らない人      │
　├────────────────────┤
　│     MOFU（検討層）        │
　│  興味はあるが迷っている人  │
　├────────────────────┤
　│     BOFU（転換層）        │  ← 狭い
　│  購入を検討している人      │
　└────────────────────┘

TOFU = Top of Funnel   / 「出会い」の段階
MOFU = Middle of Funnel / 「育て方」の段階
BOFU = Bottom of Funnel / 「後押し」の段階
```

**アニメーション：** ファネルが上から順にビルドアップ → 各英語略語の意味が出現

**ナレーション：**
「コンテンツマーケティングで非常に重要なのが、コンテンツを『購買ファネル』の段階に合わせて設計するという考え方です。
まず、ファネルとは漏斗のこと。上が広く下に向かうにつれ狭くなる形で、購買に近づくにつれて人数が減っていくイメージです。
英語略語が少し難しいので、日本語で先に整理しますね。
上の層は『まだあなたの商品を知らない人たち』。ここに出会ってもらうことが最初の目的です。これをTOFU（トーフ）と呼びます。
真ん中の層は『興味はあるけど、まだ迷っている人たち』。ここでは信頼を育てます。これがMOFU（モーフ）。
下の層は『もう少しで買いそうな人たち』。最後の一押しをする段階です。これがBOFU（ボーフ）。
それぞれの段階でまったく違うコンテンツが必要になります。次のスライドから具体的に見ていきましょう。」

### スライド 7：TOFUコンテンツの作り方——「発見される」設計（4:50〜5:40）

**スライド内容：**
```
【見出し】TOFU（認知層）：発見されるコンテンツ

目的：まだ知らない人に「存在を知ってもらう」

【主なコンテンツ形式】
・SEO記事（「〇〇 とは」「〇〇 やり方」などの検索流入）
・YouTube動画（How-to系・教育コンテンツ）
・SNS投稿（Instagram / TikTok / X で拡散）
・インフォグラフィック・プレスリリース

【設計のポイント】
✅ 商品の宣伝はしない
✅ 読者の「困りごと」や「疑問」に答える
✅ 検索されやすいキーワードで作る

【例】料理教室のTOFUコンテンツ
　→「簡単にできる時短レシピ10選」（宣伝ゼロ）
```

**アニメーション：** コンテンツ形式がアイコンとともに出現 → 設計ポイントが1行ずつビルドアップ

**ナレーション：**
「まずTOFU、認知層のコンテンツです。ここでの目的は『まだあなたのことを知らない人に、見つけてもらうこと』です。
使う手段は、SEO記事、YouTube動画、SNS投稿など。
一番大事なポイントは、ここでは商品を売ろうとしないことです。
たとえば料理教室を経営しているとします。TOFUコンテンツは『料理教室の紹介』ではなく、『忙しい共働き夫婦でも作れる時短レシピ10選』のような記事や動画です。
これを読んだ人は料理教室の存在を知らなくても、有益な情報を得て満足します。そしてそのブログや動画を通じて、運営者の名前を少しずつ認識していく。
これが最初の接点であり、信頼の始まりです。」

### スライド 8：MOFUコンテンツの作り方——「育てる」設計（5:40〜6:30）

**スライド内容：**
```
【見出し】MOFU（検討層）：信頼を育てるコンテンツ

目的：「この人（会社）は信頼できる」と思ってもらう

【主なコンテンツ形式】
・比較記事・選び方ガイド（「〇〇 vs △△」「失敗しない選び方」）
・事例紹介・お客様の声（Before/After）
・無料ツール・テンプレート・チェックリスト
・メールマガジン・ニュースレター
・ウェビナー・無料セミナー

【設計のポイント】
✅ 「なぜあなた（私たち）なのか」を伝える
✅ 読者の疑問・不安を先回りして解消する
✅ 継続接点（メルマガ登録など）を作る

【例】料理教室のMOFUコンテンツ
　→「通い続けた生徒3名の3ヶ月変化レポート」
```

**アニメーション：** コンテンツ形式リスト → 設計ポイントが出現 → 例がハイライト

**ナレーション：**
「次はMOFU、検討層のコンテンツです。ここに来た人は、あなたのことを多少知っている状態です。でも、まだ買う決断はしていない。
この層に必要なのは、『信頼を育てる』コンテンツです。
HubSpotの調査によると、購買前に平均して3〜5本以上のコンテンツに触れてから意思決定をするというデータがあります。
つまり、1本の記事だけで決めてもらうのは難しい。だからこそ、メールマガジンやニュースレターで継続的に接触し続ける仕組みが効果的です。
料理教室の例で言えば、『実際に通った生徒さんの3ヶ月変化レポート』はMOFUの王道です。数字と具体的なエピソードで、効果と安心感を同時に伝えられます。
ここでのポイントは、相手の不安と疑問を先回りして丁寧に解消することです。」

### スライド 9：BOFUコンテンツの作り方——「転換する」設計（6:30〜7:10）

**スライド内容：**
```
【見出し】BOFU（転換層）：購買を後押しするコンテンツ

目的：「今、行動しよう」と決断してもらう

【主なコンテンツ形式】
・ランディングページ（LP）
・お客様のレビュー・推薦文（Testimonial）
・よくある質問（FAQ）
・無料トライアル・デモ・体験版
・期間限定オファー・特典

【設計のポイント】
✅ 最後の不安・疑問をゼロにする
✅ 行動を促す明確なCTA（次のステップ）を置く
✅ 「今やらないとどうなるか」リスクを見せる

【例】料理教室のBOFUコンテンツ
　→「無料体験レッスン申し込みページ」
　　＋「よくある質問10問」＋「先輩生徒の声20件」
```

**アニメーション：** コンテンツ形式と設計ポイントが順に出現 → 例が強調

**ナレーション：**
「最後はBOFU、転換層のコンテンツです。ここに来た人はほぼ購入意欲があります。残っているのは、最後の小さな不安だけです。
その不安を取り除くことが、BOFUコンテンツの役割です。
よくある質問ページ、実際のお客様の声、無料体験——これらは全部、最後の一歩を踏み出すための背中を押すものです。
注意したいのは、BOFUのコンテンツをTOFUで使ってしまうことです。まだあなたのことを知らない人に、いきなり『今すぐ申し込み！』と言っても逆効果です。
TOFU・MOFU・BOFUは、それぞれの心理状態に合わせて設計するからこそ効果が出ます。
アン・ハンドレイは著書『Everybody Writes』の中で、『コンテンツは読者のどの段階に届いているかで、まったく別の言葉を使うべきだ』と述べています。」

### スライド 10：コンテンツを「資産」にするための継続設計（7:10〜8:00）

**スライド内容：**
```
【見出し】コンテンツを資産にする2つの仕組み

① コンテンツカレンダー（継続配信の設計）
　・週1本・月4本など、無理のないペースを決める
　・テーマをTOFU/MOFU/BOFUで比率設計する
　　（例：TOFU 60% / MOFU 30% / BOFU 10%）
　・季節・イベントに合わせた企画を先出しする

② リパーパス戦略（1つを多展開）
　1本のブログ記事
　　→ YouTube動画のスクリプトに
　　→ Instagram投稿3枚に分解
　　→ メルマガのコンテンツに
　　→ 半年後にリライトして上位表示を狙う

【ポイント】コンテンツは「積み上げ」で効果が出る
```

**アニメーション：** ①と②が別々にビルドアップ → リパーパスのフローが矢印で展開

**ナレーション：**
「コンテンツマーケティングで多くの人が挫折する理由が『継続できない』ことです。
そこで重要なのが、2つの設計です。
まずコンテンツカレンダー。週に何本投稿するかを先に決め、TOFU・MOFU・BOFUの比率もある程度設計しておきます。
目安としては、認知を広げるTOFUを全体の6割、信頼を育てるMOFUを3割、転換を狙うBOFUを1割というバランスが参考になります。
もうひとつがリパーパス戦略。これは1つのコンテンツを複数のフォーマットに展開する手法です。
1本書いたブログ記事を、YouTube動画のスクリプトにも、Instagram投稿の分解ネタにも、メルマガにも使い回せます。
これで制作コストを下げながら、多くのチャネルに存在できます。」

### スライド 11：実践例——HubSpotのコンテンツマーケティング戦略（8:00〜8:50）

**スライド内容：**
```
【見出し】実践例：HubSpot の戦略

【HubSpotとは】
マーケティング支援SaaS企業（2006年創業、米国）
年間売上 約2,600億円（2023年）

【コンテンツマーケティング戦略の柱】
① ブログ：毎日更新、SEO記事で月間数百万PV
　　→「マーケティングとは」「メール配信のコツ」等のTOFU記事

② 無料ツール：CRMやメール配信ツールを永久無料で提供
　　→ MOFU：使い続けるうちに有料版へ

③ 認定資格・無料コース：「HubSpot Academy」
　　→ 業界人材の育成を通じてブランド信頼を獲得

【結果】
広告費より多くのリードをコンテンツで獲得
HubSpot "State of Marketing Report" 2024 より：
コンテンツマーケティングを実施している企業は
そうでない企業に比べてリード獲得コストを
約60%削減できるという報告も
```

**アニメーション：** HubSpotの戦略3柱が①②③と順に出現 → 結果データが強調

**ナレーション：**
「コンテンツマーケティングの成功事例として、世界で最も有名な企業のひとつがHubSpotです。
マーケティング支援のSaaSツールを提供するこの会社、実は自社のマーケティング方法自体がコンテンツマーケティングの教科書になっています。
