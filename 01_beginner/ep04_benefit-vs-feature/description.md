## メイン説明文

```
ベネフィットと特徴の違いを、2ヶ月35万円でも累計10万人に選ばれたRIZAPの実話1本で解説します。
機能やスペックを丁寧に語るほど売れなくなる理由と、特徴を「客の得る結果」に翻訳する4つの問いが分かります。

街のジムは月数千円。その中で高価格のRIZAPが売っていたのは、マシンでも回数でも安さでもなく「なりたい自分＝結果」でした。

この動画では以下のことを解説します：
✅ 2012年の1号店から約6年で累計会員10万人（RIZAP公式PR・2018年4月）に至った「結果にコミット」の実話
✅ 特徴（事実）とベネフィット（客の得る結果）の違い——レビット「ドリルと穴」
✅ 特徴を売れる言葉に変える「だから何？」変換と、ベネフィットの3つの層
✅ 明日からできる1アクション：自社の特徴を1つ選んで「だから何？」を3回くり返す

※ナレーションはAI音声合成（VOICEVOX:玄野武宏）を使用しています。
```
