# 第4回：商品の魅力を言語化する「ベネフィット」と「特徴」の違い

## 動画基本情報

| 項目 | 内容 |
|------|------|
| 想定尺 | 10分（±1分） |
| 難易度 | 初級 |
| 対象視聴者 | 「自社商品の良さを伝えているのに反応が薄い」「スペックを並べても売れない」と感じている方 |

### スライド 4：ベネフィット（Benefit）とは何か（2:00〜2:50）

**スライド内容：**
```
【見出し】ベネフィット（Benefit）とは

定義：
「顧客が商品を使うことで得られる価値・結果・変化」

変換ルール：「〇〇（特徴）、だから〇〇（ベネフィット）」

例：
・ビタミンC 1,000mg  →  風邪をひきにくい体に
・防水加工          →  雨の日も気にせず使える
・処理速度 3.2GHz   →  動画編集が待ちなく快適に進む

→ ベネフィット＝「顧客の人生にどんな良いことが起きるか」
```

**アニメーション：** 変換ルール → 例が特徴→ベネフィットで変換されるアニメーション（→で繋ぐ）

**ナレーション：**
「ベネフィットとは、顧客がその商品を使ったことで得られる価値・結果・変化のことです。
変換のルールはシンプルで、『○○（特徴）だから○○（ベネフィット）ができる』と繋げるだけです。
防水加工——だから雨の日も傘を持ちながらスマホを見ても大丈夫。
処理速度3.2GHz——だから動画編集中に固まるストレスがゼロになる。
ベネフィットの本質は『顧客の人生にどんな良いことが起きるか』です。これが伝わると、人は動きます。」

### スライド 6：ベネフィットの3段階（3:30〜4:30）

**スライド内容：**
```
【見出し】ベネフィットは3つの層で考える
（David Aaker, 1991 を参考に）

【ピラミッド図：下から上へ】

　　　　▲ 自己表現的ベネフィット（最上層）
　　　  ── 「使うことで得られる自己イメージ」
　　 ▲▲▲ 感情的ベネフィット（中層）
　　 ── 「使うことで生まれる感情・気持ち」
▲▲▲▲▲ 機能的ベネフィット（基層）
　 ── 「使うことで解決される具体的問題」

→ 多くの企業が「機能的」しか伝えていない
→ 購買決定に強く影響するのは「感情的・自己表現的」層
　（Kahneman, 2011：人は感情で選んで、論理で正当化する）
```

**アニメーション：** ピラミッドが下から積み上がる → 各層に説明がスライドイン

**ナレーション：**
「ベネフィットはデービッド・アーカーのブランド理論を参考にすると、3つの層に分けて考えられます。
最下層は機能的ベネフィット。具体的な問題が解決されること。
中層は感情的ベネフィット。使ったときに感じる気持ちや満足感。
最上層は自己表現的ベネフィット。それを使うことで、どんな自分を表現できるか。
多くの企業が機能的ベネフィットしか伝えていませんが、カーネマンの研究が示すように、人間の意思決定は感情に大きく左右されます。上の2層を意識するだけで、コミュニケーションの質が大きく変わります。
さらに実務で重要な視点を加えると、機能的ベネフィットだけで選ばれているブランドは、同等機能の競合が現れたら乗り換えられます。感情的・自己表現的ベネフィットが強いブランドは、価格が多少高くても顧客が離れにくい。これがブランドのスイッチングコストを上げる仕組みです。」

```
　特徴：電解質・糖分を含む等張飲料

　「運動後の水分・塩分補給が素早くできる」
　「バテにくく、パフォーマンスが持続する」

→ 理性的な「納得感」を生む層

```

**アニメーション：** 特徴→機能的ベネフィットの変換がビルドアップ

**ナレーション：**
「機能的ベネフィットは最も基本的な層で、商品を使うことで具体的な問題が解決されることです。
スポーツドリンクで例えると、『電解質を含む』という特徴を機能的ベネフィットに変換すると、
『運動後のバテを防ぎ、パフォーマンスが持続する』になります。
この層は顧客の理性的な『納得感』を生みます。比較検討の場で競合に勝つためには、機能的ベネフィットをしっかり伝えることが必要です。」
