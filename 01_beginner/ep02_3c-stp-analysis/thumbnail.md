## ビジュアルイメージ

| 要素 | 内容 |
|------|------|
| 背景 | 濃紺グラデーション（#0B1220 → #1A1A40）。シリーズ共通 |
| 人物・キャラクター | なし |
| アイコン・図解 | 3つの重なる円（ベン図・3Cを表現）またはダーツの的アイコン |
| 強調箇所 | 「3C」「STP」をアクセントカラー（緑）で強調。「第2回」バッジを左上に配置 |

| 役割 | カラーコード | 用途 |

| アクセントカラー | `#4ADE80` | キーワード強調・枠線・ベン図（第2回固有：緑＝成長・分析） |
| テキストカラー | `#EEEEF8` | 本文テキスト（シリーズ共通） |
| サブアクセント | `#7C6FFF` | シリーズバッジ・小見出し（シリーズカラーで統一感を出す） |
