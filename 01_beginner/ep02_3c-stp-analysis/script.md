### スライド 4：Customer（顧客）分析（2:00〜2:50）

**スライド内容：**
```
【見出し】① Customer（顧客・市場）

問うべき問い：
・市場規模はどのくらいか？（成長？縮小？）
・顧客は何に困っているか？（顕在ニーズ）
・顧客が気づいていないニーズは何か？（潜在ニーズ）
・購買意思決定は誰が・いつ・どこでするか？

【ポイント】
顧客を「統計」ではなく「人間」として理解する
```

**アニメーション：** 問いが1行ずつ表示 → ポイントが強調表示

**ナレーション：**
「最初のCは顧客分析です。ここで確認するのは、市場の規模や成長性だけではありません。
顧客が『今すでに感じている困りごと』、つまり顕在ニーズ。
そして顧客自身も気づいていない『潜在ニーズ』。さらに、誰がいつどこで買うかという購買行動まで。
大切なのは、数字だけでなく顧客を1人の人間として理解しようとする姿勢です。
ここで陥りやすい落とし穴が1つあります。それは既存顧客だけを見ていると、新しい市場の変化や潜在顧客を見落とすリスクがあるという点です。また、購買意思決定者と実際の利用者が違うケースも意識してください。たとえば学習教材は、買うのは親ですが使うのは子どもです。この2者のニーズは異なるため、どちらにどう訴求するかも考える必要があります。」

### スライド 5：Competitor（競合）分析（2:50〜3:30）

**スライド内容：**
```
【見出し】② Competitor（競合）

問うべき問い：
・直接競合は誰か？（同じカテゴリの商品）
・間接競合は誰か？（別カテゴリで同じニーズを満たすもの）
・競合の強み・弱みは何か？
・市場シェアの分布は？

【例】コーヒーショップの競合
　直接競合：他のカフェチェーン
　間接競合：コンビニコーヒー、自動販売機、在宅ワーク
```

**アニメーション：** 直接・間接競合の例がビルドアップ

**ナレーション：**
「2つ目のCは競合分析です。競合といえば同業他社だけを考えがちですが、『間接競合』も重要です。
例えばカフェの場合、他のカフェチェーンが直接競合。
でも顧客の『ちょっと休みたい』というニーズを満たしているコンビニコーヒーや公園のベンチも、ある意味では競合です。
競合の強みと弱みを知ることで、自社がどこで戦うべきかが見えてきます。
さらに、競合の定義をもう一段広げる視点も持っておきましょう。たとえば映画館の競合は、他の映画館だけではありません。NetflixやYouTube、あるいは友人との外食も競合になりえます。顧客の限られた時間とお金を奪い合っているものすべてが競合です。この広い視野で考えると、本当に戦う相手と戦い方が見えてきます。」

### スライド 6：Company（自社）分析と3C統合（3:30〜4:30）

**スライド内容：**
```
【見出し】③ Company（自社）＋ 3Cの統合

Company で問うべき問い：
・自社の強みは何か？（他社にない資源・能力）
・自社の弱みは何か？
・ブランドの認知・信頼度は？

【図解：KSF】
  Customer              Competitor
  （顧客が求めるもの）  （競合が提供していないもの）
         ↘                ↙
          【KSF：Key Success Factor】
              戦略の勝ち筋
         ↗
  Company
  （自社が得意なこと）

→ 3つが重なる点 = 「やるべきこと」
```

**アニメーション：** Companyの問いが出現 → 3方向から矢印が集まってKSFが光る

**ナレーション：**
「3つ目のCは自社分析。ここで重要なのは、自社が『できること』ではなく、
『競合と比べたときに優位に立てること』を正直に棚卸しすることです。
これを経営学では『コア・コンピタンス』と呼びます。
3Cを統合すると、戦略の勝ち筋が見えます。
顧客が求めていて、競合がまだ提供しておらず、自社が得意なこと——この3つが重なる領域。
これをKSF、重要成功要因と呼びます。ここを起点に戦略を組み立てるのが、3C分析の本来の使い方です。
では、KSFはどうやって見つけるのか。実践的な流れとしては、まず顧客インタビューで本当に価値を感じている点を洗い出します。次に、競合がまだ十分に提供できていない空白を特定します。そして最後に、自社の強みと突き合わせる。この順番で考えると、根拠のある勝ち筋が見えてきます。なお、KSFは一度決めたら終わりではなく、市場の変化に合わせて定期的に見直すことが大切です。」

### スライド 9：T——Targeting と P——Positioning（5:50〜7:00）

**スライド内容：**
```
【見出し】T：Targeting（ターゲット選定）

選定の基準（Kotler, 2016）：
① 規模と成長性　② 収益性　③ 競合状況　④ 自社適合性

→ 中小・スタートアップには「集中型（1セグメント絞り込み）」が有効

---

【見出し】P：Positioning（ポジショニング）

「ターゲットの頭の中に、競合と異なる場所を確保する」
（Trout & Ries, 1981）

【ポジショニングマップ：コーヒー市場】

    高価格・高品質
         ↑
スタバ ●          ● 高級カフェ
←──────────────────→
大衆向け          こだわり向け
コンビニ●    ● ドトール
         ↓
    低価格・手軽さ
```

**アニメーション：** Targeting → Positioning の順にビルドアップ。マップはブランドが1つずつプロット

**ナレーション：**
「TのTargetingでは、セグメントの中から実際に狙う層を選びます。基準は規模・収益性・競合状況・自社との適合性の4点。
リソースが限られる中小企業には、1つに集中する戦略が有効です。
実は中小企業がよく犯す間違いの1つが、最初から広すぎる市場を狙ってしまうことです。「なるべく多くの人に売りたい」という気持ちは理解できますが、その結果どこにでもいるような存在になってしまいます。まず特定の層で圧倒的な存在感を持つ、一点突破の戦略が結果的には近道です。
最後のPはPositioning。ポジショニングとは、ターゲットの頭の中に競合と異なる場所を確保することです。
有名なのがポジショニングマップ。2軸でブランドを配置すると、競合が密集している場所と空白地帯が見えます。
スタバは高価格×大衆向け、コンビニは低価格×手軽さ——それぞれ異なる場所を取っていますね。自社が入るべき空白はどこか。これがポジショニングの問いです。」

### スライド 11：3CとSTPの関係（8:00〜8:40）

**スライド内容：**
```
【フロー図】

3C分析（状況把握）
　├ Customer → 市場・ニーズを理解
　├ Competitor → 競合の動きを把握
　└ Company → 自社の強みを確認
　　　　↓
STP分析（戦略設計）
　├ Segmentation → 市場を分ける
　├ Targeting → 狙う層を選ぶ
　└ Positioning → 差別化の立ち位置を決める
　　　　↓
　　4P（施策実行）← 第7回で解説
```

**アニメーション：** フローが上から下へ順に出現

**ナレーション：**
「3C分析とSTP分析の関係を整理しましょう。3C分析は市場の状況を把握するフェーズ。
STP分析はその情報をもとに、具体的な戦略を設計するフェーズです。
この2つを経て、初めて広告や価格設定などの具体的な施策——第7回で解説する4P——に入ります。
フレームワークを使う順番を意識するだけで、戦略の質が大きく変わります。
この順番を守ることで、すべての施策に戦略的な根拠が生まれます。逆に順番を飛ばして「とりあえず広告を出してみよう」と施策から入ると、広告・価格・商品設計がそれぞれバラバラな方向を向いてしまいがちです。土台となる分析と戦略があってこそ、施策が一本の線でつながります。」

## 制作メモ

- **想定ナレーション文字数：** 約2,900字（10分目安）
- **視覚的なポイント：** ポジショニングマップはアニメーションで動かすと印象的（ブランド名が1つずつプロット）
- **コンビニコーヒーの数値：** セブン&アイHDの公式IRや報道を確認の上、最新データに更新すること
- **BGM：** 前回と統一（Lo-Fiインスト）
- **テロップ：** 3C・STP・KSFなどの用語は必ずテロップで補助
