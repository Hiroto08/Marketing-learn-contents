## メイン説明文

```
STP分析のやり方を、10分1000円カット「QBハウス」の実話1本で解説。売る相手の決め方が分かります。
客を絞ったのに、のべ3億人が来た——「全員に売ろうとすると誰にも売れない」理由と、勘に頼らず売る相手を決める手順を10分で。

良い商品なのに売れないとき、多くの人はもっと広く宣伝しようとします。しかし先に決めるべきは「誰に売って、誰に売らないか」のほうです。

この動画では以下のことを解説します：
✅ 業界未経験・55歳で創業した小西國義さんが、市場調査の数字（不満3割・利用意向30%＝想定の6倍）で常識に逆らい、1996年・神田の1号店から691店舗・売上収益247億円（2024年6月期）まで育てた実話
✅ 3C分析（大前研一、1982）で「勝てる場所」を見つけ、STP（コトラー）で「切る・選ぶ・置き場所を決める」標準手順
✅ 「20代から60代の男女」という一番よくある罠と、明日からできる最初の1アクション（売らない相手を1行書く）
```
