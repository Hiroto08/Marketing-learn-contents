各45〜60秒。冒頭3秒に本編と同じアンカー。末尾は長編への橋渡し。AI音声（VOICEVOX 玄野武宏）使用を開示。

## Short① リフック素材：数字ゼロの企画書（KW型タイトル）

**タイトル案：** 「その客、実在しない」のに53店舗【ペルソナの作り方】

**台本（約55秒）：**
```
（0-3秒／アンカー）その顧客は、この世に実在しません。年収も、購買データもゼロ。
（〜40秒）それなのに、この“架空のたった1人”が、全国53店舗・売上99億円のチェーンを生みました。
スープストックトーキョーの伝説の企画書には、数字が一切ありません。書かれていたのは「フォアグラよりレバニラを選ぶ」「プールに着いたらすぐクロール」——一見どうでもいい、こだわりだけ。
丁寧なペルソナ＝属性を細かく埋めた表、だと思っていませんか。成功例は、その逆でした。判断が下せる“生きた1人”かどうか、が分かれ目です。
（ラスト）ペルソナの作り方の全体像は、長編で解説しています。
```

## Short② ミニ問いかけ素材：なぜ買うのか（ジョブ理論）

**タイトル案：** ペルソナに“これ”が無いと売れない【ジョブ理論】

**台本（約50秒）：**
```
（0-3秒／アンカー）30代・女性・年収500万・インスタ好き……この属性、何個並べても売れません。
（〜40秒）なぜか。「なぜ買うのか」という肝心の理由が、抜けているからです。
手がかりはクリステンセンのジョブ理論。人は商品を“雇って”、片づけたい用事を実行してもらう。朝のミルクシェイクの本当の目的は、甘さではなく「退屈な通勤をまぎらわす」ことでした。
あなたの商品は、お客さんのどんな用事を片づけていますか。属性ではなく、この“用事”を描くのが、機能するペルソナです。
（ラスト）作り方の3つの落とし穴は、長編で解説しています。
```

## Short③ まとめの1アクション素材：なぜを3回

**タイトル案：** 顧客の本音を掘る「なぜ3回」【ペルソナの作り方】

**台本（約50秒）：**
```
（0-3秒／アンカー）ペルソナは、想像で作った瞬間、飾りになります。
（〜40秒）本音は、机の上では絶対に出てきません。だから作り方の原則は、観察。実際の顧客5名から10名に、直接聞くことです。
コツは「なぜ」を3回。なぜ買った？忙しいから。なぜ忙しいと困る？時間をムダにしたくないから。なぜ惜しい？自分の成長に使いたいから。3回で、本質の欲求までたどり着きます。
明日やることは1つ。顧客を1人思い浮かべ、その人が最近選んだ“一見どうでもいいこだわり”を、ひとつ書き出してみてください。
（ラスト）ペルソナの作り方の全体像は、長編で解説しています。
```
