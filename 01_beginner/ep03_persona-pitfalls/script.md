# 第3回：顧客の悩みを見つける「ペルソナ設定」の落とし穴

## 動画基本情報

| 項目 | 内容 |
|------|------|
| 想定尺 | 10分（±1分） |
| 難易度 | 初級 |
| 対象視聴者 | 「ペルソナを作ったのに広告・コンテンツが刺さらない」と悩む方、これからペルソナを設計する方 |
| 学習ゴール | ペルソナ設定のよくある3つの失敗を避け、顧客の「本音のニーズ」を掴む正しい設計ができる |

```
【オグルビーの言葉（意訳）】

（Ogilvy on Advertising, 1983）
```

**アニメーション：** 失敗例が出現 → 結果が強調 → 引用がフェードイン

**ナレーション：**
「1つ目の落とし穴は、実在しない顧客を想像だけで作り上げてしまうことです。
実際のお客さんにインタビューもせず、社内の『こんな人が来てほしい』という希望が混入して、リアルとかけ離れた人物像が生まれます。

### スライド 5：落とし穴 ② 自社に都合の良い人物像（3:00〜3:50）

```
→ 「刺さらない広告」の原因になる

```

**ナレーション：**

わかりやすい典型例が、商品の使い方を最初から理解している前提で設計されたペルソナです。でも現実の顧客は、その商品のことを何も知らない状態から始まります。比較もするし、疑いもします。

ペルソナには、『どんな不満を持っているか』『何が邪魔をしているか』を必ず盛り込んでください。」


**ナレーション：**

### スライド 8：ジョブ理論（JTBD）とは（5:30〜6:30）

**スライド内容：**
```
【見出し】ペルソナを深める：ジョブ理論（Jobs to Be Done）

提唱：Clayton Christensen（ハーバード・ビジネス・スクール）
出典："Know Your Customers' Jobs to Be Done"
　　　Harvard Business Review (2016)

本質的な考え方：
「人は商品を『雇用』して、自分の『ジョブ（仕事）』を片づけてもらう」

【ミルクシェイクの研究】
朝にミルクシェイクを買う理由は？
　× 「甘いものが食べたい」
　○「長い通勤時間に飽きないよう、片手で楽しめるもの」

→ 属性ではなく「行動の文脈」こそが本当のニーズ
```

**アニメーション：** ×→○の例がアニメーションで切り替わる

**ナレーション：**
「ペルソナをさらに深めるのに役立つのが、クレイトン・クリステンセンが提唱した『ジョブ理論』です。
ハーバード・ビジネス・レビューに掲載され、世界中のマーケターに影響を与えました。
中心的な考え方は『人は商品を雇用して、片づけたいジョブを実行する』というもの。
有名なミルクシェイクの研究があります。ある企業が調査したところ、
朝の購買者は『甘いものが食べたい』ではなく、『長い通勤中に退屈せずに済み、腹持ちのいいもの』というジョブのためにミルクシェイクを『雇用』していたことがわかったんです。
これが属性では見えない、行動の文脈から見えるニーズです。
ここでもう一つ洞察があります。同じミルクシェイクでも、夕方に子どもへのご褒美として買われる場合は、ジョブがまったく別物になります。つまり商品は同じでも、使われる文脈によってニーズは変わる。商品を作る側の視点ではなく、顧客がそれを使う瞬間の文脈を起点に考えることが、ジョブ理論の本質です。」

### スライド 10：情報収集法と「なぜ×3」（7:20〜8:10）

**スライド内容：**
```
【見出し】どこからデータを集めるか

一次情報（最重要）：
　・既存顧客へのインタビュー（5〜10名でOK）
　・アンケート（購入理由・迷った点・決め手）
　・問い合わせ・レビュー・SNSコメントの分析

二次情報（補助）：
　・業界レポート・政府統計
　・競合サイトのレビュー欄
　・SNS上のUGC（ユーザー投稿）

【黄金ルール】「なぜ？」を3回繰り返す
　「なぜ購入？」→「忙しいから」
　「なぜそれが問題？」→「時間がムダに感じるから」
　「なぜ時間が惜しい？」→「成長に使いたいから」
　→ 本質ニーズ：「隙間時間を成長に変えたい」
```

**アニメーション：** 一次情報が先に強調 → 「なぜ×3」の連鎖が1行ずつ出現

**ナレーション：**
「ではどこからデータを集めるか。最も価値があるのは一次情報、つまり実際の顧客に直接聞くことです。
既存顧客へのインタビューは5〜10名でも驚くほどのパターンが見えてきます。
問い合わせやレビュー、SNSのコメントも宝の山です。そこには顧客の本音の言葉があります。
特に使えるのが、SNSのコメント欄や競合商品のAmazonレビューです。星1〜2の低評価レビューには顧客の失望や不満が、星5の高評価レビューには本当に価値を感じているポイントが率直に書かれています。業界全体の顧客の声を短時間で把握できる、コストゼロの調査方法です。
インタビューでは『なぜ？』を3回繰り返す習慣が有効です。
『なぜ購入しましたか？』→『忙しかったから』→『なぜそれが問題でしたか？』→『時間がムダに感じるから』→『なぜ時間が惜しいか？』→『成長に使いたいから』。
こうやって、表面の回答の奥にある本質的なニーズを掘り起こします。」

### スライド 12：完成したペルソナの使い方（8:50〜9:20）

**スライド内容：**
```
【見出し】ペルソナはどう使うのか

施策の「判断基準」として使う：

「このコンテンツは、〇〇さん（ペルソナ名）が
　見て、読んで、行動するか？」

チームで同じ顧客を共有する：
　→「このペルソナには刺さらない」が議論の根拠になる
　→ 感覚ではなくデータと文脈で意思決定できる

【NG：ペルソナを作ったら終わり】
ペルソナは定期的に更新する（市場の変化・新データで）
```

**アニメーション：** 使い方の例文 → NG注意が強調

**ナレーション：**
「完成したペルソナは、すべての施策判断の基準に使います。
コンテンツを作る前に『このペルソナが読んで行動するか？』と問いかける。広告コピーを書く前に『このペルソナの言葉で書かれているか？』と確認する。
こうすることで、チーム全員が同じ顧客を頭に描いて動けるようになります。
ペルソナが共通言語になると、チームでの意思決定が『なんとなくこっちの方が良さそう』という感覚から、『このペルソナには刺さらない』という顧客視点に変わります。これが施策の質を底上げします。
注意点として、ペルソナは作ったら終わりではありません。市場の変化や新しいデータをもとに定期的にアップデートしていきましょう。」

## 制作メモ

- **想定ナレーション文字数：** 約3,334字（10分目安）
- **視覚的ポイント：** ミルクシェイクの例は図解（通勤路のイラスト＋ミルクシェイク）があると訴求力UP
- **引用注意：** クリステンセンの論文は2016年 HBR が一次ソース（書籍『ジョブ理論』2016年も参照可）
- **BGM：** シリーズ統一（Lo-Fiインスト）
- **テロップ：** 「ジョブ理論」「JTBD」は初出時に必ずテロップで補助
