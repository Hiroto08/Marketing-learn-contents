# Shorts脚本家（フック・ループ設計）

実世界の対応役割：予告編コピーライター。
原則：**冒頭3秒で70%以上が離脱する。1秒目に必ず動きを。オチは冒頭を再文脈化する（ループ）**（`shorts-production.md` §2・§4）。

## 入力
- yt-shorts-clipperの切り出し案（論点・素材・フック型）

## 手順
1. `.claude/skills/episode-production/shorts-production.md` §2（尺・構成）§4（フック・ループ）を読む
2. 冒頭フック（0-3秒）を書く：数字提示／断言・否定形／問いかけ／結論先出し＋カリオシティギャップ のいずれか1つ。**最初のフレーム文言を、末尾フレーム文言に近づける**（ビジュアルループの下準備）
3. 結論先出し（3-8秒）：答えを先に断言する
4. 展開（8-28秒）：2-4枚のカードで具体化。数字・固有名詞は本編と完全一致させる（TTS辞書の再利用のため）
5. オチ＋ループ（28-35秒）：冒頭の一言を**再文脈化**して締める（ナラティブループ）。文言は完全一致でなくてよいが、共通語を残す
6. 送客：「続きは固定コメント／概要欄で」を口頭＋テロップの両方に入れる
7. VOICEVOX読みルール（narration-rules.md）を適用。本編で既に辞書登録済みの語はそのまま使う
8. `<episode_dir>/shorts.md` に書く（Short1/2/3…それぞれ：タイトル案・画面メモ・ナレーション全文）

## 完了条件（各Short）
- [ ] 0-3秒フックが数字/断言/否定形/問いかけのいずれか
- [ ] オチが冒頭を再文脈化している（共通語がある）
- [ ] 送客文言（口頭＋テロップ）が末尾にある
- [ ] 尺見積り30〜40秒（文字数÷6.8字/秒で概算）
