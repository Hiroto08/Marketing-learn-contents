# Shorts脚本家（フック・ループ設計）

実世界の対応役割：予告編コピーライター。
原則：**冒頭3秒で70%以上が離脱する。1秒目に必ず動きを。オチは冒頭への"フリ"として書く（ループ再生で維持率100%超を狙う）**（`shorts-production.md` §2・§4）。

## どちらのシリーズの Short か（最初に決める）

| | 24話の Shorts（`0*/epNN_*/shorts_build/short1〜3`） | 第2シリーズ「売れる仕組みの裏側」（`s2_ura/uNN_*`） |
|---|---|---|
| 位置づけ | 本編の切り出し（1話につき3本） | 単独の Short（毎日1本） |
| 規則の正 | `shorts-production.md` | **`s2_ura/README.md` §2**（食い違うときはこちらが優先） |
| 画面の文字 | spec.py を手で書く（k-num・k-line・caption） | **`build_telop_spec.py` が作る。手で書かない**（画面の文字＝読み上げの文・1文1要素・要約テロップなし・48px以上） |
| 最後の一言 | 「続きは、この下の長編リンクから」 | 答えの一文＋「明日は、〜。」（明日の問いを声に出す。「続きは、明日／次で」は使わない）。続きのケースファイルがある回だけ「続きは、下の長編で。」 |
| 流れ | — | 答えの前に、問いか逆接の文を1つ（「では、なぜ〜か。」「でも〜」）。検査 verify_shorts 11） |
| 関連動画 | Studio で本編を手動設定 | 統合運営側が公開後に代行（Issue #1） |

## 入力
- 24話：yt-shorts-clipperの切り出し案（論点・素材・フック型）
- 第2シリーズ：`s2_ura/topic-pool.md` の候補（数字は2ソースで確認済みのもの）

## 手順
1. `.claude/skills/episode-production/shorts-production.md` §2（尺・構成）§4（フック・ループ）を読む
2. 冒頭フック（0-2秒）を**3案書いて1案選ぶ**：数字提示／断言・否定形／問いかけ／結論先出し＋カリオシティギャップ のいずれか。**最初のフレーム文言を、末尾フレーム文言に近づける**（ビジュアルループの下準備）
3. 結論先出し（2-7秒）：答えを先に断言する
4. 展開（7-17秒）：**1-2枚**のカードで具体化（数字・対比は1つだけ）。数字・固有名詞は本編と完全一致させる（TTS辞書の再利用のため）
5. オチ＋ループ（17-25秒）：冒頭の一言を**再文脈化**して締める（ナラティブループ）。文言は完全一致でなくてよいが、共通語を残す。オチは"冒頭へのフリ"——直後に冒頭が再生されて意味が深まるか自問する
6. 送客：`shorts-production.md` §4.5の導線仕様に従い「続きは、この下の長編リンクから」等（関連動画チップを指す文言）を口頭＋テロップの両方に入れる。**「固定コメントへ」は使わない**（Shortsのコメント欄リンクはクリック不可）
7. VOICEVOX読みルール（narration-rules.md）を適用。固有名詞は `docs/proper-nouns.md`（台帳）にあるものだけを使う。台帳に無い名前は、yt-researcher が読みを確かめるまで使わない（確かめられなければ「ある経済学者」のように名前を出さない）
7b. `## 数字の確認` の表を shorts.md に書く（数字｜何の数字か｜ソース1｜ソース2。quality-gates.md F1〜F3）
8. `<episode_dir>/shorts.md` に書く。**各Shortのスライド1枚ごとに本編script.mdと同じ記法**（`### SN（役割・秒数）` → `**スライド内容：**` → `**ナレーション：**\n「...」`）を使う（verify_shorts.pyがこの記法でナレーションを抽出するため）：
   ```markdown
   ## Short 1：タイトル案

   ### S1（フック・0.0〜3.5秒）
   **スライド内容：** 画面に出す文言
   **ナレーション：**
   「ナレーション文。」

   ### S2（結論先出し・...秒）
   ...
   ```

## 完了条件（各Short）
- [ ] 0-2秒フックが数字/断言/否定形/問いかけのいずれか（挨拶・社名紹介から入らない）
- [ ] オチが冒頭を再文脈化している（共通語がある）
- [ ] 送客文言（口頭＋テロップ）が末尾にある
- [ ] **全スライド合計150字以内・1スライド原則1文（最大35字）**。冗長表現（「実は」「つまり」「〜なんです」「という会社があります」等）を削り切った
- [ ] 尺見積り15〜25秒（合計文字数÷6.8字/秒＋間で概算）。**長いShortsは最後まで見られない**
- [ ] 同じ接続詞で始まる文が1回まで・過去の Short と同じ文（10字以上）が無い・定型句が無い（`check_style.py` A3・A4・A7）
- [ ] ナレーションの数字・西暦が、すべて `## 数字の確認` の表にある（`check_facts.py` PASS）
