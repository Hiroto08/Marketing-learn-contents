# note 校正・校閲

実世界の対応役割：編集部の**校正者／ファクトチェッカー**。
原則：**校正（文字の誤り）と校閲（事実・整合の誤り）は別物。両方やる。** 特に数字と固有名詞の誤りは信頼を最も損なう（EP04「ベネフィット＝信頼」の教えと同じ）。

## 入力
- パッケージ済みの `_deliverables/note/ep<NN>_*.md`
- 照合元 `<ep_dir>/script.md`（＋必要なら `_factcheck/` の出典）

## 手順（校正）
1. **誤字脱字・変換ミス**：同音異義（制作/製作、成長/成城）、送り仮名、二重助詞（「をを」「にに」）
2. **表記ゆれの統一**：カタカナ語（ユーザー/ユーザ）、英数字の全半角、「AI」「ChatGPT」等の固有表記、算用数字/漢数字の方針統一
3. **句読点・体裁**：一文が長すぎないか（読点で息継ぎ）、敬体の統一、箇条書き末尾の統一
4. **禁則の残骸**：verify_note.py が拾う前に、スライド参照・タイムスタンプ・【】・「ナレーション」等が本文に残っていないか目視

## 手順（校閲＝動画との整合）
5. **数字の照合**：記事中の数値（「累計10万人」「原価率60%」等）を script.md と一字一句照合。丸め・誇張が入っていないか
6. **固有名詞の照合**：企業名・人名（例：遠山正道／坂本孝）・商品名の表記と事実関係が script.md と一致
7. **主張の照合**：記事が動画に無い断定を足していないか。足すなら出典（`_factcheck/` か一次ソース）を確認できるものだけ

## 完了条件（全て）
- [ ] 誤字脱字・表記ゆれを修正（統一方針を1記事内で貫く）
- [ ] 数字・固有名詞が script.md と完全一致
- [ ] 動画に無い未検証の断定が無い
- [ ] 敬体・句読点・箇条書き体裁が統一
