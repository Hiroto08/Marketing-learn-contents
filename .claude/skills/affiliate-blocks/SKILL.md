# アフィリエイト資産（L2＝紹介収益）

実世界の対応役割：メディアの収益化担当。
目的：**動画で実際に触れた書籍・ツールを、信頼を損なわない形で紹介し、紹介料を得る**（収益化戦略§3-L2）。
原則：**実際に動画で引用・実演したものだけ**を貼る（EP04「ベネフィット＝信頼」の教えと矛盾する売り込みをしない）。**ステマ規制・アソシエイト規約の表記を必ず入れる**（ツールが自動付与）。

## 前提（初回1回・あなたの外部作業）
- **Amazonアソシエイト**に登録し、トラッキングID（例 `yourtag-22`）を取得
- Secrets/環境変数に `AMAZON_ASSOC_TAG` を設定（未設定だと `REPLACE-TAG-22` のプレースホルダで出力される）
- （任意）AIツールのASP：A8.net / もしもアフィリエイト等で、動画で実演したSaaSの案件を取得

## 手順
1. 書籍ブロックを自動生成（`### 主な引用・参考文献` から書籍を抽出。Amazon URLがあれば直リンク、無ければ著者+書名の検索リンク）：
   ```bash
   AMAZON_ASSOC_TAG=yourtag-22 python3 _tools/repurpose/make_affiliate.py --episode <ep_dir>
   # 全話一括は --all
   ```
   → `_deliverables/affiliate/ep<NN>_*.md`
2. **人手レビュー（必須）**：
   - 誤抽出（記事・論文が混じっていないか）を除去。判定：書籍＝『』表記、記事＝「」、論文＝英語"…"
   - 検索リンクの回は、可能なら**ASIN直リンク**（`amazon.co.jp/dp/<ASIN>?tag=…`）に差し替えると精度が上がる
   - 動画で触れたのに参考文献に無い本があれば手動追加
3. **AIツール/SaaSのASP案件を手動追記**（EP13〜16等）：生成ブロック末尾のコメント枠に、動画で実演したツールのアフィリエイトURLを足す（自動抽出はしない＝案件は個別契約のため）
4. **配置**：`メイン説明文`の下（またはチャプターの後）に貼る／note記事は末尾CTAの下に貼る。**オプトインCTAより下**（無料特典を最優先の導線に保つ）

## やってはいけないこと
- 動画で触れていない商品を「関連book」として大量に貼る（信頼を毀損＝LTV低下）
- アソシエイト表記（「※Amazonのアソシエイトとして…」）を消す（規約・法令違反）
- 書籍0冊の回に無理やり本をこじつける（0冊なら書籍ブロックは省略してよい）

## 完了条件（全て）
- [ ] 書籍リンクが実在・実際に動画で触れた本のみ
- [ ] アソシエイト表記が入っている
- [ ] （AI回）ASP案件を手動追記済み、または「無し」を確認
