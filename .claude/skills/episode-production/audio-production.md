# 音声演出・仕上げ仕様（イントロ／BGM／SFX／間／アウトロCTA）

人気コンテンツの共通点（リサーチ3本＝`docs/youtube-reform-plan.md` §10出典から抽出）を、
このチャンネルの実装ルールに落としたもの。**ビルド時は本仕様のコマンドを標準とする**。

## 抽出した共通点 → 本チャンネルの実装

| 流行コンテンツの共通点 | 根拠（リサーチ） | 実装 |
|----------------------|----------------|------|
| ブランドイントロ（ロゴアニメ等）を置かず0秒から本題 | 冒頭挨拶・自己紹介は維持率を殺す最大要因 | v2のS1コールドオープン（実装済み）。開幕0.5秒に控えめなチャイム1発のみ |
| BGMは「意識されない」音量で常時、章の変わり目・結論で変化 | Kurzgesagt×Epic Mountain のBGMアーク | ループBGMを**-21dB**で全編、冒頭1.5秒フェードイン・末尾4秒フェードアウト |
| SFXは視覚イベントに同期、ただし過剰は逆効果 | 同上（無意識レベルのSFX）＋国内合成音声チャンネルの編集慣行 | スライド切替＝whoosh、強調要素（pop/scale）＝pop。**全体で最大60発・最短間隔0.6秒**のレート制限 |
| 間（ま）は無音で作る。重要な数字・反転の直前に一拍 | 教育動画のポーズ研究（分割提示が記憶を改善） | 文末0.28秒・段落0.45秒（実装済み）。脚本側ルール：リフック・キー数字の直前で段落を切り、一拍置く |
| アウトロは新情報ゼロの静止20秒＋口頭誘導＋終了画面2要素 | 終了画面のCTR研究・公式仕様 | S18=CTAスライド（下記レイアウト）。BGMフェードアウトと重ねる |

## アセット（すべて自作・権利クリーン）

`_assets/audio/`（プロキシ制限で外部素材サイトが遮断されているため、
`_tools/audio/synth_assets.py` によるプログラム合成で自作＝第三者著作権なし。README参照）

| ファイル | 用途 | 既定音量 |
|---------|------|---------|
| bgm_calm_loop.wav | 全編BGM（76bpm・4コードループ） | -21dB（--bgm-db） |
| sfx_whoosh.wav | スライド切替 | -17dB（--sfx-db、共通） |
| sfx_pop.wav | rv-pop / rv-scale の要素出現 | 同上 |
| sfx_ding.wav | 開幕アンカー（0.5秒地点）1発 | 同上 |

## ビルドコマンド（標準）

```bash
python3 _tools/video/make_video.py <episode_dir>/slide.html \
  --out <episode_dir>/video_build/out \
  --speaker 11 --speed 1.1 --final-outro 3.0 \
  --bgm _assets/audio/bgm_calm_loop.wav \
  --sfx-dir _assets/audio
```

- ミックスはconcat後のポストパス（映像は再エンコードなし）。SFXはSTEPSの`anim`種別から自動配置
- BGM音量の判定基準：ナレーションの了解度を一切損なわないこと。迷ったら下げる（-21dB基準、許容-24〜-18dB）
- ミックス後の検証：①A/V長一致（±0.1秒）②`ffmpeg -filter_complex ebur128`でIntegrated Loudnessが**-16〜-13 LUFS**帯（YouTube正規化-14 LUFS前後）③冒頭・中盤・末尾を3秒ずつ切り出してSFX/BGMの音量バランスを実聴確認（ユーザーに提示）

## S18 CTAスライドの標準レイアウト（関連動画・終了画面前提）

- 2カラム：左＝未解決の問い（t-xl）＋「答えは次の動画で →」＋登録CTA／右＝**16:9の点線プレースホルダー枠×2**（上「▶ 次の動画」・下「▶ 講座の再生リスト」）
- この右側の枠位置に、YouTube Studioの終了画面で「動画」「再生リスト」要素を重ねる（＝枠は視線誘導と配置ガイドを兼ねる）
- S18表示中は新情報を出さない。ナレーションで「次の動画」へ口頭誘導（v2仕様）
- 実装例：`01_beginner/ep01_what-is-marketing/slide.html` の `id="s18"`

## 公開時の対応作業（yt-publisherのチェックリストと連動）

- YouTube Studioで終了画面：動画要素（次の回）＋再生リスト要素を右側プレースホルダーに合わせて配置
- AI音声の開示申告（合成音声使用）を忘れない
