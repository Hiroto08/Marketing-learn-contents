# ストーリー設計ガイド（台本前の必須工程）

[retention-packaging.md](retention-packaging.md) §2の構造v2が「器」、本ファイルは「中身（物語）の作り方」。
**「EP◯◯を作って」という指示だけで物語品質が安定する**ことが目的なので、
以下の工程・ワークシート・採点は省略禁止。感覚に頼らず、書式を埋めて採点で判定する。

---

## 1. 手順（この順で必ず実施）

1. **事例リサーチ**：WebSearchで対象トピックの実例を2〜3件収集する（§2の優先順位で選ぶ。出典URL必須）
2. **ワークシート記入**：§3の書式を script.md の `### ストーリー設計` に埋める
3. **構成流し込み**：ワークシートを構造v2（S1〜S18）に割り付けて18枚の見出しを作る
4. **ナレーション執筆**：§4の文体ルールで書く
5. **ルーブリック自己採点**：§5で10点満点採点。**8点未満は該当項目を書き直してから再採点**（採点表は制作メモに残す）
6. **機械検査**：[retention-packaging.md](retention-packaging.md) §3（維持率）→ [narration-rules.md](narration-rules.md)（読み方）の順でPASSさせる

## 2. 事例の選び方（優先順位）

1. **実在×日本×公開情報で数字が取れる**（最優先。例：ワークマンの客層拡大、無印良品の再生）
2. **実在×海外の有名事例**（教科書事例は必ず「新しい切り口」を1つ足す。M&M's・Appleの使い回しだけの回は不可）
3. **架空のコンポジット**（複数の実例を再構成）。この場合は本文・概要欄で**「実在の公開事例をもとに再構成した架空例」と必ず明示**し、数字は断定形にしない

**禁止**：架空を実在に見せる／出典のない統計・数字／同じ看板事例を複数回で主役にする（補強役なら可）

## 3. ストーリー設計ワークシート（script.mdに必須で残す書式）

```markdown
### ストーリー設計

| 項目 | 内容 |
|------|------|
| 主人公 | （名前・立場。視聴者の分身＝原則、中小企業/個人規模の担当者。実在大企業の場合も「当時の担当者・経営者」を主語にする） |
| 主人公の目標 | （欲しい結果を数字で。例：月商100万円） |
| 敵＝思い込み | （このエピソードで壊す常識を1文で。**人を悪者にしない**） |
| どん底 | （失敗の具体描写：金額・期間・行動。例：広告費30万円かけて問い合わせ2件） |
| 転機 | （フレームワーク/考え方にどう出会い、最初に何に気づいたか。偶然の成功にしない） |
| Before→After | （対になる数字。例：転換率0.5%→2.1%） |
| 感情曲線 | 共感(S1-2)→不安(S3-4)→違和感(S5-6)→発見(S7-9)→納得(S10-14)→行動意欲(S15-17) の各感情がどの場面で立つか1行ずつ |
| 主オープンループ | S2で張る問い＝「（問い）」→ S（N）で回収 |
| リフック① | S7に置く反転・意外な数字＝「（内容）」 |
| リフック② | S12に置く反転・部分回収＝「（内容）」 |
| 事例の出所 | 実在（出典URL列挙）／架空コンポジット（根拠にした公開事例） |
```

## 4. 場面の書き方（ナレーション文体ルール）

1. **各スライド＝1場面**。「場面（何が起きたか）→意味（なぜそうなるか）→原則（何を学ぶか）」の3層で書く。場面のない解説スライドを2枚以上連続させない
2. **行動描写＞抽象語**
   - ✗「マーケティングを見直しました」
   - ○「まず、チラシの見出しを全部書き直しました」
3. **セリフ・内心を1本あたり3回以上**入れる（「なんでウチだけ売れないんだ」と社長は頭を抱えました）——合成音声でも感情移入はセリフで作れる
4. **数字には体感換算を添える**（「自由回答1,000件」→「全部読むと丸3日かかる量です」）
5. **固有名詞・具体物で語る**（「ある商品」より「980円の高機能レインウェア」）
6. 理論名・人名は場面の**後**に出す（「これが後に◯◯と呼ばれる考え方です」の順。理論が先に出ると教科書に戻る）

## 5. 品質ルーブリック（10点満点・8点未満は書き直し）

各1点。制作メモに「点数＋1行根拠」を10行で記録する：

| # | 基準 |
|---|------|
| 1 | 冒頭15秒に数字または対比のビジュアルアンカーがある |
| 2 | 主人公が視聴者の分身（規模・悩みが対象視聴者と一致）である |
| 3 | 敵が「思い込み」として1文で言語化されている（人が悪者になっていない） |
| 4 | どん底が金額・期間つきで具体的である |
| 5 | 転機に必然性がある（偶然や根性で解決していない） |
| 6 | 1つの事例が全編を貫通している（別事例は補強役1つまで） |
| 7 | Before→Afterが対の数字で示されている |
| 8 | 感情の言葉（焦り・不安・驚き等）またはセリフが3回以上ある |
| 9 | まとめが「明日やること1つ」の行動に落ちている |
| 10 | 事例の出所が明示されている（実在＝出典／架空＝再構成の明示） |

## 6. Before / After 実例（フック1文の場合）

- ✗ Before（教科書型）：「マーケティングとは、売れる仕組みを作ることです。今日はその基本を解説します。」
- ○ After（物語型）：「機能は他社の2倍、価格は半分。それなのに、この商品は3年間まったく売れませんでした。作った本人が『何が悪いのか分からない』と言ったこの商品、あなたなら何を疑いますか。」

- ✗ Before（理論先出し）：「STP分析とは、セグメンテーション・ターゲティング・ポジショニングの略です。」
- ○ After（場面先出し）：「その社長が最初にやったのは、意外にも『売る相手を減らす』ことでした。——これが後にSTPと呼ばれる考え方です。」
